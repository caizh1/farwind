# 提示框方案一实现检查

final result: passed

## 范围与依据

- 目标：把共用提示框改为方案一的底部叙事栏，保留游戏场景、正文和继续操作。
- 视觉依据：`docs/dialog-design/reference.png`，用户已选择的第一张效果图。
- 样本：路牌、药师最长对话、碑文；独立检查页复用实际 `Interface.dialog`，不连接游戏实例、不改存档、不冒充通关。
- 实际游戏证据：`docs/dialog-design/evidence/runtime-npc.png`。在内置浏览器的生产构建中，通过新游戏、真实键盘步行、E 交谈打开人物提示。
- 开发检查入口：`http://127.0.0.1:5173/docs/dialog-design/preview.html`。
- 生产游戏入口：`http://127.0.0.1:4176/`。

## 尺寸与对比证据

- 原设计为 1725 × 912 像素；等比归一到宽 1368 像素，并裁去最下方约 1 像素，得到 1368 × 722 的对比画面。
- 实现截图为 1368 × 722 像素，对应同尺寸 CSS 视口，截图像素与 CSS 为 1:1。
- 桌面面板尺寸 1280 × 220，位置为 (44, 474)。路牌标题和文字与参考一致，正文按东西、南北两组分行。
- 全景组合：`docs/dialog-design/evidence/comparison-full.png`，左侧参考，右侧组件固定样本。固定样本的纯色背景与顶部检查按钮属于检查页，不是新增游戏界面；背景不纳入面板视觉差异判定。
- 局部组合：`docs/dialog-design/evidence/comparison-panel.png`，上方参考，下方实现，用于直接检查边框、插画、字号、间距和按钮。
- 场景融合另以生产游戏截图核对，人物提示复用现有角色第一帧；路牌固定样本不作为真实步行抵达东村口的证据。

## 检查结果

| 检查面 | 结论 |
| --- | --- |
| 字体与排版 | 宋体类标题、清晰正文；桌面标题 34px、正文约 21px，窄屏标题 24px、正文 16px。长文本自然换行，没有省略内容。 |

| 图片质量 | 三张独立生成素材已落入项目，路牌真实透明，木框采用九宫格保留角部比例，按钮箭头来自图片。合计约 493 KiB。 |
| 内容与操作 | 原提示内容保留；路牌、人物、碑文分别使用对应插画及类别。按钮的无障碍名称仍为“继续 · E”。 |
| 键盘与可访问性 | 打开时焦点进入继续按钮；人物对话在真实游戏中经 E、鼠标点击、Esc 关闭；关闭后 HUD 可恢复，Tab 能打开行囊。支持减少动画偏好。 |

### 响应式证据

- 390 × 844，最长药师对话：面板 366 × 363，按钮 (190, 748)，168 × 56；无横向溢出、无需滚动，按钮完整可见。证据 `docs/dialog-design/evidence/narrow-long.png`。
- 740 × 360，最长药师对话：面板 716 × 279，按钮 (540, 264)，168 × 56；无横向溢出、无需滚动，按钮完整可见。证据 `docs/dialog-design/evidence/short-long.png`。
- 同一低高度窗口下检查碑文，证据 `docs/dialog-design/evidence/short-rune.png`。
- 独立检查页包含可运行的横向溢出断言，布局失败会报错。

## 对比迭代记录

1. 初版存在 P2 视觉差异：文字区过于靠左，路牌插画偏窄，九宫格角落装饰过小。早期证据 `docs/dialog-design/evidence/comparison-panel-before.png`、`runtime-npc-before.png`。
2. 调整插画列到 240px、内边距到 24px，保持面板约 220px 高；正文补入东西与南北之间的自然分行。
3. 重新生成较宽的岩石、白花、草叶路牌底座，扩大边框绘制宽度以恢复黄铜包角与叶片的尺度。
4. 重新捕获桌面组件及生产游戏对话，并将参考和实现放在同一张局部组合图中检查。无剩余 P0/P1/P2 视觉问题。
