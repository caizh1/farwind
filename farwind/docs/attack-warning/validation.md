# 攻击预警实现与验收

## 当前结果：地面预警位于角色下方

用户指出设计图中的地面预警位于主角下方，而实机的亮边横穿主角身体。此前只将填充和箭头放入地面层，边框、辉光和计时线仍在高层；脚边短弧也与头侧感叹号共用高层，这是实际遮挡的原因。

本轮统一分层：地形在世界顶部减一千；首领地面装饰在世界顶部减九百零一；预警填充、方向箭头与脚边短弧在世界顶部减九百；危险边框、辉光和计时线在世界顶部减八百九十九。上述层级均低于主角阴影与角色。头侧感叹号和弹反提示继续使用独立提示层。

普通敌人预警边框下移；首领预警从血条及现身特效的共用绘图对象拆出，新增一个持续复用的地面边框对象，逐帧及重置时清理。首领地面裂纹、冲击环和碎屑也下移。血条、实际挥击特效及头侧气泡保持各自原有层级。

攻击几何、伤害、时钟、锁向、取消、暂停与保存规则未因分层修改而改变。朱红填充、大号箭头、亮边及收拢计时线继续沿用上一轮视觉修正。

地刺脚本在四千六百八十一毫秒已经走入圆圈，却继续第二轴移动，四千九百三十一毫秒时读取到原区域已过期；原过期时间是四千八百二十五毫秒。修正为一进入圆圈就停止，删除途中额外截图。

## 审查结果

VERDICT: PASS

P0/P1 BLOCKERS:

无成立的阻塞问题。

检查普通敌人、首领、地面危险区、脚边提示和头侧气泡的所有调用；核对共用图层、角色及阴影深度、血条、挥击特效、负坐标区域、室内退出、暂停、逐帧清理和场景重置。反证确认：首领血条和现身特效仍使用原高层；新地面边框对象随场景管理并持续复用；本轮不推进或改写正式攻击状态；所有地面预警使用低于最上方地形边界的统一排序值，不依赖玩家当前位置。未发现达到阻止合并或发布程度的缺陷。

UNVERIFIED RISKS:

- 本轮未重跑全游戏回归、全部首领路线、满敌人预算与其他设备的长期性能验收。
- 最终美术满意度仍需玩家试玩确认。

NON-BLOCKING FINDINGS:

- 地面预警现在会被建筑、树木和其他实体遮挡，这符合地面分层。头侧提示在附近真实威胁预计命中时独立显示。
- 普通镰灵和部分复杂侧跃轮廓仍为已有示意，贴身提示读取正式接触预测；本轮没有调整这些几何定义。
- 正式构建保留既有大资源分块提示。
