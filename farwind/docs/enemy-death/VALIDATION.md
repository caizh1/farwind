# 普通怪物阵亡动画修复

日期：2026年10月3日。

## 根因与修复

风针弩灵、唤巢铃妖、裂影猎手、岩脉术士使用的高清图集只有待机、两格行走、蓄力、出手、收势。正式动画采样器已进入死亡状态，但渲染分支将死亡映射成待机纹理，直到共享死亡时窗结束后淡出。

共享高清渲染分支现在按正式死亡时钟执行650毫秒连续倒地：逐步侧倒并压缩横向尺寸，倒地后保持姿态，到2000毫秒开始淡出，2400毫秒完全隐藏。脚根仍来自战斗身体，表现旋转和显示偏移不改变坐标、碰撞、伤害或掉落。其余十种怪物继续使用原有阵亡帧。

固定动画审阅入口增加普通怪物的阵亡动作，调用正式渲染器，支持方向、暂停、时间拖动和重新播放。

## 验证

- 64项相关逻辑测试通过，覆盖敌人动作、史莱姆动画和远程弹反。
- 类型检查与生产构建通过。
- 浏览器固定预览通过：十四种怪物的四方向，共56组；核对死亡优先、根坐标、镜像、连续倒地、停留、淡出、暂停和重新播放。检查原有十种怪物确实切换阵亡帧。
- 正式游戏链路通过：独立浏览器导入合法装备和药品起点，用真实方向键和J攻击击败风针弩灵，验证倒地可见、暂停冻结、淡出、保存和刷新后不复活。没有写入运行时死亡或通关结果。
- 首轮预览断言因浮点数精度失败：实际旋转为1.3499999999999996，期望为1.35。保留首轮追踪，改成容差比较后通过。
- 补截图的实战复验被同期地表开发触发的热刷新打断：追踪显示页面重新连接开发服务器，`terrain.ts`和`campNestGround.ts`修改时间与中断一致。原实战已通过；随后固定本轮源码复验，避免并行改动混入。
- 固定源码后定位到测试的保存等待竞态：先前自动保存的成功提示仍可见，测试误以为新写入已完成；保存期间按Esc被正式输入门禁拒绝，页面一直停留在暂停菜单。复验改为等待写入队列完成，再点击「继续旅途」并确认退出暂停；不修改游戏输入门禁。

## 审查

VERDICT: PASS

P0/P1 BLOCKERS：无。检查了死亡优先级、残留攻击取消、旋转重置、镜像、暂停时钟、显示对象复用、正式结算与读档边界；没有发现成立的阻塞问题。
