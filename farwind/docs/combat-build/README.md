## 范围与假设

- J／左键立即近战；I／鼠标中键独立剑风，按住由模拟时钟控制重复，完整动作每 400 毫秒一次。原有 K／右键架剑、L 风步保持。
- 剑风永久五阶不收费。四连终结通过村庄练习场教本训练获得；未学前保留三连终结。第四段近战具备较宽扇形、较强硬直和较长收招。
- 新增三枚低阶符文：回风、留痕、续势。破岸复用原符文，并保留原探索奖励入口。
- 回风按原生施放共用去程／回程去重集合，每目标各程最多一次；回程伤害为原生基础伤害的 60%。障碍截断，原路或锁定折返时玩家位置，不持续追踪。
- 留痕由原生去程命中产生，四秒寿命、最多八个；同次去程不能消费自己的痕迹。后续去程或本次回程消费一次，半径 60 扰流造成 40%A，无原生触发、无递归。
- 续势只保留已完成有效挥击的连段，合法风步仅保留一次窗口；不能以连续风步续期。默认 700 毫秒，从容分支 1100 毫秒，追身分支下一刀靠近最多 32 像素，沿现有阻挡扫掠且不加无敌。
- 两枚进阶各只有一次解锁及两个互斥分支，安全状态免费改选。三套既有预设保留，其中两套供两条路线使用；预设不授予收藏。
- 本轮美术复用真实挥剑图集与武器采样，第四段作独立时序编排，标记临时表现，最终美术需用户验收。

## 验收边界

基准用户为新档与已学剑风的旧档玩家。人工基线是原有三击后剑风及五槽配装；验收要求独立持续剑风、合法四连终结、两枚符文改变路径或衔接，零双重终结、零穿墙、零重复奖励。用固定时间线、真实入口解锁及录屏核对。该任务为游戏玩法开发，不以未经测量的人工节省百分比宣称达标；代表性战斗不等于普通主线全流程平衡。

## 可玩交付与正常获得路径

启动 `npm run dev -- --host 127.0.0.1 --port 5238`，正式入口为 http://127.0.0.1:5238/ 。本轮已启动该入口，保留原先 5173 服务。正式新游戏默认不授予剑风。隔离战斗验证入口为 `/?combatSlice=1`，使用独立数据库，不能替代正常获得。

操作：WASD 移动；J／左键立即近战；I／鼠标中键剑风，按住连续释放；K／右键架剑；L 风步；E 交互；R 符文；Esc 暂停。剑风无需体力或回能符文，以出手节奏、瞄准、阻挡及敌人逼近限制强度。近战与剑风可以同时保留。

1. 村庄练习场主木桩附近的“本领与构筑训练”或教本：选择“四连入门”，同组前三刀实际命中主木桩，永久获得第四刀及续势。未训练仍是有效三连。再次选择“破岸终结”，一组四刀命中取得破岸；东路原奖励仍保留。
2. 南侧木桥“临水送风”教本：开始限定试用，站在提示位置朝北，用 I 击响水上风铃，正式学习剑风第一阶，同时获得回风、留痕。其余四处原教学仍保留，改为独立剑风输入。
3. 脱战八秒、附近无威胁且没有未结束攻击或派生对象时，R 装备“回风＋留痕”，剩余三个槽自由，保存到“旅途配装 1”。去程安排命中位置，回程或后续剑风消费地面风痕，形成局部扰流。
4. 同样在安全状态装备“续势＋破岸”，保存到“旅途配装 2”。短连后合法风步调整位置，在窗口内接回下一刀，再决定完成终结。没有续势时四连仍然完整。
5. 装备回风，教本“回流训练”：两次同一原生动作去程和回程命中木桩，进阶一次。装备续势，“借势训练”：两组风步接回后命中木桩，进阶一次。均不消耗材料，不增加槽，不反复发奖。

原有第三套预设保留。预设只保存已拥有符文的五槽配置；分支是对应符文的共享成长状态，并非每个预设各存一份。不凭预设增加收藏、刷新冷却或回满资源。

## 来源、计数与旧机制

动作显式区分近战、剑风与反击，带原生动作编号、根来源、近战终结标志及剑风去／回程。独立剑风使用第一段动作编号语义，不能从 `stage===4` 推断剑风。远程格挡反击仍沿原有反击链路，不能错误变成学会四连后的常规第四刀。

- 终结符文：未学四连时第三刀；已学四连时第四刀。同连段只触发一次，剑风不触发。破岸的既有派生潮浪、撞障／免疫补偿保留。
- 蓄积类雷击、云海、剑域、雷敕按原生动作计数，去回与多束不额外重复蓄积。附着／命中类按合法目标接触及原有冷却执行。回程可以额外命中，但不能再生成一次释放事件。
- 原生剑风释放允许既有叠浪、焰尾及对应联动；回风、复制刃、潮浪、扰流没有无限原生再入。扰流只进入派生伤害结算，不调用原生命中规则。
- A 保持武器加成后的第一刀18基准；不含暴击、御风、剑域、虚弱。上述通用原生增伤在原生伤害结算一次；近战终结加成不强化独立剑风，剑风轨迹改造不强化近战。没有重做旧符文全套公式。
