# 小宝 · 听风小宗师：守村与出征完整设计

日期：2026-09-28。委托、同伴战斗、元素技能与飞援已按本方案接入本地游戏。本文保留设计数值、机制与验收要求；当前实现及实际证据以[实施说明](IMPLEMENTATION.md)、[验证记录](VALIDATION.md)、[实现审查](REVIEW.md)为准。用户动作美术、设备听感和完整长期性能验收仍有缺口，不能沿用设计通过作为这些验收通过。

## 一、角色定位与世界观

小宝是能接受长期守村委托、也能跟随旅人出征的五行高手。他的定位是高伤害、能清群、会救场的宗师同伴。当前普通敌人应当一两招解决；重招用于成群敌人和危急局面。主角负责行进、探索、选择目标和安排战术，小宝主动完成大部分战斗判断。

保留用户认可的短黑发、圆脸、笑眼、小门牙、星星练功服、青绿披肩与棕色软鞋。身体比例、年龄感和面部特征保持一致。认真施法时只改变眼神、姿势与周围风纹，战后仍会拍手笑。

岚爷爷的新评语：“这孩子听见的，是风里万物的名字。”风替他传信，石回应拍掌，火回应笑声，雷回应举指。小宝天然能借来五行之力，乐于护住熟悉的人与村灯。常用动作是伸手、拍掌、抱圆、跺一下软鞋和抬指点星。

人物关系：岚爷爷负责翻译小宝的风语；医师照料日常起居；木匠把星形小扣修在披肩上；卫队将他视为能够机动支援三门的同伴；小黑会替他探路，归队后一起休息。

对话用短句与动作保留童真。字幕可以表达风语，不要求角色持续说成人式长台词：

- 接受守村：“村灯，我看着。”随后拍拍胸口。
- 接受出征：“一起！”伸手抓一下主角衣角。
- 保护同伴：“别怕，风在。”抱圆挡在前方。
- 落石：“小石头，下来。”拍一下手。
- 火域：“暖暖的。”掌心开出一朵赤金小莲。
- 天雷：“亮一下！”抬指，雷纹沿风线跳开。
- 凯旋：“回家啦。”拍手，恢复平时的笑脸。

## 二、玩家操作与长期委托

角色只有一个实体。长期任务分为自由活动、守村、随行三种，任一时刻只拥有其中一种。任务变更后生命、真气与冷却继续保留。

| 长期任务 | 如何开始 | 持续与结束 | 自动行为 |
| --- | --- | --- | --- |
| 自由活动 | 初次见面；解除委托 | 持续到接到新委托 | 维持已有广场散步、演武与夜间小憩；附近有人遭袭时救急后回原地 |
| 守卫村庄 | 对话选择“委托守村”，再选全村巡护或东／北／南门 | 默认持续，直到主动解除或改为随行 | 巡护、接收卫队警报、赶赴拦截点、保护村民与设施，战后归位 |
| 随我出征 | 对话选择“与我出征” | 跨室外区域持续；选择“回村守候”或“解除委托”结束 | 跟随、参与主角交战、识别远程威胁、救急、战后归队 |

第一次对话即可使用守村和随行，不增加刷好感、每日续约或反复付款。陪伴记忆只丰富台词，不降低基础战斗能力。剧情认识小宝后即会使用全部招式；长期成长通过共同经历、演武心得和外观小物表达。

普通对话保留“人物故事”“查看本领”“演示武学”。在主角现有界面增加一个正常文档流中的“小宝”入口，显示任务、生命、真气和调息状态。完整技能说明留在本领页，日常界面不铺满技能按钮。

战术只有三个：

- 稳健作战：自动选足以解决目标的招式，危险时保留18点真气用于护阵。
- 护人优先：优先保护主角／村民、打断威胁，随后输出；不因低血友军远离而无限追逐。
- 全力出手：提高群攻和重招的优先级，允许自动使用绝招，仍遵守场景、资源和命中规则。

主角可在“小宝”面板下达“集火我正在攻击的目标”“保护我”“在此等候”“归队”“落石压制”“火域封路”“天雷点杀”“五行归元”。目标优先取主角最近1.5秒真正攻击的合法敌人；没有目标时，攻击指令显示原因，由玩家先选定目标。区域技能以该目标下令时的位置为中心。

打开面板沿用当前菜单暂停。关闭后开始执行，不靠操作面板时流逝的墙钟时间缩短冷却。手动技能只保留一条待执行指令，最长等待5秒；新指令替换旧指令。目标已死亡、离开合法空间或无法取得施法视线时取消并提示，不擅自把指定绝招改打另一个敌人。普通自动战斗仍可继续。

“在此等候”是随行中的临时命令：以当前位置为锚点、活动半径120像素，守住锚点附近；同一室外区域内持续有效。主角改去另一个地理区域或进屋时结束等候并恢复归队／门外等候，避免把小宝永久落在旧区域。

## 三、宗师基础数值

下表为候选数值。距离单位是世界像素；时间单位是有效模拟秒，暂停、失焦、提交存档时均不推进。

| 参数 | 候选值 | 目的 |
| --- | --- | --- |
| 生命 | 640 | 明显高于现有近战卫兵的180与主角的100，能够独立扛住普通来袭 |
| 护甲 | 12 | 使用正式伤害入口扣减，保留最低1点伤害 |
| 真气 | 100 | 供特殊招式共用，普通听风掌不耗真气 |
| 回气 | 交战每秒6；脱战每秒10 | 能持续自动作战，同时为连续重招留出呼吸 |
| 生命恢复 | 脱战6秒后每秒恢复最大生命的1.5% | 守村长期持续；正式接触、有效命中和正在承受持续伤害均刷新脱战时间 |
| 日常步速 | 36 | 沿用现有小步散游气质 |
| 随行／普通战斗步速 | 170／230 | 稳定跟随主角的150步行速度 |
| 追赶步速 | 280 | 跟得上主角的235冲刺速度 |
| 守村赶路 | 420 | 已收到警报且尚未交战时沿合法道路轻步赶赴；遇阻挡仍绕路 |
| 重大袭击飞援 | 巡航1600；起飞0.20秒、降落0.25秒；冷却30秒、耗气0 | “踏风飞援”跨越室外屋顶、树冠与水面，安全落地后先护人；详见[飞援专项设计](FLIGHT-SUPPORT.md) |
| 跟随间距 | 72–110 | 站在主角侧后方，避让主角与小黑 |
| 感知距离 | 600 | 仅识别同空间可见威胁；守村另外接收卫队实际报告 |
| 单次追击约束 | 随行不得离主角超过320；守村不得离指定门的活动区超过80 | 防止追逐把任务锚点拖走；远程施法也要满足技能本身射程 |
| 重新选敌 | 每150毫秒 | 有界、确定性判断；相同优先级按距离和稳定编号选择 |

当前源码基线：五种普通敌人生命分别为48、72、60、90、64；主角基础三段伤害为18、20、30，实际受装备影响；守卫近战18、弓箭22。小宝的72点普通掌伤害是主角基础单段的2.4–4倍，能一掌解决48–72生命的普通敌人，对90生命目标需要两掌。高伤害直接落实到正式伤害数值。

小宝不永久死亡。生命降至0时立即进入“护风调息”：不能继续行动或施法，解除敌人目标锁定，以原地护风茧表现30秒有效模拟时间，结束后恢复320生命与50真气，再延迟1秒投入战斗。若位置在恢复时不可站立，沿当前空间合法地面就近修复。调息不可通过切换委托、打开菜单或读档提前完成；生命、剩余调息时间和攻击冷却都要持久化。主角不会因小宝调息而失去原有复生流程。

所有表内伤害都是未扣目标护甲的原始伤害，不额外继承主角武器倍率。半径、距离与视觉效果用同一个实例配置。完整伤害要求目标真实处在对应命中形状中；离开火域会躲掉后续结算，落石外圈不会承受内圈追加两击。飞援落印与卸风护盾共用取大规则，不能叠加翻倍。

连环天雷的520是五个不同目标的合计，第一个目标最多144；绝招的440是一个目标承受所有阶段的合计。双方数值不能混作单体爆发比较。

### 近战、远程与范围的具体规则

听风掌与三叠掌每一段重新检查距离、扇形、敌人存活和真实近战阻挡。三叠掌可逐段踏前最多12像素，地面扫掠被树、墙或水阻挡就停止踏前。目标在第一掌倒下后可让剩余掌势自然播完，不用重复奖励制造“三连命中”。

弹星指、回风刃使用连续段碰撞，不能靠低帧率跳过敌人或墙。每次接触按沿飞行线的距离排序；墙先于敌人时挡住弹体。回风刃去／回两程分别去重，反弹点固定在实际受阻位置或最大射程点，不追踪已经走远的小宝。

落石只能选同一室外空间的可见合法落点。提前显示地面风纹与石影，落地是攻击效果，余石不能变成新地图阻挡物。每次冲击以对应圆形范围判定，圆心到受击单位之间仍检查阻挡，不能隔墙打到室内住民。

火域以固定圆心和五个明确时刻结算。离开领域不会携带额外未列出的燃烧伤害。进入两个重叠同源火域时同一目标在同一时刻只受较高的一次火域伤害；不会刷新成无限叠加的持续燃烧。终点4.0秒的一次伤害先结算，再销毁领域。

惊雷一指前摇中可修正方向；释放时锁定目标身份、空间与数值。释放瞬间目标不可见或已死则取消。连环天雷每跳从上一处真实命中点寻找未命中的可见敌人，按距离与稳定编号选择；找不到下一跳就结束，不用死目标续链。

抱圆卸风在正式伤害结算时吸收伤害，剩余护盾归零后才扣生命；护甲、80%开阵减伤、护盾、生命按此顺序计算。只能保护相同空间、同阵营、开阵时位于范围内的存活单位，包含主角、卫兵、村民和小宝，最多5名，按“正在受袭、低血、距离、编号”选取。护盾不治疗伤者、不复活卫兵，不代替医师救护。

踏叶救急选择友军受到威胁的一侧合法落点，完整位移沿现有地面扫掠检查。路径受阻就缩短位移；无法赶到时转用合法远程打断或护阵，不穿墙、不跨水、不传送到屋内。

### 有限的招式衔接

保留能理解、能验收的三个衔接，第一版不给全套元素追加复杂反应表：

- 星陨落石首击打断 → 火域铺在目标前进路线上：落石为火域争取停留时间，伤害直接按两项技能相加。
- 听风掌击退 → 连环天雷：打散贴身敌人再远程收尾；雷链每跳仍须有有效目标。
- 抱圆卸风 → 踏叶救急 → 惊雷一指：先护住急迫目标，再改变站位、打断远程威胁。

小宝已经释放的多个技能可以产生组合，但最终伤害仅按独立、去重的正式命中事件相加。第一版不引入导电水面、火烧树林、落石堵门或永久地形改变。

## 五、守村工作闭环

全村巡护以广场合法站位为休息点，通过村内道路巡护。指定门驻防以该门现有活动区内的合法空地为锚点，避让卫兵岗位、门洞、塔楼射口与居民预约位置。小宝使用独立稳定身份，不占据或替换九名卫兵中的任一席位。

一般警戒跨广场到三门的长距离赶路使用村道路径点分段，每段再使用现有480半径的有界局部寻路；重大攻击启动踏风飞援，按单独的空中状态连续移动。地面赶路保留扫掠，飞援起降保留合法地面检查，巡航不套用普通地面阻挡。完整触发与路线规则见[飞援专项设计](FLIGHT-SUPPORT.md)。

一次来袭的行为顺序：收到真实卫队警报 → 选择被袭门及拦截点 → 一般袭扰地面赶赴／重大攻击踏风飞援 → 安全入场、护住村民与卫兵 → 选招击退入侵者 → 等待原防御系统确认结束 → 按原任务归位、回血回气 → 留下一条守村回报。

无警报的夜里可以坐着听风、小憩回气，守村委托仍保持有效；有效警报到来立即收起休息动作。随行状态夜间跟随主角当前行动，不按原来的21:00日常睡眠循环自动脱队。护风调息属于失去行动能力，与普通夜间小憩分开。

优先处理已在攻击村民、设施或低血卫兵的敌人，其次是已经进入村内保护区的入侵者，再是警戒带逼近者。实际选择仍需要当前有效视线，卫队警报只提供最后报告位置；抵达后重新确认，不对隔山敌人凭报告坐标直接施法。报告超过1.5秒且没有续报时转为查探该位置，不无限锁定旧敌人。

全村巡护只有一个小宝，不同时在三门生成影分身。出现多个威胁时按“已伤及居民／设施、预计接触时间、低血友军、到达所需路径长度、稳定编号”调度。一般转场先完成当前释放／恢复；重大飞援允许最多0.10秒收势中断剩余主持动作与后摇，已释放弹体／领域继续，需本人出手的未释放阶段取消；危急护阵可在前摇阶段替代尚未释放的攻击。

普通守村追击限制在该门活动区及外扩80像素的合法室外地面，超过界限就返回。重大警报的临时飞援允许跨门，抵达后改以受援门活动区为战斗锚点，结束恢复原驻防门；起降和攻击仍受空间／地形约束。指定门没有威胁时保留岗位；全村巡护在警报结束后回巡护路线。

当前首夜安静、后续夜间计划、三门各三名卫兵健康与返岗条件、保护期、冷却、每夜事件数量、生成合法性保持既有职责。小宝不能代替这些准入条件，也不主动生成更大波次来展示伤害。30场正式守村验收必须通过正常导演调度，不直接调用生成函数强刷。

玩家进屋或在另一片室外区域旅行时，守村仍由同一个室外世界推进。暂停、失焦、标题页面和关闭游戏不推进战斗。睡到次晨沿用当前住宿安全规则与夜间跳过机制：已有来袭／攻击风险时不能住宿；被跳过的计划记录“今夜休整”，不能伪报成小宝杀敌守村。

回报包含原事件编号、村门、参与的实际命中与击退数、是否有人受伤、结果和发生的有效世界时间。无声守候与战斗胜利分开记录；保存最多最近10条，开面板才展开，不每次命中打断主角。

## 六、随主角出征

小宝通常站在主角侧后方。主角遇敌时，他可以主动走到侧前方输出；战后以跟随间距归队。主角正面对近战怪时，他优先用弹星指／惊雷处理远处射手；主角已被围时先护阵或救急，再落石与火域。

跟随距离超过180时优先归队；超过360时进入280速度追赶，取消新的非紧急攻击。目标追击不能把他带出主角320距离。对主角正在攻击的敌人会增加优先级，但“护人优先”可以先打断更急迫的攻击者。

只对主角实际交战的目标、正在威胁队伍的目标或玩家明确指定的目标出手。普通路过时不会主动把整片区域怪物拉来。主角撤离时小宝采取打断、卸风和归队，不留在屏幕外无止境追击。

绕行复用现有有界寻路与地面扫掠。连续2秒没有实际进展，废弃旧路径并进行一次重新寻路；仍无路径时停在最近合法站位、显示“小宝正在找路”。不循环瞬移到主角脚下。过门、快捷通道和明确场景转移可以按同伴规则安置在目的地合法落点；这种转移由真实交互触发，与一般跟随寻路分开。

主角进屋时，小宝停在屋外合法等候点，室外未释放攻击取消，已释放弹体与火域只在所属室外空间内运行到寿命结束。主角离屋后归队。守村任务不受主角进屋影响。训练投影、演武木桩和主角的弹反练习默认不进入小宝的正式攻击目标列表；玩家在“演示武学”中看本领，练习进度仍由主角自己完成。

主角倒下按原有流程返回广场，随行小宝停止开新招并经同一复生事件回到广场的合法站位。小宝不会代替主角复活，也不在死亡画面期间继续计算多轮伤害。

随行的“危急自动回援”默认开启，可在同伴面板关闭；主角当前危急时先护主。飞援只暂时中断随行，战后恢复原任务。已离地时发生复生／场景转移，按[飞援专项设计](FLIGHT-SUPPORT.md)从当前空中位置改往安全地面，不直接把屋顶投影根当成地面站位。

## 七、确定性的选敌与选招

每150毫秒收集一次当前场景的真实敌人、友军、阻挡与警报。按稳定顺序执行：调息状态 → 空间／任务限制 → 主角当前危急保护 → 重大警报飞援／当前飞行阶段 → 主角撤离或普通等候命令 → 紧急护人 → 有效手动指令 → 群攻机会 → 单体出手 → 归位。重大跨门支援的边界例外与随行回援偏好按[飞援专项设计](FLIGHT-SUPPORT.md)处理。

紧急判定包括：同空间受保护友军生命低于30%且有即将命中的攻击；敌人已对村民／设施开始有效攻击；两名以上敌人已贴近主角。判断来自正式攻击前摇、接触与目标信息，不从屏幕闪光猜测危险。

| 实际情况 | 默认选择 | 选择失败时 |
| --- | --- | --- |
| 一个普通怪，96内，无紧急保护 | 听风掌 | 移到合法近战站位；可见且远处则弹星指 |
| 一个需要持续输出的目标，112内 | 三叠震山 | 普通掌或远程点杀；不要求当前增加精英敌人 |
| 单个远程威胁，96–520 | 惊雷一指；资源／冷却不足用弹星指 | 合法接近，不能隔墙点杀 |
| 至少3目标集中在首落石110圆内 | 星陨落石 | 火域或连雷；同时考虑正在靠近的移动方向 |
| 至少2目标会穿过同一通路或围住友军 | 赤莲火域 | 落石；不能在不可见通路上盲铺火 |
| 至少3目标分散、相邻链距不超过150 | 连环天雷 | 回风刃或逐个弹星指 |
| 护人紧急且范围可达 | 抱圆卸风／踏叶救急 | 合法惊雷打断，或沿路径赶赴 |
| 全力战术且至少4目标在绝招范围内；或至少3目标围住低血友军 | 五行归元 | 单项护人／范围招；默认稳健战术的绝招由玩家手动指定 |
| 正式重大警报且战场距离超过240 | 踏风飞援，安全落地先护风落印 | 冷却时地面赶赴；调息时如实提示；主角危急时先护主 |

同一招式的前摇、释放、后摇期间不反复变更招式。持续领域不会锁住已经恢复行动的小宝。目标死亡时取消未释放指令，已释放技能按各自规则结束；不会把剩余三掌、雷跳或火结算额外转成奖励。

硬直按目标已有能力处理，短硬直取较晚截止时间，不把连续小技能累计成数十秒眩晕。一次硬直最长0.8秒；同一目标脱离一次硬直后1秒内再次受到的控制时长减半。生命、伤害照常结算，已有不能打断的攻击标记应被尊重。

## 八、伤害、掉落与任务归属

小宝属于村方阵营，所有伤害通过正式阵营校验、目标存活与空间门禁。近战、投射物、每次落石、每次火结算、每次雷跳均有独立、可追溯的命中键：会话编号、攻击序号、技能阶段、目标编号。一次死亡只能结算一次。

复用现有非玩家击杀的世界状态与主线结晶待领取链路，再统一补齐同伴随行时的掉落归属：

- 随行期间击倒正式野怪视为队伍贡献。掉落尽量进入主角行囊，背包满时进入该敌人的唯一待领取掉落；主线、杀敌记录、结晶进度按原要求推进。
- 守村／自由活动期间击倒靠近防线的常驻野怪，掉落留在地面，不静默代领主角采集与剧情奖励；核心结晶保持可领取。
- 原夜间防御事件继续采用自己的结束与回报机制，不给同一只怪追加野外奖励。演练和演武目标没有正式掉落、铜币或任务进度。
- 不改变掉落种类、有限野怪数量或当前无经验等级体系。不提供刷委托无限领奖的循环。

当前源码已经在非玩家击杀通知中保留裂枝镰灵的结晶，并在正式任务条件满足后对账；实现时复用这条路径，禁止仅替换敌人生命、绕过死亡通知。

合法释放时锁定攻击来源、伤害、阵营、空间与委托版本。小宝之后进入调息或换任务，不能改变已释放弹体的伤害；新的攻击仍需要小宝存活且可行动。场景销毁时清理该场景弹体与领域；场景内的任务切换只取消未释放动作。命中结算不能伪造“施法者仍满血”。

## 九、存档、时间与异常恢复

设计时正式存档结构版本为7，本次已升至8，地图仍为6。旧1–7版本经现有迁移链后补默认自由活动、640生命、100真气、零冷却；地图不升版、不平移坐标。

持久化字段包括：认识状态、长期任务、驻防门／全村、战术、室外地面根、生命、真气、各技能剩余冷却、调息剩余时间、护盾及控制剩余时长、当前正在生效的攻击与领域、稳定攻击序号、近期回报。运行时选择目标、寻路缓存和显示对象可以重建。

写入只走现有串行状态提交锁。委托切换先保存合法快照、成功后发布；保存失败保留旧委托和旧位置，反馈“委托尚未保存”。反复点击不产生第二个角色、第二个夜间事件或双份奖励。

战斗中存档需要能够保持新伤害实例的连续性：已释放弹体保存起点、当前位置／速度、剩余寿命与已命中目标集合；领域保存中心、剩余时长、下一结算阶段及已结算阶段；技能冷却保存剩余值，读档只恢复剩余阶段。正在前摇的施法可统一取消，因为资源尚未扣除；读档追加0.3秒恢复，不能取消已释放技能再重放首击。

原常驻野怪只保存死亡记录。本次结构8已增加“受小宝影响、仍存活的常驻敌人”有限快照：生命、地面根、控制剩余、控制恢复保护与上限、当前空间。集合包含尚未命中的施法目标以及弹道范围、领域中的真实野怪，不能等首次伤害才记录，否则已发弹体读档后会面对回到家园的敌人。集合上限为正式野怪数量，死亡移出，编号仅来自正式定义；它与领域实例一并恢复，避免伤害进度重置。

存档对所有数值验证有限范围与稳定编号；技能名必须来自当前12项技能，弹体／领域数量受运行上限约束，命中集合去重；未知字段不进入发布状态。飞援另保存警报前线去重、原任务上下文、当前航程／起降阶段、剩余冷却与落印释放标记，按[飞援专项设计](FLIGHT-SUPPORT.md)连续恢复。单位不能在两个空间同时登记。新开局、返回标题、重建World时销毁旧实例并更换会话标识，避免旧投射物回调伤害新存档。

技能按战斗有效模拟时间运行，不能用加速的世界分钟或系统时钟计算。住宿跳时不补算未发生战斗；不加快调息和技能冷却。当前没有战斗风险才允许住宿，新技能必须加入“在场攻击／投射物／领域／飞援与待降”的安全检查。

内置演武页增加12项技能完整预览：四方向／镜像、主体与特效、前摇／命中／后摇、飞援起降／巡航、暂停逐帧、实际根位移。数值和命中形状从正式技能定义读取。验收保留设计图、固定预览、真实守村／出征截图三种证据。

| `src/game/systems/damage.ts` | 明确新增同伴近战／飞行／元素来源；将已释放快照从塔箭限定扩至合法同伴来源，每阶段伤害锁定；统一护甲、减伤、护盾、生命计算 |
| `src/game/systems/obstacles.ts`、`enemy.ts` | 复用地面扫掠、近战阻挡、弹道阻挡与有界寻路；与当前每帧寻路总预算共同排队 |
| 居民危急警报、卫队正式观察与小宝飞行状态 | 接入真实重大前线识别、跨门任务例外、空中接触层、有限落点检查及空中读档恢复；普通碰撞函数保留地面职责 |
| `src/game/scenes/World.ts`中的野怪死亡／防御通知／结晶对账 | 统一同伴击杀与现有掉落闭环，保证一条死亡事件只结算一次 |
| `src/game/systems/state.ts`、`stateCommit.ts`、`save.ts` | 结构7迁8、校验、串行委托提交、战斗保存与恢复；新受伤野怪有限快照必须一起校验 |
| `src/game/systems/sleep.ts`、`World.sleepSafety` | 将同伴攻击、领域、弹体和新敌人风险计入正式住宿安全门禁 |
| 现有世界地图／小地图入口 | 展示小宝当前实际位置与任务；地图标记留在正常布局与既有绘制链路 |
| `src/xiaobao-preview.ts`、专项测试 | 共用正式技能配置新增逐帧与真实动作对照；演武无奖励、无任务副作用 |

主体状态机为“归位／巡护／跟随／赶路／飞援起飞／巡航／待降／降落／选择站位／前摇／释放／恢复／护人／调息”。长期任务与当前动作分开：守村是任务，落石与飞援是动作，不能因为动作播完把守村自动改回自由活动。

运行约束：同时最多2个小宝飞行攻击实例、2个持续地面领域、1个本体飞援状态；每个元素技能总接触事件上限固定，飞援尾迹、落石显示物与雷纹对象有限复用。世界寻路仍使用当前每帧最多2次总查询预算，不给小宝额外无限A*。满额时自动选没有新领域需求的招式；手动指令显示资源原因，不静默少结算伤害。

## 十二、验收基线与真实样本

目标用户是希望小宝能自主作战的《远风》玩家。输入条件是当前正式地图、五种普通敌人、三门防线、真实玩家移动／攻击／委托界面，以及结构1–7旧档和结构8新档。支持范围为单个小宝、当前室外区域与已有门内等候规则。新增精英、地下城、联网多人和可破坏地形不在本次角色机制范围。

人工基线是逐次选敌、靠近、攻击／闪避、赶赴门口、护人、查状态与处理掉落。当前已对五种普通单敌记录同场景、同站位的无小宝／自动随行主动战斗输入、耗时、生命与掉落；详细数字见验证记录。目标为普通战斗干预减少至少80%，探索移动与委托准备不计入；固定单敌结果不能外推所有人工流程，复杂场景对照仍未完成。

错误门槛：正式样本中误伤、非法穿墙／越空间命中、双份奖励、主线材料丢失、同伴复制和存档损坏必须为零。有效合法命中漏结算必须为零；被阻挡、被躲开、目标提前死亡属于应当无伤害的反例。自动选招是否“够聪明”以固定危险样本中护人优先级和死亡结果验收，不仅看演武动作播放成功。

交付次序：先完成技能姿态／特效设计图与数值定义；随后接入委托、状态、目标、伤害、飞援和保存；再验证守村／随行真实路径、12技能完整结算与故障反例；最后验证美术、听感与长期帧率。后续实现可分批落地，但本设计中的三种任务、五种攻击覆盖、重大袭击飞援和保存闭环都属于完整交付要求。

## 十三、设计反证审查

VERDICT: PASS

P0/P1 BLOCKERS: 无。此处为设计审查；已编写实现的独立审查见[实现审查](REVIEW.md)，具体运行验收见[验证记录](VALIDATION.md)。

已反证并落实到设计的风险路径：

- 主角进屋 → `resolveBattle`提前返回 → 守村看似施法却无真实伤害：明确将守村放进仍推进的室外战斗时间片与正式伤害入口。
- 高伤害仅改生命 → 没有死亡通知／待领取结晶 → 主线材料断路：复用并统一现有死亡与结晶对账，满背包仍只留一份掉落。
- 多阶段范围命中／同帧补刀 → 多次结算死亡 → 重奖励：每阶段独立命中键，目标死亡统一一次结算，事件与野外奖励职责分开。
- 投射物保存／读档 → 未死亡常驻怪满血重建 → 原领域重放或伤害消失：持久化受影响未死野怪与当前释放实例，恢复剩余阶段。
- 回风刃使用活体来源校验 → 小宝调息后所有已释放命中被拒绝：扩展正式不可变释放快照，不伪造施法者满血。
- 新领域未加入住宿风险 → 跳时清场／重放技能 → 跨夜幽灵攻击：统一住宿门禁；住宿不推进技能时间、不虚构战报。
- 指令切换／存档发布 → 原生命、冷却或事件被覆盖 → 无限重招／同伴复制：唯一实体、串行保存、模式与动作分离、剩余状态连续。
- 自动寻路／范围特效无上限 → 大量查询与对象 → 长帧或内存增长：共用当前查询预算与固定实例上限，性能需要真实设备验证。
- 重大跨门警报被普通驻防边界拒绝、空中投影遭地面纠错／命中、重复警报重放护印：按飞援专项设计限定任务例外，使用空中状态／接触层、阶段保存和前线去重。

UNVERIFIED RISKS: 此处为设计阶段风险清单。当前自动选招、技能结算、护人、保存和固定五敌基准已实施验证；主观美术、设备听感、复杂战场人工对照及完整性能边界仍见[验证记录](VALIDATION.md)。独立实现审查见[审查记录](REVIEW.md)。

NON-BLOCKING FINDINGS: 当前普通敌人较弱，小宝加入会显著降低交战难度，这是本次高输出定位的预期。全村巡护只有一个实体，赶路时间会影响跨门救援，不能仅凭身份设定承诺所有居民永不受伤。后续若新增高生命敌人，可直接复用已有技能与控制约束，不影响当前设计。
