# 小宝 · 听风小宗师

日期：2026-09-28。三种长期委托、十二项战斗／支援技能、重大袭击飞援、正式伤害与掉落、保存恢复、动作及界面已经接入本地游戏。详细结果见[验证记录](VALIDATION.md)、[实施说明](IMPLEMENTATION.md)、[审查记录](REVIEW.md)。

短黑发、圆脸、笑眼、小门牙、星星练功服、青绿披肩和棕色软鞋继续保留。对话立绘直接使用用户认可原画，仅等比缩小；原照片未复制到公开游戏资源。

## 怎样使用

1. 点击左上方“小宝”状态按钮，或靠近小宝按E。
2. 选择“委托守村”“与我出征”或“解除委托”。任务会保存，生命、真气与冷却保留。
3. 驻防可选全村巡护或三门；战术可选稳健作战、护人优先、全力出手。
4. 随行可下达集火、保护、等候、归队、落石、火域、天雷或归元。攻击指令取主角最近真正攻击的目标；无目标、资源不足或隔墙时显示原因。
5. 默认允许出征时危急回援，可以关闭。仅观察野怪不触发飞援，真实重大袭击才自动出手。
6. 展开“查看十二项本领与守村回报”阅读数值、剩余冷却和最近战报。

生命640、真气100。零生命后护风调息30秒，恢复320生命、50真气后继续原委托。随行不主动拉取远处普通野怪；战后归队，进屋留在室外。守村职责在室外推进，菜单、失焦和保存冻结有效时间。

飞援先保存再离地，巡航最高1600像素／秒、支援预算5000、冷却30秒；起飞0.20秒、降落0.25秒。空中不攻击、不回血回气、不能被地面接触命中。成功落地为附近最多五人提供120护盾、持续2秒；不相加。落点被占时选择备用点或悬停安全返降。
