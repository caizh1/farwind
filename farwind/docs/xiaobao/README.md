# 小宝 · 听风小宗师

## 人物设定

小宝是风铃村的小客人：短黑发、圆脸笑眼、笑起来露出小门牙，穿浅米白金粉星星练功服、青绿短披肩和棕色软鞋。身份原画由用户提供的两张照片生成，用户已明确认可“非常像”。对话立绘直接使用这张原画，仅等比缩小。

岚爷爷说：“这孩子先听懂了风，才学会走路。”他平时在广场小步散游、拍手大笑、坐着听风；认真起来，能用听风掌送出风息，以抱圆卸风化去来势，用踏叶轻步轻盈起落。招牌话：“风很大，也可以轻轻的。”

本次交付是可互动、会活动与演示武学的人物。演武不扣玩家物品、不改变伤害或技艺进度。实际战斗AI、传功任务和加入居民救护系统均未在本次实现。

## 动作与运行

共12组、72个真实手绘姿态。行动图集：听风待机、正面小步、侧面小步、背面小步。社交图集：挥手招呼、大笑鼓掌、抱拳致意、盘腿听风。武学图集：听风掌、抱圆卸风、踏叶轻步、安心小憩。

三套运行图集每帧160×160，地面根固定在[80,148]。整套只采用一个缩放比例，盘腿不放大。步态只读真实自主位移；轻步的素材升高与地面根分离。镜像经现有Actor统一设置，风效随动作进度播放。夜里21:00至06:00小憩，已开始的演示播完再休息。暂停、对话、保存与失焦均跟随主场景冻结。

小宝初始在广场右侧[810,725]，沿[870,725]、[870,685]、[810,685]小范围活动。路线避开广场树冠，防止小宝被前景遮住。靠近按E，可看立绘、设定并选择听风掌、踏叶轻步或完整演武。进屋后隐藏小宝，室外行动仍查询室外地图的正式碰撞。开局与读档重建他的表现循环；人物没有需要写入存档的任务、物品或战斗状态。

## 素材与复核入口

- 身份原画：`art/sources/concept-source.png`。
- 原始动作：`art/sources/motion-source.png`、`social-fixed-source.png`、`mastery-source.png`。
- 运行素材：`public/assets/xiaobao/`，资源清单记录实际切分、透明通道和缩放。
- 固定预览：`http://127.0.0.1:5173/xiaobao-preview.html`。支持12组动作、原尺寸与三倍对照、暂停、逐帧、镜像及连续播放。
- 源提示词：`art/prompts.md`；均使用内置imagegen。原照片没有复制到游戏公开资源目录。
- 可重建命令：`npm run assets:xiaobao`；专项验证：`npm run test:xiaobao`。

社交初稿第三行的鞋与第四行的头相接，无法可靠切帧。针对行距与尺度进行了单次定向修正；运行使用修正版，原图保留以便追溯。打包器要求24个独立连通主体，否则报错，避免静默切坏。打包只裁切、等比缩放和根对齐，没有重绘已认可的脸。

## 验收边界

守村、随主角出征以及近战、远程、落石、火焰、闪电的完整扩展设计见[战斗与委托设计](COMBAT-DESIGN.md)。该文档是2026-09-28的机制设计；当前运行角色仍是上文的日常与演武版本。

重大攻击时的快速支援技能“踏风飞援”见[飞援专项设计](FLIGHT-SUPPORT.md)：起飞、巡航、降落与护风入场，新增后共12项战斗／支援技能；同样处于设计阶段。

人工基线是逐个裁切72帧、手工登记锚点、逐项检查12组动作，再进游戏走动与交谈。当前自动化覆盖所有帧的完整主体、透明边界、姿态差异、脚底位置，并检查正式村庄路线和真实键盘交互。尚无人工流程的计时对照，因此不宣称已经量化减少80%人工。

身份原画已经认可；动作连贯度、神态与游戏内尺寸仍待用户美术验收。自动化结果与实际运行截图分别记录在`evidence/`。设备长期帧率与音频听感未测，未提交、推送或部署。

当前验收以`evidence/production/`的正式构建截图与`browser.json`为准。`evidence/`根目录保留早期开发截图，其中路线尚未避开树冠，不代表最终可见性。验证汇总见`VALIDATION.md`，代码审查见`REVIEW.md`。
