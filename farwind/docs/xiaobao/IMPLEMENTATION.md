## 用户、基线与支持边界

目标用户为当前《远风》玩家。输入为正式五种野怪、三门防线、当前地图、真实移动／攻击／委托界面、结构1–7旧档和结构8新档。支持单个小宝、当前室外世界和既有房间；联网多人、新精英和地形破坏不在范围。

人工基线为选敌、调整站位、出招、赶赴防线和领取掉落。普通战斗干预减少至少80%是设计目标，目前只有五类普通单敌固定按键对照可量化；不外推全部阅读、判断或复杂战场。误伤、跨墙／跨空间伤害、双份奖励、关键材料丢失、非法落地和无效状态发布门槛为零。

## 文件与验证

核心文件为 `src/data/xiaobaoCombat.ts`、`xiaobaoState.ts`、`xiaobaoCombat.ts`、`xiaobaoWorld.ts`、`World.ts` 与 `xiaobaoView.ts`。正式伤害、敌人目标、防御、居民护盾、投射物、声音、保存及住宿入口沿现有链路接入。独立演武位于 `src/xiaobao-combat-preview.ts` 与 `xiaobao-combat-preview.html`。

`tools/pack-xiaobao-combat.mjs`按独立透明主体切帧，数量不符拒绝静默打包。专项逻辑、正式三门路径、三十场集成与真实浏览器分别记录在 `tests/xiaobao-*` 和 `evidence/`。

工程通过、运行截图、用户美术接受、设备听感、长期性能与发布是不同状态。真实检查项与数字见[验证记录](VALIDATION.md)，对抗结论见[审查记录](REVIEW.md)。最终包完整60分钟记录包含三次正式来袭和两次飞援，对象最终520、纹理200；短CPU对照仍不能替代全部新增逻辑开销指标。
