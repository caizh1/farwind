# 小宝人物接入审查

VERDICT: PASS

P0/P1 BLOCKERS:

无。审查覆盖新增人物的数据、行动推进、空间查询、素材加载、生命周期、对话事件、输入暂停、与存档及现有任务的交互、构建入口和资源分发，没有确认成立的P0/P1阻塞。

已对候选问题反证：

- 行走穿过实体：调用正式室外连续碰撞查询，阻挡时不累积位移或步幅；当前广场路线由自动化验证可走。进入室内后仍查询室外地图，避免把玩家所在房间的几何用于广场人物。
- 前景遮住人物：运行截图发现原路线走入广场树冠，已移到北侧空地；专项检查整段路线不进入树冠遮挡区，正式构建的出掌截图确认人物完整可见。
- 对话、暂停、保存或失焦时偷跑：推进只在主场景的正常模拟阶段执行，沿用已有暂停与提交门禁。没有独立定时器或不可暂停的补间。
- 轻步升高改动碰撞位置：角色地面根保持，升高只作用于精灵显示；阴影与交互目标始终使用地面坐标。
- 演武误扣材料、修改伤害或存档：新增交互在居民通用分支前处理，只改变小宝表现状态；没有写玩家库存、任务、战斗或居民生活状态。过往存档无需迁移，读档重建表现循环。
- 重复交谈泄漏对象：场景只创建精灵、阴影、标签、风效四个对象；按钮与监听随每次对话节点移除。没有每帧新建对象、订阅全局事件或写入长队列。
- 源图行距导致截断：打包按24个独立主体切分，不采用生成图的名义等距网格；不足24个直接报错。初稿人物相接已定向修正，72帧检查透明边界与脚底。
- 其他任务回归：只在世界加载、创建、刷新、正常更新及交互集合增加小宝钩子。未改写原有受击、架反和剑风工作；所有已登记立绘要求资源互不重复。

UNVERIFIED RISKS:

- 身份原画已认可，但12组动作的神态、整体连贯度和最终尺寸仍待用户美术验收，不能用构建或测试通过代替。
- 没有目标设备长时间帧率数据；新增三套960×640图集与四个固定对象的资源规模可核对，但不能据此声明性能验收完成。
- 未进行设备音频听感验收，本次也没有新增音频资产。
- 没有人工基线计时对照，不宣称已经达到减少80%人工的量化目标。

NON-BLOCKING FINDINGS:

- 表现循环在读档时重新开始，位置与演示进度不持久化；当前没有任务或战斗状态依赖小宝的位置，因此不造成进度或数据损失。后续若加入传功任务或战斗AI，须另行定义持久化状态与验收样本。
- 六帧动作已可逐帧复核；如用户提出更细腻的连贯度要求，需根据具体动作补画姿态，而不是用旋转、缩放整张人物图冒充新的动作。
