# 踏风飞援：听风小宗师的危急支援

日期：2026-09-28。阶段：技能设计。本文扩展[小宗师战斗与委托方案](COMBAT-DESIGN.md)，飞行及重大攻击响应尚未接入游戏。

## 技能气质

风铃急响，小宝抬头听风，脚下青绿风环托住软鞋，星星衣服亮起微光。他张开小手、披肩迎风，从屋顶与树冠上掠向受袭处，轻轻落在需要保护的人身前。

招牌风语：“风来了，我也来了。”

这是一个自动响应重大袭击的快速飞行技能。小宝的投影位置沿航线连续移动，玩家能看见升空、飞行尾迹、阴影与落地；保持已认可的脸、童真、服装与身体比例。

## 候选数值与到场目标

| 参数 | 候选值／规则 |
| --- | --- |
| 起飞 | 0.20秒，从合法室外地面升起 |
| 巡航最高速度 | 1600世界像素／秒；短航程按最短巡航时长均匀推进，实际速度不超上限 |
| 最短巡航 | 0.20秒，短距也保留可辨认的移动过程 |
| 最大支援航程 | 5000世界像素，覆盖当前4200×2200室外世界；超过累计支援预算仅允许安全返降，停止新增前线切换 |
| 降落 | 0.25秒，重新确认落点后收风站稳 |
| 素材升高 | 巡航约88显示像素；随起降进度升降，与投影根分离 |
| 真气消耗 | 0，回气不足时仍能救村 |
| 冷却 | 30秒，从离地正式释放时开始 |
| 近场处理 | 已在战场240距离内时直接护人、打断与输出，保留飞援冷却 |
| 飞行中行为 | 不攻击、不回血回气、不触发采集／掉落／剧情区域交互 |
| 落地保护 | “护风落印”：周围120内最多5名村方存活单位各获得120护盾，持续2秒 |

护风落印包含小宝、主角、卫兵与村民，按受袭、低血、距离、稳定编号选取；只在成功落地且重大攻击仍有效时释放一次。它与抱圆卸风使用同一个护盾规则，取较大剩余护盾和较晚截止时间，不能相加成240护盾。落印本身没有伤害、治疗或复活效果。

按当前小宝广场站位[810,725]与三个门外拦截点计算，起飞、巡航和降落合计约为北门0.81秒、东门1.34秒、南门1.19秒。实际落点需避让、起飞前可能挪步，故村内到场目标为约1–2秒。当前地图最远对角航程约4741像素，纯起降与巡航合计约3.41秒。

这些是距离推导的设计目标，尚无运行实测；警报确认、状态提交与落点调整耗时另记，不能把纯飞行时长当成真实报警到场时间。所有技能时长与冷却只读有效模拟时间。

## 怎样判定重大攻击

取现有正式卫队观察、敌人攻击实例、居民／设施真实伤害事件与居民危急警报。调试警报、尚未出生的预警、屏幕特效和历史战报不触发正式飞援。

满足以下任一条件，且同一警报前线仍存在真实存活、未禁用敌人：

1. 居民系统发出二级“居民区威胁”警报，实际原因是敌人突破门内防线、接近居民区，或正在发生的来袭导致门级失守。
2. 村民或关键设施正在遭受正式敌方攻击：已有真实扣血；或当前有效前摇将在0.6秒内接触一个合法受害者，且攻击未取消。
3. 当前正在交战的村门，在岗、存活、生命至少35%的卫兵少于两人，门内／近门保护区仍有入侵或攻击威胁。35%按守卫各自最大生命计算。
4. 两个村门同时存在真实的入侵或攻击警报，需要机动支援；仅在门外观察到路过野怪不算。

当前居民系统的二级警报包含调试入口，因此不能只判断 `life.alarm === 2` 就升空。还必须校验真实敌人、危急原因与正式报告来源。

普通一级袭扰继续使用已有地面巡护、420速度赶路与常规技能。飞援接收已发生的危急事件，不改变首夜安静、夜间计划、生成许可、卫兵健康准入或来袭数量。

## 与三种长期任务的关系

| 原任务 | 响应方式 | 战后行为 |
| --- | --- | --- |
| 自由活动 | 正式重大警报自动响应，结束小憩或演武；最多0.10秒收势后进入起飞 | 返回广场，恢复原日常 |
| 守村 | 自动飞援；重大警报可暂时跨门支援，突破原指定门的日常活动边界 | 回到原驻防门或全村巡护路线 |
| 随行 | “危急自动回援”默认开启，可在同伴面板关闭；收到警报先显示一次“村庄危急，小宝将飞援” | 恢复随行并归队 |

随行时若主角生命低于30%，且有0.6秒内将真实命中的敌方攻击，小宝先用可用护人技能处理；危险仍有效时延后飞援，显示“先护住旅人”。主角脱险后再检查村庄警报。不能在护主危险持续时硬拉走小宝。

飞援是原任务中的临时动作，保存原任务、驻防门、战术与归队对象；不把随行偷偷改成长期守村。原地等候命令可被正式重大警报临时打断，结束后同区域恢复等候，跨区则按原规则归队。

小宝处于30秒护风调息时无法出动；状态显示“调息中，卫队仍在应战”。30秒飞援冷却未结束时沿合法地面赶赴，不重置冷却。真气为0时仍可起飞，落地护印与普通听风掌可正常救场。

重大飞援可以中断普通动作与施法后摇，收势最多0.10秒。未释放的攻击取消；已释放的弹体与领域按原实例继续，不退真气、不刷新冷却；三叠掌等需要本人继续出手的剩余未释放阶段取消。五行归元首段正式释放后，其后续火息／终雷由锁定领域推进，小宝可收势离开主持姿态。这样不会为了播完数秒动作而延误飞援，也不因升空产生额外命中。

战后返程遵守同一个飞行冷却。冷却尚未结束时沿道路归位／归队，不能借免费返航重放护印或绕过下一次出动限制。自动回援关闭只限制随行中的离队行为，不关闭守村／自由活动的危急响应。

## 从警报到入场

响应顺序：正式警报 → 确认前线与受护对象 → 验证安全起落点 → 接受并保存支援动作 → 起飞 → 巡航 → 安全降落 → 护风落印 → 正式选招参战 → 前线安全后恢复原任务。

同一重大警报周期、同一前线只接受一次飞援请求。飞行中不逐帧新增召援，不产生第二个小宝。原始夜间事件编号保持不变；无夜间事件的居民危急使用独立警报周期编号，并保存已响应前线集合。

多前线优先级为：居民／设施正受击 → 低血友军即将遭受致命接触 → 村内入侵 → 失守门 → 其他重大警报；同级按预计接触时间、真实航程、稳定编号选择。普通新警报不打断正在进行的巡航。更高优先级的危急前线可在巡航前半程改道一次，从当前真实位置继续飞行，累计航程仍受5000上限约束，不能回退到原起点。

起飞前重新确认警报与目标。敌人全部被卫队击退则取消，不消耗冷却。离地后危机解除时选择附近安全地面降落，记录“危机已解除”，不放护印、不结算支援杀敌；已发生的飞行仍消耗冷却。

降落后先开护风落印，再复用原有战斗选招：先打断正在攻击居民的敌人；密集敌人用落石，通路群敌用火域，远程威胁用惊雷，分散敌群用连雷。五行归元继续遵守原来的真气、冷却、战术与目标条件，不能因飞援到场免费刷新绝招。

## 真飞行的路线与落点

起飞、巡航、降落是三种明确动作状态。投影根沿当前空间航线连续移动，主体升高单独计算。巡航由专用空中层显示在屋顶／树冠上方、界面下方，阴影跟随真实投影根。左右由Actor统一镜像，不用步行动画表示高速巡航。

巡航允许越过当前室外世界的树冠、房屋屋顶、围墙和水面。它不查询普通地面行走阻挡来拒绝飞越，但不修改行走、近战或地面弹道的碰撞函数。起降必须使用现有合法地面检查，不能落在树干、塔基、水面、墙体、门洞阻挡或屋内空间。屋檐下先挪到合法起飞空地，仍受地面扫掠限制。

飞援只前往正式报告中的村庄前线，不开放任意点飞行；返程目的地是原任务锚点或主角当前合法室外位置。不能用飞援解锁未开放区域、快捷通道、剧情门或室内空间。飞过区域不会触发主角的任务／采集逻辑。

落点优先取受护对象朝敌人方向的侧前方72–110距离；其次取当前村门的安全拦截空地。目标点来自受护者真实位置或已有合法村门数据，不把敌人的站位当成着陆点。起飞时预先选择一个主落点、两个备用落点，以及一条到目的地区域预设安全地面的撤退航线。安全返降只负责恢复合法地面状态，不释放护印、不攻击、无额外奖励，沿用已消耗的飞援冷却。

降落前再检查一次地形、空间和占位。主落点失效则从当前空中位置飞向仍合法的备用点。每次选择最多检查16个有限候选，遵守当前总寻路预算；不无限运行全地图搜索。备用点全失效时最多悬停1秒，再沿撤退航线返向当前区域的预设安全地面。最终落地仍须合法；没有合法地面时保持不可攻击的待降状态，并以每150毫秒一次有界候选检查等待合法地面，禁止硬塞坐标。

巡航中的小宝不进入现有地面攻击的目标集合；起飞未离地和降落结束后的地面状态按正常受击规则处理。原已释放的地面弹体也要按当前空间与接触层校验，不能在小宝升空后继续命中他的投影根。当前设计未引入对空敌人或空中攻击。

报告超过1.5秒未更新时仍可飞往固定的村门查探点；空中只能确认视线范围内的真实敌人，不能凭旧坐标在空中施法。抵达后无真实敌人则结束支援，不虚构战斗。

## 动画、特效与提示

新增主体18帧：起飞6帧、巡航6帧循环、降落6帧；正面、侧面、背面分别绘制，左右统一镜像，共54方向帧。全套与现有92显示尺寸、脚底锚点和认可原画对齐。

- 起飞：听铃抬头、抱圆收风、软鞋离地，青绿风环往上托起。
- 巡航：小手自然张开、披肩向后飘、腿轻收，星点尾迹沿实际航线生成；每条尾迹寿命有限。
- 降落：风环扩大减速、软鞋轻点地、抬手护风，随后切入正式护人或攻击动作。

声音是一次风铃回应、起飞短风声、沿镜头距离衰减的掠空声、落地柔和风息。沿用当前音频总线与静音／暂停，不每帧重新播放。小地图和世界地图标出“小宝·飞援中”及实际位置；预计到场时间来自剩余航程与起降阶段。界面图标与状态使用正常文档流。

飞援固定预览检查起降、四方向／镜像、投影根、主体升高、尾迹与暂停逐帧。正式场景分别观察广场到三门，以及野外到村庄；保留不同镜头下越屋顶／树冠／水面和安全落地截图。

## 时间、保存与已有系统接入

飞援放进World正式有效时间片，而非帧尾另跑一个时钟。位移用该时间片的实际增量推进，不能以每渲染帧固定步长飞行。起降边界与落印事件在大帧中也按时间顺序处理，一次落地只发生一次保护。

重大警报取居民系统中的正式危急原因与防御系统的观察／攻击信息。无论主角进屋还是远行，守村与危急飞援仍在室外空间推进；表现随玩家空间和镜头可见性隐藏。主角菜单、失焦、状态提交和标题页面冻结有效时间。

未来结构8小宝字段需要一并保存：危急回援偏好、重大警报周期／已响应前线、临时支援上下文、飞援冷却剩余值、稳定飞援序号、起点、当前投影位置、主／备用落点、已走／剩余航程、飞行阶段和剩余阶段时间、是否已释放落印。只读档恢复剩余阶段，不重新起飞、不重放护印。

加载正在巡航的存档时按空中状态恢复，不能先用地面纠错把飞越屋顶／水面的投影根挤到别处。加载已降落状态才走地面站位校验。非法空间、超过世界边界的坐标、超限航程或未知阶段必须拒绝，保留上一份有效存档。

新开局、返回标题与World销毁清除旧航线、尾迹与音频；旧飞援回调不能操作新会话。主角复生或明确场景转移改变归队对象时，已经离地的小宝从当前位置改往对应安全地面，不能在屋顶投影位置直接切成地面人物。

飞行、待降或待执行危急救援计入住宿安全门禁，待飞援结束并确认前线安全后才可睡觉。住宿跳时不推进飞行、冷却或保护效果，也不写战斗胜利回报。

## 验收与反证

验证样本至少包含：广场飞援三门；最远室外位置飞援；当前真实破防与门级失守；村民／设施有效攻击；普通一级、调试警报与历史警报反例；低真气、调息、冷却；主角危急与回援关闭；多门优先级；起飞前／巡航中警报解除；主落点被占用；飞越水面和屋顶；中途改道；升空、巡航、降落、护印后四处保存读档；暂停／失焦／室内推进；主角复生与标题重开。

硬指标：同一前线仅一个支援实体，零非法落地、零重复护印、零地面投影假命中，飞援冷却连续；真实敌人和原任务进度无伪造。分别记录正式警报到响应、到离地、到落地的有效模拟耗时与真实墙钟耗时。广场到三门的村内1–2秒目标需实测，不能由公式代替验收。

VERDICT: PASS

P0/P1 BLOCKERS: 无，结论针对设计。已反证地面碰撞误用于空中航程、地面投影受击、暂停偷跑、空中读档被地面修复、落印重放、警报重复派遣、守村边界拒绝跨门与随行任务丢失，并在上述状态／空间／保存约束中明确处理。

UNVERIFIED RISKS: 真实到场速度、重大警报覆盖、落点选择成功率、飞行美术、设备帧率和音频听感尚未实测。

NON-BLOCKING FINDINGS: 一般警戒仍用地面巡护；冷却和护风调息可能延后支援，须在界面如实显示。飞行不等于能保证所有村民零受伤。
