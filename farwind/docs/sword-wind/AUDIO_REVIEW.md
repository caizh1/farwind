# 一线斩风呼啸制作与验收

## 本次声音

离刃声替换为原创、双声道的四百六十毫秒风呼啸。低频风压提供起势，带噪声的共振风体先卷起再滑落，短刃缘气流强调释放瞬间，尾部快速收窄消隐。没有采用第三方录音或新增依赖。

原释放声约一百四十毫秒，主要是一层扫频噪声。本次不是简单加大原声：主风腔约从八百赫兹卷到一千四百赫兹，再下降至三百三十赫兹，另有较淡的上层共振与气流。持续时间覆盖剑风飞行及短尾，不增加命中确认。引剑、命中、自然消散仍使用原独立事件。

游戏初始化音频时按实际采样率生成并缓存一次；离刃帧只启动缓存声源，不发起网络下载或解码。走已有战斗总线、压缩器及总音量，不绕过静音与弹反总线控制。新增声源最多保留两个，结束后断开连接；暂停、失焦、标题及会话清理截停声音，恢复不会补播。音量设为零立即停止在播呼啸，后续释放不创建静音声源。

本次只修改声音与声音生命周期。第四击的模拟释放时刻、连段、伤害、首目标终止、技能和存档规则沿用当前工作区；没有新增命中回调或碰撞，不更改角色动作和地面切痕。
