# 行囊书册背景资产

## 生成方式

使用内置图像生成工具，以已选中的方案一设计稿作为材质与构图参考，独立生成无文字、无物品、无控件的展开双页书册背景。没有编辑游戏源码、运行浏览器或部署。

## 提示词

用途：Farwind 游戏行囊界面的独立书册背景位图。参考图只用于书册材质和整体画风，不复制其 UI 内容。
请把参考中的展开双页旅行册提取为干净的独立背景资产，横向画布 1600×1000。俯视正面展开书册，书册尽量占满画布，四周只留极窄透明边距。暖象牙色羊皮纸双页，纸质轻微自然纹理，棕色皮革封边，少量绿叶与小花装饰仅在角落、纸面之外，不遮挡正文区域。左页宽约 62%，右页宽约 38%，纵向书脊中心严格落在整个画布横向 62% 位置，使左侧适合物品网格、右侧适合详情与配药面板。书页展开平整，中心只保留自然细书脊与浅阴影，不能有强烈透视。
全部内部留白，只有纸张纹理。彻底删除所有文字、字母、数字、罗盘、挂件、物品、图标、格子、标签、分隔线、按钮、材料、药瓶和界面控制，禁止水印。不要村庄、地板、桌面或其他背景。书册轮廓外必须是真正透明的 alpha 背景，不能是棋盘格图片，不要灰色背景，不要不透明阴影。保持参考图暖色手绘游戏美术、精致皮革与羊皮纸质感，供 HTML 动态内容置于其上。

## 交付与校验

- 生成原图：`bag-book.png`，尺寸 1586 × 992，保留工具输出原始像素。
- 游戏资产：`../../../public/assets/bag/bag-book.webp`，尺寸 1600 × 1000，通过标准图像转换与微小尺寸统一生成，没有重绘。
- 书脊约在横向 62% 位置，左右页内部完全留白。
- 两份资产均有真正的透明通道。游戏资产透明度范围为 0 至 255，四角透明度均为 0。
- 视觉检查已确认羊皮纸、皮革封边与角落绿叶，纸面没有文字、图标、格子、按钮、物品或村庄背景。
