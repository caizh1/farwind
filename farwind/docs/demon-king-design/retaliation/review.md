# 据点陷落后的魔王报复

每处据点首次完整清剿后，独立派出一波十只精英裂枝镰灵，从地图边缘沿现有道路向村庄行军。第一波一阶，第二波二阶，第三、第四波继续升阶；每只生命依次为九十四、一百一十五、一百三十七、一百五十八，原始攻击伤害依次为二十二、二十六、三十、三十四。普通史莱姆为四十八生命、十伤害。镰灵使用既有外观、精英阶数标签及每秒九十五像素的物种移动速度。

旧方案仅将数量改为十只，仍要求恶意达到十才加入精英；当前四处据点无法达到这个门槛，因此前两波都成了史莱姆。新版在派遣时保存独立报复阶数，按已处理据点数量加一确定，而非按当前恶意快照决定。连续清完四处后排队的部队仍为一、二、三、四阶。已有袭击时依次接续，不覆盖或临时升级在途部队。优先选择据点所在方向；西门未开放或边缘站位不安全时使用其它开放方向。报复不依赖首夜、夜间时段、常规冷却或守卫健康；仍有三秒预警和保存确认，并在暂停界面关闭后推进。

报复预警先保存再出生。预警被玩家近身、视口或活体占位阻止时保留同一事件，重新寻找安全边缘站位；新站位需保存确认后才出生。记录与行军位置随存档保存，每个据点仅派遣一次。旧档迁移只给历史清剿补基线，不回放更新前的报复；新增清剿仍会触发。缺少新版报复阶数字段的旧在途史莱姆保留类型、伤亡及生命，不因更新换怪或补血；之后新触发的报复按当前据点顺序升阶。恶意值仍直接取自永久清剿事实。

总攻结束后继续常规夜间骚扰：恶意零至四时，单夜计划概率依次为百分之五十、六十、七十、八十、九十。单夜至多一次，首夜保持安静，实际出兵仍受原有冷却、防线健康、岗位和生成门禁约束。因此计划概率不等于不受条件限制的实际袭击频率。

## 验证

- 十九项新版报复专项通过，覆盖首波十名一阶镰灵、第二波十名更强的二阶镰灵、连续四处依次升阶、在途强度冻结、旧史莱姆预警与行军存档兼容、错误阶数和类型拒绝、实际攻击伤害与护甲扣减、血条及保存恢复一致性。原有完整清剿、事务失败、去重、边缘门禁、四方向行军与后续夜袭验证继续通过。
- 本轮另有三十一项魔王、八项四门来袭、五项村庄集成回归通过；共六十三项相关用例。针对首波升级要求先运行失败样本，确认旧实现没有报复阶数且全员为史莱姆，再修复。新增伤害测试曾因第二波使用备用东门、测试仍选南门守卫而失败，改为根据实际派遣门选择守卫后通过。

- 应用内浏览器在本轮生产构建端口五二七八，通过正式导入两个固定存档，实际触发首波十只一阶镰灵、九十四生命、二十二伤害及第二波十只二阶镰灵、一百一十五生命、二十六伤害的出兵提示。旅途手记确认第二波在途快照及递增规则，图片为同目录的 elite-journal.jpg。固定样本用于验证正式导入与世界触发，不代表从新游戏实际清剿首领。
