# 风赐主角使用示例

日期：2026年10月3日。

旧预览仅在空地中央循环绘制材质，没有主角、目标、使用条件或命中过程。本次将获取风赐后的预览改为主角教学演示。

## 已实现

- 复用正式主角的近战、终结、剑风、架剑、受击与移动图集；伙伴示例使用小宝图集。
- 61种风赐与18组共鸣均定义使用条件、操作顺序、作用对象和结果。第三次、第四次剑风，弹反后反击，终结后剑风，伙伴接力等按对应规则展示。
- 命中后目标受击；回血与回力改变对应状态条；普通敌人被黑洞牵引；护伴护盾显示在小宝身上；闪链复用正式电弧绘制器。
- 条件与操作顺序持续显示。动画支持暂停、继续、重播和时间拖动；减少动态效果时先显示静态结果。
- 已持有风赐按真实等级显示效果文字。选择保存成功后自动展开所选风赐示例。
- 复用界面预览清理入口，折叠、后台、暂停时停止绘制，界面重绘或关闭时释放循环与监听。
