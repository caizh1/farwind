# 旅途锻炼实现与验收

日期：2026-10-01。

## 实现范围

正常奔跑的碰撞后真实位移按每米32个世界坐标单位累计。体力第n次增益的累计门槛为 `500n + 25n(n-1)/2` 米；生命为 `1000n + 50n(n-1)/2` 米。两项独立读取同一里程，每次永久增加1点，均封顶200。里程最多记录347,500米。

`playerVitals(state)` 是两项上限的统一入口。成长由存档里程推导，不保存或重复发放成长等级，不补当前生命和体力。正常移动结束后立即采集，随后攻击、击退、风步和归风等位移不会混入。暂停和失焦处理继续使用现有输入与时间线暂停机制。

奔跑控制、普通及精准弹反、消耗品、泉水、旅馆休息、住宿、归风珠死亡复活和符文恢复均已接入动态上限。固定回复量保持；凰心百分比回复按成长上限计算。HUD数字、比例、无障碍上限和当前值同步，按Q打开手记可查看累计里程、永久加成和下一次成长剩余米数。

跨门槛时显示不打断操作的提示，并使用原有帧末保存队列。失败不回滚内存成长，不删除旧有效存档，保留现有失败提示和导出备份入口。

旅途迁移为18→19，旧档从零里程开始。共享工作树同期接入了小黑系统的19→20迁移，因此当前最终结构为20；没有回退或覆盖同期功能。另有专项验证19版成长存档迁移后里程、上限及当前值保持。

## 验证结果

类型检查和生产构建通过。成长专项21项及移动、弹反、符文、经济、泉水、昼夜、基础状态和装备相关188项回归通过，合计209项。

成长逻辑覆盖两项各100个门槛前后、余量继承、一次跨多个门槛、独立成长、封顶、不补当前值，以及5公里对应生命104／体力108。距离验证覆盖30／60／120帧、正交与斜向、鞋子加速、碰撞阻挡、非奔跑和异常位移。恢复验证覆盖大于100的固定回复、百分比回复、满值拒绝、体力耗尽恢复门槛和弹反返还。

正式浏览器使用生产构建，以下场景分开记录，不以成长样本代替自然奔跑：

## 全量回归的限制

曾执行默认全量回归，65个文件、1284项中1272项通过、12项失败，不能宣称全量通过。执行期间共享工作树的小黑系统正在接入，部分测试工作进程混用了新增调用和旧初始状态，出现缺失 `catBond`；最新209项相关回归中此问题已消失。

独立复核仍存在的非旅途问题：据点首领两项测试使用总活体数量断言，当前附近遭遇也会生成，分别得到6和4而非预期1；对白立绘测试的模拟世界没有新增的 `catRemember` 方法，正式World存在该方法。居民五日长测曾超过60秒测试时限，未完成再次验证。以上未擅自修改，不作为本次旅途功能的通过证据。

## 风险审查

VERDICT: PASS

P0/P1 BLOCKERS:

无。审查本次成长规则、权威状态和迁移、距离采集在战斗时间线中的位置、恢复调用链、保存队列与失败、会话重置和显示链后，未发现证据成立的P0或P1阻塞问题。

反证检查包括：成长不会扣除共用里程或重复奖励；旧档不会根据当前生命伪造里程；采集在自主移动后且在攻击／击退／传送前；上限提高不会把当前值压回100；自动保存完成仅确认快照，不把旧副本覆盖到运行世界；保存失败保持内存并保留上次有效写入。每项均有当前调用路径或专项验证支持。

UNVERIFIED RISKS:

- 真实后台切页尚未取得可信证据：自动化浏览器持续仿真页面焦点；尝试原生Chrome时窗口捕捉接口报捕捉失败。失焦事件回归不能替代此项。
- 未自然跑满173.75／347.5公里；练满数值通过全部整数门槛和正式存档边界样本验证。
- 未做长时间连续试玩或目标设备性能验收。
- 全量首领数量断言、对白模拟环境和居民长测仍需各自任务闭环。

NON-BLOCKING FINDINGS:

- 构建保留现有大包体提示；未作为成长机制的性能验证或阻塞问题。
- 地图中近距离禁止突然刷敌的保护使最初复活站位无法触发攻击。已根据只读追踪确认实际敌人，再用真实步行进入警戒范围；没有修改游戏运行状态来制造复活结果。
- 自动化首次加载需要等待Phaser初始化，导入需要接受真实确认，暂停菜单的空格可激活继续按钮。这些测试场景问题已修正，失败追踪保留在 `.journey-training-local/initial-browser-evidence/`，未无理由重复执行。
