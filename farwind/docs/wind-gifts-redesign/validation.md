# 风赐改版验收

已实现深青暖金奖励卡、十二种矢量徽记、获得后总收益和持续成长预览。图标采用正常文档流中的网格或弹性布局。

## 本次规则

- 风甲每级减少百分之一的战斗伤害，独立乘算，护盾按减伤后的伤害吸收。等级继续累加，伤害最低为零，不产生负伤害或回血。
- 普通、完美弹反均使下一次近战每级增伤百分之二十，同时释放一道扇形剑气；剑气每级造成百分之四十的基础普通攻击伤害，范围为一百八十、夹角一百二十度。
- 剑风不消耗回锋；同一强化近战命中多个目标均增伤，但剑气仅释放一次。训练投影不会授予回锋，剑气不会递归触发原生命中效果。死亡或场景清理会清除临时蓄势。
- 持有种类与等级不再设游戏上限，不需要替换旧风赐。重复选择累加一级，其他待领候选保持不变。原有一、二级存档保留对应等级。
- 持续增伤不再被原有百分之六十或一万伤害检查静默截断。体力消耗最低为零，避免高等级减耗反向恢复体力。仅保留存档数字精度与合法性校验。

## 验证结果

- 类型检查和生产构建通过；构建仍有既有的大包体提示。
- 七个相关测试文件共二百九十项通过，覆盖风赐、战斗二版、符文、近战、弹反、营地首领和小宝战斗。其中新增八项风赐专项，验证一千次连续领取、超过六种与二级、存档回读、保存失败不发布、百分比减伤、减耗零边界、高伤害及回锋快照、几何和重复释放。
- 五项浏览器专项通过：三项界面与持久化测试，以及普通、完美弹反各一项正式世界集成测试。
- 界面测试通过独立浏览器从手记入口操作领取、升级、保存与刷新读档。七种十二级的样本可把风甲升级到十三级，并可新增第八种，不需替换。样本属于固定验收数据，不代表通过战斗取得这些奖励；用户浏览器存档未被导入或改写。
- 已检查六种窗口：1440×900、1075×600、768×600、640×720、390×844、320×640。无横向溢出，低窗口三项接受按钮可见，窄屏单列并允许面板滚动。
- 回锋集成验证导入已发现但未击败的林豕遭遇，使用真实键盘输入与正式攻击、接触、伤害链路。只读预警时间辅助精确起按；敌人生命、攻击时钟与判定结果未被修改。普通弹反近战伤害二十八点八、完美弹反三十六，剑气均为七点二且仅命中一次。运行截图已检查，可见前方扇形金色剑气。
- 首次回锋集成测试未生成敌人，证据指向未发现遭遇的近距离刷新保护；修正固定样本为已发现的合法遭遇后通过。未改动正式刷新逻辑。
