# 远风之地开发文档阅读入口

本目录集中记录游戏已开发内容、机制、具体数据和开发状态。后续了解当前游戏时，直接读取本目录。

## 阅读顺序

1. [已开发内容与机制总览](DEVELOPED-CONTENT.md)：按25类了解玩法入口、前置条件、运行规则、成长、伙伴、世界、界面、存档、验证边界及未完成事项。
2. [游戏内容完整目录](CONTENT-CATALOG.md)：查询物品、商店价格库存、全部符文与共鸣、成长分支、敌人、首领、固定遭遇、建筑、地图兴趣点及小宝技能数值。

## 状态与维护方式

文档核对日期、源码基线和进行中的开发，以总览开头为准。已实现、历史专项验证、开发中和未验证分别记录；文档不能替代最新源码与实际游戏验收。

后续功能完成时，更新总览对应章节、目录对应数据以及总览末尾的变更记录与追踪清单。历史截图、录像与专项报告继续保留在上级 `docs` 目录各专题中，由本文档链接引用。
