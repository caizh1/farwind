# 专用风铃素材生成说明

使用内置图像生成工具。生成一张横向三列部件图：木架、带悬绳与铃舌的铜铃、青绿捕风飘带。三层分开制作摆动，木架固定在地面；受风时铃体和飘带各自响应。

视觉约束：温暖日系手绘、约四十五度俯视、深棕轮廓、古铜钟身、青绿布条；背景为纯洋红，部件完整且彼此分离，无文字、数字、背景场景与石碑造型。

素材验收：缩小后仍可辨认为铜钟；悬挂点固定、底座不漂移；正常摆动、受风强摆与鸣响有不同反馈。设计图片与运行截图分开记录。

## 实际生成提示词

用途：远风之地游戏专用手绘风铃素材图集，供真实游戏拆分为独立层并制作摆动动画。画布横向1536×1024，三列等宽区域，每列只放一个独立部件，所有部件完整、居中、有足够留白，区域之间不能相接。第一列：一座小巧的木制风铃架，两根温暖棕色木柱与一根弯曲横梁，有麻绳绑扎和少量浅绿苔藓，架子中央与下方空着，不能有铃或飘带，地面底座低矮，不是石碑。第二列：一枚清楚可识别的古铜风铃，顶部细绳、圆润中空的小铜钟、可见铃舌，铜色与少量青绿纹饰，竖直静止姿态，部件轮廓完整，不带木架、不带飘带。第三列：一条青绿色捕风飘带，顶端细绳、窄长柔软布条、轻微弯曲，部件轮廓完整，不带铜钟、不带木架。风格：俯视约45度的温暖日系手绘冒险游戏，粗细有变化的深棕轮廓、柔和水彩笔触和精细高光，与明亮草地、石板小路、圆润树冠的场景相匹配。不是写实照片，不是像素风，不是UI图标，禁止任何文字、数字、符号、边框、背景场景、阴影或多余物件。所有背景必须为纯平统一#ff00ff，以便拆分和去除背景。请使铜钟在游戏缩小到40像素后仍一眼识别为风铃，不得画成符石、水晶、石碑、矿石或魔法方尖碑。
