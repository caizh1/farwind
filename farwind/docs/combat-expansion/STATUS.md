# 村庄周边战斗扩充实施记录

日期：2026-10-01。当前交付是南线首批机制，代码与素材已接入正式工作树；整个扩充计划尚未全部完成。未新增地图，未提交、推送或部署。

## 已落地的游戏内容

| 内容 | 玩家实际需要作出的选择 |
| --- | --- |
| 菌铃祭司 | 优先打断举铃，或先杀施法者；一次保护一个普通同伴，不保护首领、不叠加，无接触伤害 |
| 爆囊滚兽 | 观察锁向，避开滚动后的一秒膨胀；重击可打断，击退改变实际爆点，也可诱爆附近敌人与菌障 |
| 普通孢卫 | 在单发瞄准与较长前摇的三向射击之间变化；锁向后的弹道固定 |
| 南线混合遭遇 | 芦苇桥加入远程孢卫，药草洼地与巢地加入祭司，果园加入滚兽；合计四名新增遭遇成员，复用原有地点 |
| 孢心巢母第二阶段 | 两处可攻击祭根连接核心，拆根逐步削弱护心，全部拆除后出现反击窗口；普通攻击可处理，不要求特定符文 |
| 洼地净根 | 拆除固定菌根恢复两处药草采集，回村领取谢礼 |
| 果园清障 | 诱导滚兽爆炸或直接攻击拆除菌障，恢复对应采集点，回村领取谢礼 |
| 委托与存档 | 公共委托簿和药师均有事件说明与领取入口；每处谢礼为铜币十二、药剂一，保存成功后才发布领取结果 |

为混战增加了出手预算：附近普通敌人最多同时两个伤害前摇，其中最多一个重击或冲撞，以及一个辅助施法；荒野存活上限十二，首领地面危险最多三个。滚兽爆炸走真实爆点、视线与各角色伤害链，能伤及玩家、小宝、卫兵、平民和附近敌人；敌人互伤不会反复产生资源掉落。

祭司、滚兽与菌根有独立图集，已检查固定动作、朝向、透明边缘和正式实战。护盾连线、膨胀范围、祭根连接和可攻击标签均在实际场景显示。素材仍保留临时标记，主观美术和声音尚未验收。伤害飘字取整显示，伤害计算保留原精度。

## 验收边界与后续顺序

已验证的是机制和带小宝的正常南线闭环，不是整体平衡完成。单人正常通关、六名玩家盲测、目标设备性能、六十分钟混战、最终美术和听感仍未验证。实战中观察到首领四种招式，并发生成功弹反；单次通关时间和帧间隔不能代替难度与设备验收。

下一阶段按 [总计划](PLAN.md) 继续西北路线：狼群夹击与召唤约束、风针锁向、林豕撞墙，以及狼王和獠王机制。随后才是东线与已有遗迹的首领内容，最后处理隐藏首领、再战、袭村组合与长期平衡。其余两种新小怪、新精英和两个首领目前均未实现。
