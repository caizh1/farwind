# 村庄周边战斗扩充执行计划

目标是在现有风铃村和周边空间中，让玩家需要识别敌人、选择目标、打断、诱导和反击。参考《哈迪斯》的敌人分工与招式承诺，不新增地图，不以单纯提高血量代替战斗机制。

2026-10-01 实施进度：南线首批机制已接入当前工作树；新敌人与事件、巢母祭根和正常旅途闭环见 [实施记录](STATUS.md)。其他阶段尚未实现，整份计划仍在进行中。

## 内容预算

保留并深化八种原有小怪，加入菌铃祭司、爆囊滚兽、风针弩灵、唤巢铃妖，共十二种。升级三个既有精英并加入断钟双卫。深化四处据点首领，再在已有遗迹风核和北部望台加入章节首领及可选隐藏首领。现有三十一组遭遇使用十五种组合模板，六个已有兴趣点承担战斗事件。

## 南线机制规格

菌铃祭司只能保护一名附近普通敌人，显示连线；不保护首领、不叠加。举铃施法可被攻击打断，祭司死亡、离开范围或施法失效立即解除保护。祭司没有接触伤害。

爆囊滚兽先锁定滚动方向，再停止膨胀；爆炸预警至少八百毫秒。爆炸能波及附近敌人，也能被重击打断。击退改变实际爆点，命中与预警使用相同几何。爆炸不制造敌对阵营互相攻击的无限掉落循环。

巢母第二阶段出现两处可攻击祭根，祭根连接核心并增加保护。拆根提供明确反击窗口，普通攻击也能处理祭根；没有强制特定符文。祭根属于本次首领战，死亡、离场重置和读档必须一致处理。

普通敌人最多同时两次伤害前摇，其中最多一次冲撞或重击，最多一个辅助施法。荒野同时存活上限十二，地面危险有数量上限与通行空间。职业分工与出手预算覆盖相邻遭遇追击形成的混战。

## 存档与交付边界

成员以稳定身份迁移。旧档已激活的批次保留伤势、掉落和结算，不把新成员突然加入进行中的战斗；未激活批次及后续合法重生使用新组合。历史已清据点继续保持已清状态。保留原有主线、符文、村庄生活及夜袭进度。

当前执行以正式工作树为交付对象，不提交、不推送、不部署。设计图通过工程检查仍不等于玩家美术验收；专项测试、真实流程、长期性能和外部盲测分别记录，不以测试状态修改冒充真实通关。

六名玩家盲测与目标设备长期性能验收需要真实参与；缺少参与或测量时明确标记未验证。每阶段回归、负向检查与审查结果在验收记录中列明。
