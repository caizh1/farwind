# 木匣签页委托簿实现记录

日期：2026年9月28日。依据为用户选中的第2张 `commission-folio.png`。

## 实现范围

广场简笔书架换成手绘木匣，保留原交互位置。页面使用木框旧纸、墨绿签页和南路插画，按委托人、目标、路线、启程补给和完成奖励阅读。村庄委托含南路补给与西侧旧道，旅途手记保留主线、木匠支线和技艺记录。

文字和状态由真实 HTML 控件承载，图标与按钮使用正常 flex/grid 文档流；材质由真实位图和九宫格承载。正文内部滚动，关闭和办理操作固定在底部布局行，未使用图标绝对定位。

办理复用 `southQuestSnapshot`、`westRoadSnapshot`、`StateCommit`、`save` 与 `World.publishState`。保存时禁用页面按钮，并使用共用锁阻止关闭与世界写入；保存成功才发布新状态，失败展示错误并解除锁。不新增存档字段。
