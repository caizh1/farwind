# 主角受击反馈实现与验证

## 实现

- 真实伤害应用后启动专用受击状态；三方向各三帧，左向仅由角色系统镜像。
- 硬直为模拟时间 220 毫秒。前 110 毫秒沿来袭方向衰减击退，空地累计 14 像素；复用正式碰撞扫掠，受阻位移不积蓄。
- 硬直期间停止自主移动，丢弃攻击、弹反和风步请求，清掉旧预约；恢复后新输入正常生效。
- 前 120 毫秒绘制固定在命中位置的局部接触核心与方向射线。受击动作期间角色不透明，结束后继续原有保护闪烁。
- 伤害、护甲计算、850 毫秒受击保护、风步保护窗口和原有受击音效保持原值。死亡、读档、新游戏及场景清理重置临时状态；不修改存档格式。

## 验证结果

相关逻辑检查共 **271 项通过**，覆盖受击、普通战斗、弹反、反馈、移动、敌人及剑风。命令：

```sh
npx vitest run tests/player-hurt.test.ts tests/combat.test.ts tests/parry.test.ts tests/parry-v2.test.ts tests/parry-feedback-v3.test.ts tests/motion.test.ts tests/enemy-combat-v1.test.ts tests/sword-wind.test.ts
```

新增受击检查为七项，包含正式地图树干和世界边缘碰撞、30／60／120 帧率与长帧、操作门禁、重置、帧选择及透明素材。类型检查、构建和变更空白检查通过。构建仍有现有主包大于 500 千字节的提示。

浏览器在实际开发服务 `127.0.0.1:5173`、原生图形后端、单工作进程下检查。使用导入入口设置明确标识的起始存档，攻击、接触、伤害和操作均走正式链路；不修改运行中的位置、生命或计时器。八个场景在针对性执行中均通过：

| 场景 | 结果与证据 |
| --- | --- |
| 固定预览四方向 | 三阶段脚底根一致；左向由角色系统镜像；四张固定预览截图 |
| 四方向真实接触 | 生命 100→90；三帧均实际呈现；角色透明度为 1；击退约 14 像素；220 毫秒后恢复 |
| 输入与暂停 | 受击中三种出招输入被丢弃；暂停 300 毫秒后模拟时间、位置和生命不变；恢复无延迟出招 |
| 弹反与风步 | 精准弹反和风步保护期真实接触均无伤害、无受击状态 |
| 致死与读档 | 回城后生命恢复 100、临时受击状态清除；随后读档仍为空 |
| 多敌人 | 首次受伤，后一次接触免疫；生命保持 90；硬直和保护时长未延长 |
| 孢子投射物 | 真实孢子接触，生命 100→86；同一受击动作和约 14 像素击退 |
| 会话重置 | 存活受击中返回标题；继续旅途、新游戏均清除受击状态 |
