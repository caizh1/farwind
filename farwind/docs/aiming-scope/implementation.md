## 正常使用

1. 新游戏出发资金仍为120金币。在溪石铁匠铺的装备分类，选择寻风瞄准镜，确认支付80金币，物品进入行囊，剩40金币。
2. 按 Tab → 装备 → 头部 → 穿戴。购买不等于穿戴；未学剑风时界面显示“尚未学会剑风”，不会因买装备授予本领。
3. 在村庄周边原有第一阶教本开始限定试用，使用中键手动剑风击中风铃，正式学会剑风。已有剑风存档无需重学。
4. 接近怪物，按住 I：瞄准镜选取当前射程内无遮挡目标，按原节奏连续施放。松开停止。主角无需先面向怪物。
5. 鼠标中键始终手动施放，可继续处理风铃和机关。不穿戴镜子时，I 仍是原有手动剑风。

装备页按“武器 → 头部 → 护甲 → 宝珠”排列，肖像显示已佩戴镜子。头部只能在安全村庄、脱战8秒、没有在途原生或派生攻击时更换；复用既有锁定规则与保存后发布交易事务，不通过换装清冷却。图标和状态文字保持正常布局流，390像素窄屏实测没有横向溢出。

## 参数与触发限制

| 项目 | 当前规则 |
| --- | --- |
| 商品／装备位置 | `windScope`，溪石铁匠铺，80金币，头部 |
| 唯一持有 | 行囊和已穿戴合计最多1件；买多件、重复购买与出售均拒绝 |
| 装备前提 | 永久剑风正式学会后生效；不改变学习阶段 |
| 施放节奏 | 原动作110毫秒起势＋100毫秒有效段＋190毫秒恢复；命中停顿沿用战斗时钟 |
| 射程与宽度 | 一至三阶300／28，四至五阶420／64；使用真实出手锚点与目标碰撞边缘，未提前授予阶段 |
| 瞄准查询 | 原生剑风动作正式开始时选一次，快点按I也保留本次输入来源 |
| 目标选择 | 活着、可受伤的真实怪物，排除教学目标、机关与祭根；最近合法目标，同距按编号稳定排序 |
| 保持与换锁 | 持续输入优先保持合法目标；死亡、超距或遮挡后，下次施放换锁；松开／暂停／死亡／读档清瞬时引用 |
| 障碍 | 与正式剑风共用扫掠规则，从地面根完整检查出手路径，不跳过贴身薄墙 |
| 无目标 | 当前朝向手动剑风，界面说明；不自动移动、不追敌、不预判 |
| 分束与回返 | 五阶仍是中心束瞄准、两侧±30°；原生来源及共享去重沿用，回风分支不被镜子改写 |
| 普通／精英／首领 | 一次正式死亡3／8／35金币，三类互斥，不叠加 |
| 奖励归因 | 玩家或跟随小宝造成有效伤害后，守卫补刀也奖励；纯守卫防守无奖励 |
| 钱包 | 既有 `coins`，上限1000000；满包仍能得金币，上限只收可容纳部分，无待领队列 |
| 其它收入与支出 | 原任务、材料出售、药剂、铁剑、护甲、休息和住宿原价保持；只统一“金币”显示 |

按住施放只有一个预约，键盘重复事件不追加动作。中键请求明确手动；受击、架剑、风步、暂停与失焦沿用原动作清理。镜子不修改飞出剑风的方向，不把反击或符文派生重新视为原生剑风，关闭反馈特效不影响选择器。

金币只接入已通过死亡幂等门禁的分支：遭遇成员的死亡标记和余额在同一状态快照内更新；夜袭先同步死亡成员，再回调一次金币结算。参与标记持久化，读档不会重复发奖；原巡游合法新周期可再次结算，新周期仍由原规则管理。原有材料掉落途径保留。
