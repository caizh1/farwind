# 寻风瞄准镜与金币机制设计

日期：2026年10月1日。本文件保留实现前确认的设计与当时基线；文中的“拟”“后续”属于历史设计描述。现已接入正式商店、装备、自动瞄准、金币与存档，当前交付状态、运行证据和限制见 [实现与验收记录](implementation.md)。

## 当前工程基线

当前分支为 `codex/initial-game`，开始时工作区干净。现有永久剑风已使用 I／鼠标中键，支持按住按战斗节奏连续施放；剑风一至三阶射程300，四至五阶420，均有实际障碍判定。

`src/data/economy.ts` 已定义唯一货币钱包：新档120铜币，上限1000000；铁剑60、皮甲45、恢复药剂18、休息12。材料出售木材2、石材2、药草3、浆果1。南路补给任务奖励24，南路事件谢礼12。常规敌人目前掉物品，不能把拟议金币掉落描述成已实现。

现有装备页只有武器、护甲、宝珠；归风珠是永久绑定的重生说明。购买、出售和换装已经有序列号、保存锁与“持久化成功后发布状态”的事务链，本设计复用它们。

## 装备外观与位置

[外观与佩戴位置概念板](concept.png)，[完整生成提示词](prompts.md)。已核对单目镜片、铜制翻折铰链、皮带、角色右眼佩戴位置及中文名称；概念画面不是正式游戏运行证据。

名称：寻风瞄准镜。品质：普通实用装备。物品标识拟为 `windScope`，栏位拟为 `head`，界面名称“头部”。

旧铜圆形单目镜框，浅青绿透光镜片，细铜刻度，深棕皮革额带与短翻折铰链，耳侧单叶铜饰。平时翻起贴在额头右侧；自动瞄准施放时翻下至角色右眼。它是一件村庄工匠可制作的光学器具，尺寸轻巧，保留旅人的棕发、面部和红围巾。参考既有归风珠的旧铜与青绿材质，不使用符文边框。

装备页按照“武器 → 头部 → 护甲 → 宝珠”排列，沿用左侧旅人画像、中间装备列表、右侧详情。头部未穿戴时显示“未佩戴头部装备”，不编造基础帽子。购买后进入行囊，在装备页明确穿戴；背包里拥有镜子并不生效。头部仅允许一件物理装备，不附带子孔、符文或额外加成，不改变五个符文槽。

图标、品阶、快捷键及状态文字均采用正常 flex／grid 文档流。桌面四行装备卡排列；窄屏纵向滚动。选中、未装备、已装备、未学剑风分别有明确文字，不能只用颜色表达。

正式说明：

> 寻风瞄准镜 · 头部
>
> 穿戴后，按住 I 自动瞄准射程内无遮挡的敌人，按现有节奏连续施放剑风。松开停止。
>
> 需要先学会剑风；不增加伤害、射程或施放速度。
>
> 风会指出方向，出手仍由你决定。

角色佩戴概念图不等于已完成角色所有战斗、风步、受击与镜像图集。正式接入时必须校验头部锚点、左右镜像及遮挡，不能用整张概念板替代动画资源。

## 商店与使用路线

在已有溪石铁匠铺“装备”分类销售，售价80金币，从新档即可购买；无需额外材料或任务门槛。只允许持有一件，已穿戴也计入持有数，防止重复购买；不出售换钱，允许永久卸下再装备。没有耗损、子弹、耐久或维护费。库存初始1，买后展示“已拥有”，不以每日补货绕过唯一持有。

正常路径：通过现有教学学习剑风 → 铁匠铺买镜 → 行囊／装备页穿戴到头部 → 离开菜单 → 接近敌人并按住 I。允许先购买、后学习；未学时展示“已装备 · 尚未学会剑风”，不因付钱授予本领。

鼠标中键保留现有手动朝向剑风，提供装备状态下仍可选择的手动方式。没有镜子时 I 继续手动施放。头部装备仅在安全村庄、脱战8秒且无在途原生／派生攻击时更换；换装不重置冷却、资源或符文状态。

## 自动瞄准边界

按一次 I 发起一次施放，按住按既有战斗时钟持续；不是永久开启开关。仅在每次原生剑风动作被正式接受时选择一个目标，锁定本次方向；飞出后不追踪、弯转或跟随目标。

候选必须同时满足：同一活动区域、存活、可受伤的敌对怪物；从真实剑风出手点到敌人身体碰撞点，在当前已学射程内；以当前剑风宽度执行与正式投射物相同的墙体／树木等障碍判定。村民、同伴、守卫、训练木桩、风铃与机关不自动锁定，教学与机关使用中键手动瞄准。

首次选择最近合法目标，距离相同以稳定敌人编号排序。按住期间优先保持原目标，除非死亡、越界、出射程或被障碍挡住；不每帧来回跳锁。目标离开后，在下一次合法施放时选择新目标。没有合法敌人时按角色当前朝向施放，提示“无可锁定目标 · 手动剑风”，保留基础攻击与机关能力。

自动瞄准不预测敌人未来位移，敌人仍可闪避；玩家负责接近、退让、遮挡与出手时机。五阶三束只有中心束瞄准，旁束保持既有±30°；回风只继承该原生动作方向，回返分支和留痕规则不受镜子改写。锁定框只用于呈现，关闭特效不改变目标选择。

受击、格挡、风步、死亡、失焦与阻断菜单沿用基础动作规则清理持续输入；暂停、命中停顿后不补发积压。出生、死亡、换区及读档清理瞬时目标引用。镜子不允许走位以外的自动寻路、自动追敌、免伤或穿墙。

## 金币循环

将现有“铜币”统一展示为“金币”，保留 `State.coins`，旧余额按1:1继承。只有一个钱包，不新增兑换货币；无改价、补发或重置。金币不占背包格，仍使用非负安全整数及1000000上限。金币界面图案建议旧金圆币加叶纹，与游戏材质一致。

| 收入来源 | 首版规则 | 防重复与边界 |
| --- | --- | --- |
| 出发资金 | 120，保持现有值 | 仅新档；导入、迁移不给第二份 |
| 普通怪物 | 每只3 | 正式死亡结算一次；木桩、教学和调试目标无金币 |
| 精英怪物 | 每只8 | 覆盖普通奖励，不叠加3 |
| 营地首领 | 每只35 | 覆盖普通／精英奖励；旧档已击杀不给补领 |
| 村庄任务 | 已有12／24奖励保持 | 沿用完成／领取记录；新一次性任务拟20–40 |
| 材料出售 | 保持木材2、石材2、药草3、浆果1 | 售价低于进价；结晶与任务物品不可出售 |

普通巡游实际刷新后可再得金币；保存、重载或离开区域不是新刷新。使用已有遭遇周期和敌人实例生成唯一结算键，不能无限保存每次击杀的大账本；只保留当前周期必要状态和已有一次性完成记录。

只在玩家或小宗师实际参与造成有效伤害的战斗奖励；若之后由守卫／塔补刀仍可结算，纯村庄自动防守不产生玩家金币。参与记录和死亡标记需在同一保存快照内持久化。金币结算只发生在正式死亡分支，不放入每次命中、回返、风痕或渲染回调。归因规则以这个设计为准，不直接照抄当前掉材料的 `source !== guard` 判断。

达到钱包上限时仅收可容纳部分，显示实际收入；超出的金币不存无限待领队列。金币收入不受背包满影响，原物品掉落照旧。死亡不扣金币，避免新手因失败失去基础配装能力。

| 支出 | 金币 | 定位 |
| --- | --- | --- |
| 寻风瞄准镜 | 80 | 一次性操控便利，手动剑风始终可玩 |
| 风杉铁剑／旅人皮甲 | 60／45 | 保持现有价格 |
| 恢复药剂 | 18 | 可购买，也可继续用材料制作 |
| 村庄符文 | 18／20／24 | 保留已有售价与五槽选择 |
| 旅馆休息与住宿 | 12／现有住宿价 | 保持现有安全与时间规则 |

出发120买镜后剩40，可买两瓶药剂剩4；买铁剑与皮甲后剩15，若再买镜需65：南路任务24＋一次谢礼12＋10只普通怪30＝66。两条路线都可达到，不要求先培养另一套构筑。这里是金额算例，未宣称实际路线耗时或全主线经济平衡通过。

目标：学会剑风后镜子能作为早期便利选项，常规探索有持续购买补给的收入；正常玩家不靠反复失败刷奖励、不靠挂机守卫、不靠传奇符文推进。用实际新档两条消费路线验证，不假定怪物刷新速度能支持某个金币／分钟数字。

## 接入与迁移约束

后续最小改动点：`content.ts` 添加物品名与图标；`economy.ts` 添加头部定义、价格与唯一持有校验；`state.ts` 版本迁移默认 `equipment.head = null`；装备页复用现有卡片与事务；原生剑风动作入口快照瞄准方向，复用 `swordWindGeometry.ts` 障碍规则；金币收入接正式死亡结算，避开具体符文名称分支。

旧档保留余额、装备、技能、任务与世界进度，不自动给镜；迁移可重复执行，不补历史怪物金币。采用现有原档备份机制，失败不覆盖唯一存档。购买、穿戴、读档与死亡奖励分别在同一权威状态链处理；保存失败不扣款、不发物品、不发布假余额。

## 验收与审查

设计完成标准：装备实物与佩戴概念可见，装备位置明确，货币规则与当前钱包兼容。实战实现仍须完成购买→穿戴→自动瞄准→存档重载的正常流程，当前不标记为可玩功能。

后续必验：不穿戴不生效；未学剑风不施放；最近目标与保持目标；障碍和范围；中键手动机关；三束／回返仍正确；暂停失焦不补发；满包与交易失败；卸下、死亡、换区、导入导出后状态一致；玩家／同伴参与但守卫补刀的奖励；重载同一死亡不重复发奖；怪物刷新仅发新实例奖励；上限与负余额拒绝。最终美术须固定预览和真实移动验证。
