# 小黑同行与默契机制

已接入正式世界、现有战斗、状态栏与存档流程。小宝继续承担护卫职责，小黑提供同行增益与协同反馈。素材沿用现有小黑图集，新增地面气息、寻物方向点、爪印与护盾。

| 默契 | 阶段 | 能力 |
| --- | --- | --- |
| 0 | 熟悉 | 灵猫同行：正常随行时体力恢复增加10%。 |
| 20 | 亲近 | 寻风嗅迹：提示附近可见、尚未发现的宝箱、任务线索与尚未采集的资源。 |
| 45 | 合拍 | 影爪共鸣：真实近战终结或完美格挡后，小黑扑近敌人，留下五秒印记；主角下一次命中该敌人的近战或剑风伤害增加15%。支援冷却十二秒。 |
| 75 | 信赖 | 护主灵息：受伤后仍存活且生命不超过上限30%，获得相当于生命上限16%的护盾，持续五秒，冷却六十秒。 |
| 100 | 心有灵犀 | 同行恢复提高到20%、嗅迹范围从240扩大到320世界单位、印记增伤提高到20%、护盾提高到生命上限22%。 |

四项能力依次累计开放，不占装备、符文槽。护盾随体魄的生命上限成长，按整数向上取整；先结算小宝的保护，再抵扣小黑护盾，最后结算主角符文的受伤反应。护盾不能复活主角，也不返还被截断的过量致命伤害。

小黑必须在主角附近且路线可通，短暂落后有1.6秒宽限。扑击仍走现有碰撞与自主位移路径，不穿墙、不瞬移；目标已经死亡时，真实终结可以改为支援附近可达的存活敌人。没有实际命中的印记不会消耗，其他敌人、小宝和符文衍生伤害不会消耗该印记。室内切换、归风、倒下与新会话清理旧目标和临时表现，冷却仍保留。

## 默契来源

- 探索新路段：小黑正常随行、主角在新的400单位分区内实际自主移动至少160单位，首次增加2点。重复同一区段不重复增加；传送、练习、室内和挂机不计入。
- 首次并肩击退正式敌人：普通敌人增加2点、精英4点、首领6点。卫兵独立击杀不计入，同一正式编号不重复增加。
- 共同发现宝箱增加3点，回应风石或读取古碑增加2点，临水夜风增加5点。
- 每个游戏日，摸猫增加2点，分享一份浆果增加3点，共同在旅馆休息增加2点，各一次。摸猫和喂食要求猫已跟上且附近安全；满默契不再为增长消耗浆果。

默契上限100。没有在线时长经验、死亡惩罚或离线衰减。正式世界的经历编号有界，不能通过反复清怪或反复传送无限积累。

## 操作与存档

点击状态栏“小黑”，或在暂停菜单打开“小黑 · 默契与能力”，查看已掌握能力、下一阶段、最近共同经历、支援状态，并进行摸猫和喂食。

摸猫和喂食沿用保存事务：先构建并校验副本，保存成功后才扣道具、发布默契及互动反馈。保存失败保留原状态，重复请求受事务锁与每日次数共同约束。

存档结构升级到第二十版。十九版补齐小黑状态，十八版同时补齐体魄与小黑；原有行囊、地图与任务保留。旧档仅根据明确记录的击退、宝箱、风石和夜风经历补默契，不根据在线时长推测。实际写入升级存档前，数据库保留一份迁移前备份，暂停菜单可导出。影爪和护主冷却、护盾剩余量及有效期随存档保留；离线不跳过冷却。
