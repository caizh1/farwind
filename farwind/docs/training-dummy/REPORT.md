## 实现与真实链路

1. 出生点仍为 `(670,720)`。训练根位于 `(850,650)`，广场东北侧草地边缘，出生镜头可以看见。四面训练通过键鼠绕行验证，未占用守风人交互、水井、房屋入口或草药。新增小块土色空地与目标名称。
2. `CombatController → inStrike → attack.hit → World.strikeTarget` 使用原判定、时序、方向、距离、遮挡和实例去重。两个 `combat.update` 都使用同一个 `combatTargets()` 入口。`Enemy | TrainingDummy` 明确分派；敌人死亡、击杀、掉落与任务路径仍由 `strikeEnemy` 专用处理。
3. 木桩物理占地为 `26×14`，沿用原玩家安全边距。共享射线接收具体目标 ID，仅豁免被攻击目标自身占地。玩家、黑猫和风步碰撞不传豁免 ID，不能穿底座；房屋、水体等原障碍照常阻挡攻击。
4. 训练目标正生命值 `1` 只表示可受击，代码不递减该值、不执行死亡。位置只读，摆动只作用于身体图层。没有敌人定义、追逐、攻击、经验、掉落、任务、背包或击杀写入。
5. 每轮第一刀产生新的运行期 `comboId`，第二／三刀继承；每实例只消费一个训练命中事件。统计从 `STRIKES` 读取实际伤害，仅实际命中的段进入集合。风步取消、受击、死亡、会话重置通过既有 `epoch` 清理，单击或断连不会拼成伪三连。
6. 同一命中入口触发一次现有停顿与受击音。空挥不触发训练反馈。普通暂停冻结模拟时间；原命中停顿同时冻结世界模拟，以未冻结帧时间扣减，不另建停顿账本。
7. 提示与统计面板使用正常 flex 文档流，不阻塞操作。距离小于185时显示提示；命中结果保留3000ms，末250ms淡出，暂停不推进。统计不写入存档。

## 素材与参数

- 内置 `image_gen` 实际生成了原创稻草人，源文件 `assets/dummy-source.png`；没有调用另一个付费服务，也没有使用敌人改名。来源是生成素材，不虚构外部许可或用户美术认可。
- 生成要求：透明背景、俯视三分之四手绘风、稻草头身与手臂、旧青绿色补丁布衣、棕色缝线胸靶、短木桩底座；无文字、武器或场景。保留生成源与中文元数据。
- `node tools/pack-training-dummy.mjs` 可重现分层：整幅90×114；身体90×94，地面根上移20；固定底座90×22，重叠2像素避免接缝。没有重切旧角色素材。
- 受击身体回弹330ms，轻击力度0.6、终结斩1；闪色90ms；稻草6／10片，450ms销毁表现；伤害数字850ms消退，最多6个实例。木桩根与逻辑伤害点不随表现移动。从北侧贴靶时，身体透明度降为0.45，让主角保持可辨认；固定底座不淡化。
- 草木声音复用既有音量与音频入口，短带通噪声配合下落三角波，轻／重包络不同。录屏旁路采集真实 AudioContext 输出，不替代主观听感验收。

## 首轮失败与修正

- 四向截图检查发现北侧贴靶后主体遮挡主角，增加与现有树木遮挡一致的身体淡化；修复前图 `down-occlusion-before.png` 保留，重新录制后对照。

- 新训练测试最初尝试从东侧横穿木桩；底座正确阻挡，改为北侧绕行。旧档夹具最初使用0 HP被原合法性校验拒绝，改为合法1 HP并让现有敌人执行死亡恢复。未放宽碰撞或存档校验。
- 旧黑猫房屋转角测试从 `(830,390)` 直走到 `(830,700)`，经过新增底座安全边距，正确停在约625.76。新增两个西侧绕行点 `(810,390)/(810,700)`；原位置精度、黑猫不入障碍、停稳与跟随距离断言均保留。
- 默认三工作进程首轮森林测试的8ms采样错过重击停顿起点，实际采到最大41.3467ms而原断言要求至少45。失败追踪记录叶灵72→54→34→4，正好18／20／30；58ms停顿在下一16.65ms帧后变为41.35ms。单工作进程仍复现相同采样相位问题，因而将只读探针改为逐呈现帧采样，保留至少45ms及双方冻结的全部原断言。未改游戏停顿逻辑。原始失败追踪与解码摘要保留，未以重跑覆盖首因。

- 修正采样后，默认三进程森林用例通过；同轮旧满包固定节奏脚本未击杀叶灵，旧宽限／风步短窗口脚本持续等待，后者在其他用例结束后主动中止（16通过、1失败、1中止）。这两份旧测试未放宽断言；并行不稳定尚未全面归因，最终完整回归采用单浏览器运行。另一次完整运行因检查出北侧遮挡而主动停止，日志独立保留。
