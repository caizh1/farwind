# 回身终结斩素材记录

使用内置图像生成工具制作原创角色动作，未使用其他游戏素材。源图保存在本目录的 `finisher-source.png`，正式图集为 `public/assets/animation/hero-melee-finisher.png`。

## 生成要求记录

生成透明背景的二维手绘游戏角色动作图集。角色为棕发旅行者，红围巾、皮革护甲、长剑，保持 Farwind 既有角色的比例和配色。三行分别是正面、背面、右侧面，每行六个独立姿态；左侧面使用项目原有镜像约定。动作依次包含收紧身体并蓄势、重心旋转、回身大幅横斩、挥击展开、收剑、恢复站姿。身体和武器都必须实际改变姿态，脚底清楚，透明间隔足够，禁止第三刀旧图拉长或待机图旋转，禁止文字、水印、背景、刀光遮盖身体。

上述为本轮生成要求的中文语义记录，不冒充工具原始输入的逐字副本。

## 导入与验收边界

通过 `tools/pack-melee-finisher.mjs` 分离十八个连通人物姿态、统一脚底根并生成三行六列的一百六十像素图集。武器握点和剑尖记录在 `src/data/meleeFinisherArt.ts`，第四刀使用正式战斗时间轴；伤害继续由原有终结事件产生。

固定根四方向预览已检查，截图为 `docs/wind-legacy/evidence/finisher-preview.jpg`。新图集已经接入正式游戏，但素材和握点、实际四连衔接、格挡／风步／受击衔接仍待连续实战观感验收，`FINISHER_PROVISIONAL` 保持开启。
