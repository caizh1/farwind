# 旅人装备与归风珠实现记录

日期：2026年9月29日。用户选择方案1「旅人装备手册」。

## 已实现的行为

按 Tab 打开行囊，再点击「装备」。暂停菜单中的「行囊」也可进入。装备页包含武器、护甲和宝珠三个栏位，默认选中归风珠；武器与护甲详情从正式穿戴状态读取，可从行囊更换或卸下。穿戴操作复用既有原子交易与保存锁，只有保存成功才发布新状态，失败保持原装备与行囊。

归风珠是永久绑定的系统装备，不增加背包物品、交易库存或存档字段。新档与能通过现有存档校验的旧档都直接显示它，满包不影响显示，重复读档不会产生副本。名称、说明、重生位置和生效提示统一来自 `RETURN_WIND_ORB`。

阵亡沿用原有恢复生命、体力、清理战斗输入、重置跟随者和两秒保护流程，村庄坐标仍为（670，720）。生命归零后显示归风珠提示；同步记录回村后的地点，避免同帧普通抵达提示覆盖归风珠说明。行囊、铜币、穿戴装备与旅途进度不因这项接入被修改。

退出装备页遵循现有返回来源：由暂停菜单进入时返回菜单，由游戏进入时返回旅途。槽位选择和穿戴后恢复槽位焦点；键盘焦点留在当前面板内。所有新增图标、按钮与状态均使用正常网格或弹性文档流。
