# 游戏参考依据

已查阅原游戏官方资料，仅借鉴系统原则与空间分工，不使用其他游戏素材。

1. [星露谷物语官方介绍](https://www.stardewvalley.net/about/)明确描述居民各自的日程、料理和制造的用途，以及房屋家具装饰。风铃村据此把生活陈设、已有居民活动和实际可用补给放在同一房间中。
2. [动物森友会官方创造页面](https://animalcrossing.nintendo.com/new-horizons/create/)介绍通过自然资源制作工具、家具和生活用品；[任天堂产品页面](https://www.nintendo.com/us/store/products/animal-crossing-new-horizons-switch/)介绍家具摆设、墙地装饰和商店。风铃村据此强调物品陈列与生活材质，而不是只添加服务按钮。
3. [我的世界村庄与掠夺官方更新](https://www.minecraft.net/en-us/article/village---pillage-out-java-)描述职业工作站、床位、聚会点和可视交易。风铃村据此区分药房、铁匠、木工和旅馆的空间与商品。

以上为设计取舍的依据，不代表这些游戏采用本项目的具体价格、恢复数值、库存刷新或保存机制；这些参数由风铃村现有系统和本轮验证确定。
