每场普通总人数增加2n（n为档位），至原人数两倍封顶，轮流分配原波次。身体及预告按空余名额补入；普通场地身体、召唤与预告不超过十只，全部敌对身体、机关、夜袭与预告共享十二槽。补援记录从一开始属于原波次，未全部击败不会推进；奖励仍按场次使用原凭据结算一次。金币按档位增加并沿用余额上限，风赐次数不变。
