# 闪链电弧重设计与验收

日期：2026年10月3日。

## 设计

原表现与伙伴连线共用平滑曲线，持续约600毫秒，缺少放电冲击；两个附伤目标距离不足55时可能被视觉去重合并。现在使用独立电弧绘制，原受击者与真实附伤目标之间的坐标快照作为固定端点，电颤随战斗时钟连续变化。伤害结算时刻、范围、倍率、目标数和冷却保持原值。

- 单束320毫秒：前28毫秒快速先导，随后主弧放电与落点爆闪，再断裂消散。
- 第二束演出错开70毫秒，只延迟绘制，不延迟伤害，不增加战斗计时任务。
- 亮白电芯、蓝青双层辉光、三条侧分叉与落点放射电丝；局部亮核控制在怪物身周，不闪整个屏幕。
- 简化模式移除侧分叉、辉光与残弧，降闪模式降低亮度并取消电弧明暗脉动。
- 共享同一绘制函数的图鉴与[动画审阅页](index.html)可以暂停、慢放和逐时刻检查。

## 图稿

[概念图](concept.png)由内置 imagegen 生成，只作形体与色彩参考。实战是随目标坐标绘制的动态电弧，不使用概念图整图贴图。

最终生成提示：用途：风铃村俯视角奇幻游戏「闪链」电弧特效视觉参考，stylized-concept。生成一张横向三格无文字动画关键帧设计图，每格背景均为暗绿草地的低对比虚化环境，有三只小型绿色史莱姆形成三角位置，保持三格布局一致。第一格：原受击史莱姆向左上方另一只释放细长而清晰的蓝青电弧，电弧主干尖锐不规则折线、明亮白色电芯、青蓝两层柔和辉光，短的分叉电丝，有放电起点小亮核。第二格：原受击史莱姆向右上另一只释放第二条电弧，第一条只有迅速断裂的淡蓝残迹；第二目标局部受击爆出小而锐利的星芒和碎电丝。第三格：主弧已散，目标身周只残留少量分叉电丝和向外飞散的短电火花。特效需像高品质ARPG链式闪电，电弧有明确方向、瞬时高能放电感、尖锐折角和分叉，禁止平滑绸带、圆润曲线、宽光柱、全屏闪光、大爆炸。角色不被遮挡，特效占据画面主体，强电弧感。三格整体是视觉参考，不是UI和图标。不要任何字母数字文字、水印或边框。

## 第二轮：向设计图继续对齐

第一轮线宽均匀、锯齿节距重复、端点过弱，本轮重绘主弧为不等间距的锐角通道，并按段填充宽窄变化的白色电芯。六条侧分叉、两端星芒、每端十六条不同方向的电丝与尖碎片，以及主弧断裂后的六组残弧补足层次。柔光限定在通道与落点，绘制端口提供局部径向光晕；世界用八层低透明度圆近似，Canvas教学页用径向渐变。正常与简化降闪均沿同一战斗时钟，不新建纹理、定时器、粒子对象或伤害任务。

[新版真实I触发图](gameplay-v2.png)来自当前工作树游戏画布原始截帧；[近距离聚集触发图](gameplay-v2-close.png)与[新版预览](preview-v2.jpg)一并保留。[伤害证据](evidence-v2.json)确认三个史莱姆中原目标从2000降至1964，另外两个降至1996.4；面板“派生命中”统计没有覆盖此基础闪链入口，不能用该面板的零值否定实际附伤。

隔离场闪链预设改为三个分散史莱姆，距离仍在正式180范围内，移动、碰撞、攻击、伤害与视觉均走游戏原有逻辑。截帧预约等待115毫秒，使第二束的70毫秒演出延迟在截图内可见。正式存档未修改。

本轮五份专项61项测试、类型检查与生产构建通过。检查新增光晕在正常模式出现、简化模式消失，降闪绘制强度不超过0.46；零距离、竖直线路及到期清空仍通过。

VERDICT: PASS

P0/P1 BLOCKERS：无。已沿正式触发、绘制端口和场景清理检查，几何循环有固定上限，输出坐标有限；光晕不创建可积累资源，绘制不修改伤害、存档或冷却。已有特效数量预算和过期清空生效；经过反证，未发现实际可达的P0/P1。

UNVERIFIED RISKS：目标设备高密度帧率尚未量测。美术更接近参考的主弧与落点，但参考图的柔和光学溢出仍更丰富，不宣称完全还原。

NON-BLOCKING FINDINGS：启动日志有其他并行据点素材的装载错误，场景仍完成装载，未妨碍本次触发。构建既有分块体积提示仍存在。
