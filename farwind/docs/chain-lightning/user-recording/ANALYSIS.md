# 用户录屏连线来源核对

日期：2026年10月3日。录屏9.981667秒，原始分辨率2294×1490、120帧每秒。

## 结论与证据

5.20秒已有长直风丝；5.40秒怪物之间出现锐角蓝色电弧，同时玩家附近到怪物的长风丝仍存在。两者不是一个效果的先导与主弧。

当前正式存档配装0/10，只有永久归风，排除留痕的织风与永冬之核。风赐12种、13级，包含递锋1级、同心1级、闪链1级；未持有归息、并肩或递锋同行。

递锋在原生命中时建立3秒标记，下一次真实伙伴命中增加20%并消费。同心在伙伴同行时增加8%原生伤害。当前两者均使用连接编排，命中时以怪物为起点、玩家为默认末端；连接绘制有两股风丝和沿途贴片。连续I反复命中，使两种连接演出叠加成持续长线。闪链仍独立连接原目标与最多两个附伤目标。

应纠正此前留痕织风的推测。单凭录像无法分别标注每条风丝的事件编号，但录屏、实际持有清单和正式调用路径相互吻合。

## 后续修复

递锋在敌人局部建立白金刃结，真正伙伴消费时才播放短接力；同心用伙伴双源的局部汇合亮结。移除两者默认怪物到玩家的整段连接，保持现有标记时长、消费和伤害规则。长线无须承担闪链前摇；闪链保留独立电弧。具体实施尚未执行。
