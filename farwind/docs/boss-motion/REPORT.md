# 首领连续动画与狼爪修正

本轮修正荆冠猎王的交叉爪击：前爪先抬起，再伸展挥出，爪风从爪尖释放后离开前爪继续飞行。最终狼爪相关151项逻辑检查、两项浏览器专项、类型检查和生产构建通过。完整首领实战与最终动画观感仍未验收。

## 用户指出的问题与根因

上一版仅对站立图做小幅全身网格形变，前腿没有独立肩肘关节，因此爪风出现时看不到完整挥爪。旧爪痕围绕脚底根绘制固定圆弧，不具有独立向外移动的释放点。上一轮网格连续性检查能证明数值没有跳变，不能证明真实爪子完成了挥击；这一视觉结论已被用户反馈否定。

## 本轮实现

- 直接从现有高清图集沿前腿轮廓划分主体和前腿网格，不新增纹理；肩、肘分别驱动前爪，避免抬爪时拉扯整片躯干。
- 前摇期间先抬爪，正式出手前160毫秒开始伸爪挥击，到正式攻击段起点才释放爪风。蓄力期间只有随爪尖移动的蓄光。
- 朝下两段分别使用近侧、远侧前爪。朝上使用身体外侧的向上挥击轨迹，侧面和镜像沿对应方向挥出。
- 三道波刃从固定释放点整体离开前爪，继续飞行并消散。爪子回收不会把已释放爪风拉回身上。
- 交叉爪击活动时间由200毫秒增至320毫秒，最终范围由115世界像素增至260世界像素。正式范围按波刃轨迹向外扩展；远处目标等待扩展到达，不在释放瞬间提前命中。地面预警覆盖完整终点，伤害和单段一次命中规则沿用原系统。
- 网格与爪风共用正式攻击时钟。暂停、取消、弹反和存档换时钟不会各自推进一套计时器。隐藏、受击位移、镜像、缩放和销毁同步到主体与前腿两层网格。
- 固定预览加入二分之一／四分之一慢放、精确毫秒输入和第一爪／第二爪选择；二倍视图的前腿和特效同步放大。

旁侧和背面原图只有一条清晰可见前腿，两段挥击复用该可见前腿；没有重建遮挡的另一条腿，也没有新增完整转身素材。
