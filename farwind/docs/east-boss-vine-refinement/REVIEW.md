# 东侧首领八连藤刺精修审查

VERDICT: PASS

本记录保留第一轮精修结论；随后已完成连续播放优化，最新资源回退与审查结果见 [后续审查](../east-boss-vine-streaming/REVIEW.md)。

## P0/P1 BLOCKERS

无。对当前实现、实际调用路径与资源清单完成审查后，没有成立的 P0 或 P1 阻塞项。工程通过不等于最终美术签收。

## 审查证据与反证

- 战斗规则：本轮未修改正式攻击系统。视觉读取现有几何、时钟和手臂挂点；藤尖端点对应几何端点，墙体截断来自已有采样。绘制不写碰撞体、伤害或攻击进度，不能用视觉位移重复推动实体。
- 状态与中断：特效每帧先隐藏对象，再按当前有效攻击绘制；已取消攻击不再绘制。死亡、撤退和暂停继续沿原正式战斗状态清理或冻结，没有增加异步攻击计时器。暂停、保存刷新和进度恢复通过实际界面操作。
- 双实体：材质共享、播放状态仍按实体记录。长藤池最多 128 个对象，单条路径最多 60 段，即使两实体同时显示也不越界。双实体测试没有关键缺帧或加载失败，大招互斥使用原调度规则。
- 资源生命周期与内存：动态图集预算扣除新藤蔓与既有光束材质；加载、预热、预取和淘汰使用同一剩余预算，包含新旧页同时存在的预约空间。单元测试及最终四组实测均低于合计 192 MiB。审查发现原计量遗漏光束材质，已修正后重新采样；该问题不再存在于当前实现。
- 透明度和缓存：保留压缩图集预乘、PNG 普通透明度路径；内容版本同时用于资源地址和纹理键。透明度专项通过，服务实际返回的图集及藤蔓哈希与新产物一致。
- 动作与导出：左右换手骨架矩阵连续，脚部漂移小；新网格显式使用正确的源纹理坐标。交付工程直接生成母版。渲染及打包验证源工程哈希，拒绝工程改变后继续复用旧母版。保留旧版清单和物理资源，重建不覆盖原版基线。
- 兼容性与恢复：没有增加存档字段或更改技能编号。独立浏览器导入现有固定存档成功，第三刺暂停保存刷新后继续至第八刺。玩家已有旅途存档未读取、导入或覆盖。

上述候选风险均检查已有保护、调用范围、合理可达路径与实际严重程度。未把缺少低性能设备测试、审美差异或优化空间当作 P0/P1。

## UNVERIFIED RISKS

- 低性能设备、公网冷启动、长时间战斗、GPU 驱动总内存及浏览器整体内存尚未验证。当前证据是本机固定样本的专项实战。
- 原画与最终动画观感需要用户审阅正常速度及慢放；矩阵差、渲染帧数与工程测试不证明达到《哈迪斯》的最终完成度。
- 本轮没有重做其他招式及分身召唤的艺术表现，其既有质量不属于本次精修结论。

## NON-BLOCKING FINDINGS

- P2：双实体 PNG 路径记录 118 次非关键帧回退，累计下载 586,575,597 字节。关键出手缺帧为零、战斗未冻结、伤害没有等待素材，但准备或收势姿势仍可能短暂重复。应继续优化 PNG 分包及预取，不能宣称全程零缺帧。
- P2：合计纹理接近预算边界。当前执行严格限额并实测未超标，后续新增素材必须计入相同共享预算，不能复制整套材质或图集给分身。
- P3：藤蔓与树林同属暖棕，实际场景中已有亮棱与地面方向提示，最终仍需审阅复杂背景下的尖端可读性。
- P3：实战录像原始采样 25 帧，四分之一慢放输出采用重复帧。检查源动作细节应优先看 1080p／60 帧的 Blender 同条件对照及直接试玩。
