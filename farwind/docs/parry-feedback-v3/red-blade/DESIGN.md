# 成功白闪与剑身红光

本轮只实现弹反成功白闪及随后贴着剑身的红光。保持现有音效、判定、窗口、自动反斩、伤害、体力、取消权限与敌人失衡；第四刀、经济伤害修正与防御战继续使用现有路径。

| 时刻（成功后模拟毫秒） | 呈现 |
| --- | --- |
| 0 | 暖白核心、剑刃短亮边和朝拨开方向展开的碎光立即成立。普通／精准命中停顿仍为55／75毫秒，白闪随模拟冻结。 |
| 20～60 | 白闪退去；朱红剑刃亮边由零升到完整强度，与现有拨开动作一致。 |
| 60 | 现有正式自动反斩启动，红刃继续跟随当前实际武器采样。 |
| 115～230 | 现有反斩有效段，历史武器轨迹使用红色淡带与暖白细线。真正命中才产生独立切入反馈。 |
| 230～375 | 按正式反斩截止时间，在最后145毫秒收势中衰减；提前接第二刀时，旧剑身红光立即结束。 |

普通成功核心半径5.5、亮边半长14；精准核心半径6.5、亮边半长18，并保留第二道细亮边。数值为1280宽基准下的显示尺度，与伤害半径无关。接触生命期150毫秒保持原值。

红光从剑柄到剑尖的22%处开始，避开握柄。柔光宽6、红亮边宽2.6，普通暖白芯宽0.8，精准1.1。背向柔光在身体后层，细亮边覆盖图集中可见钢刃；刀光保留原前后层。正、背、侧均读取已提交姿态，左向由已有武器采样镜像，不重复镜像角色。

红刃只持有一份成功快照，反斩开始时绑定正式攻击编号与结束时间；没有反斩启动的异常反馈最多保留450模拟毫秒。余势、反斩命中和重复事件不会刷新红光。新成功替换旧快照；风步取消、重新防御、真实受伤、死亡与会话重置清理旧红光。暂停与命中停顿冻结模拟时间，呈现不反向控制输入或伤害。

素材全部复用现有图集和程序绘图，无新商业素材或依赖；原动作素材的临时标记继续保留。主观亮度、红色观感及移动设备可读性待用户验收。
