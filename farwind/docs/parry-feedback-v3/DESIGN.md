## 两个重拍与事件事实

第一个重拍由免伤成功裁决成立；与反斩能否命中无关。第二个重拍只由正式攻击的已应用伤害成立。反斩开始、挥出、命中是不同事件；隔墙、挥空、取消、目标已死亡都不会生成虚假命中。

`CombatFeedback` 是轻量有界控制层。事件深拷贝并冻结，包含唯一编号、模拟时刻、主目标／攻击编号、接触位置、来招方向、剑刃方向、拨开方向、等级、材质、原失衡截止时间。音效、特效、敌人受力共用同一快照。正式敌人、防御战敌人和训练投影均走该路径。

接触位置从来招当前几何中心减去28像素的可见高度近似，投影到防御剑刃25%至85%的合法段；没有几何时使用敌人可见根高度。位置和拨开方向随来招变化，不在脚底或敌人中心固定爆闪。该投影只服务表现，不参与伤害。

拨开方向取剑刃切线，利用来招与剑刃的叉积选择一侧，再混入少量反向来招分量并归一化；避免固定全方向十字星。

## 实际时序

以成功接触时刻为零点：

| 模拟时间 | 事实与呈现 |
| --- | --- |
| 0 | 免伤、退款、取消来招完成；受力姿态、亮核心、剑刃边、偏向碎光及成功声同次更新提交，然后55／75毫秒世界停顿 |
| 20毫秒 | 实际拨开姿态到达，单次拨开声 |
| 60毫秒 | 原正式自动反斩实例启动；合法风步／防御仍可优先取消，取消即丢弃 |
| 80毫秒 | 已启动反斩经过20毫秒，进入新的起势姿态；单次反斩破风声 |
| 115毫秒起 | 原反斩有效段，四个相继姿态扫过；只有实际主目标伤害成立才产生第二重拍 |
| 原失衡结束前160毫秒 | 敌人回收重心；不增减实际硬直 |

破风声从原有效段开始移到已启动攻击的实际起势姿态，避免其包络峰值落在命中声之后。只改变反馈时序：自动反击仍在60毫秒启动、55毫秒前摇后开放伤害。起势前被取消时不补放计划中的破风声；真实受伤清理未执行的拨开和破风。

世界模拟时间推动闪光、受力、拨开和破风，命中停顿、暂停与失焦均冻结。输入接收沿用原时间轴，不由表现锁操作。音频用实际 `AudioContext.currentTime` 调度；诊断保存提交墙钟、呈现帧和设备报告输出延迟。没有宣称声画物理延迟为零。

## 动作、刃光与敌人受力

新图集六姿态覆盖起势、有效段四姿态、收势，正面／背面／右面独立；左面统一由Actor镜像。统一460像素源裁切、160像素帧、145像素显示、地面根[80,154]；没有逐帧按含剑包围盒缩放。每个姿态手工标记剑柄／剑尖。

有效段四姿态分别进入目标前方、扫过、带出。固定根完整历史路径大于35像素；有效期自身三视角均有至少24像素路径，首有效姿态已朝正式出刀方向，不再是身后举剑。`WeaponTrail` 沿用8毫秒历史采样，读取与当前图像完全一致的握点和剑尖；不同攻击／会话不连接。刀光不是伤害来源，旧扇形判定保持。

成功首帧已有暖白11／12像素核心、18／24像素刃边、单侧17／24像素碎光；精准增加双刃线，普通不是弱提示。反斩命中另有26像素切向短闪与三份目标材质碎光。小接触闪放在两名角色的局部接触层，刀光仍保留原前后遮挡层，不放全场景最高层。寿命150／115／65毫秒，最大32份。

敌人首帧建立55%受力，60毫秒到峰值，独立于600／800毫秒总失衡。史莱姆偏倒回弹；叶灵较明显躯干／挥击偏转。反斩实际命中增加95毫秒次级受击，只改变表现；不重播首次招架、不重置奖励、不延长或缩短截止。死亡立即退出存活踉跄。
