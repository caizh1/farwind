# 素材与许可记录

## 声音

采用项目内原创程序合成，没有外部录音、商业游戏资源、来源不明素材或付费购买。来源为 `src/game/systems/feedbackAudio.ts`；确定性噪声、包络、受力主体和不规则金属模态直接生成浮点PCM，首个交互缓存，战斗事件不重新生成整块数据。

金属模态为731、1177、1811、2693、3919赫兹等非整数倍衰减，精准增加4463／6137赫兹短层；撞击瞬态和主体同一起音，没有排成通知旋律。噪声种子与包络按身份区分，同身份三变体仅少量失谐。

`assets/audio/` 的11份48千赫单声道16位WAV由 `node tools/export-parry-feedback-audio.mjs` 导出，仅供分身份试听。游戏使用同一合成器缓存的AudioBuffer；录像音轨来自实际运行的AudioContext输出，没有后期补音。来源无外部素材许可依赖，合成源码／导出波形遵从本仓库原有授权边界；不擅自为整个项目另加许可证。

**状态：程序合成原型。** 已验证加载、实际输出、缓存、节点结束释放、同帧多身份和静音；尚未完成耳机、笔记本扬声器、长期重复疲劳、盲听辨识或用户音色验收。没有把采样峰值、真峰值估计或非静音作为听感通过证据。

## 动作

来源为本轮内置图像生成工具，以本项目角色比例、红围巾、手绘冒险风格制作原创反斩连续姿态；未提取参考商业游戏任何素材。第一稿存在第四姿态刃向反复，保留 `counter-source-first.png`；修正刃向后，最后核查发现首有效姿态偏蓄势，另保留 `counter-source-precontact.png` 并定向重画三视角第2格。最终 `counter-source.png` 的正面刃线已切至脚前、右向已推出剑、背面已向前切入；重新标注根与武器点，没有挪动判定时刻。源图1536×1024透明PNG。

`node tools/pack-parry-feedback-v3.mjs` 使用固定地面根、统一460像素裁切、主体连通域移除邻格碎片、固定160像素帧装配960×480图集。没有逐帧独立放大角色。真实剑柄／剑尖标注保存于 `assets/counter-manifest.json` 与 `src/data/counterArt.ts`。左向只由Actor镜像。

输出 `public/assets/animation/hero-counter-v3.png`；固定预览 `evidence/counter-fixed-preview.png`。图集实际解码、每姿态剑尖像素、固定根四方向扫掠、正常比例游戏呈现均检查。

**状态：临时动作素材。** 开发者固定预览与运行帧检查已经完成，用户最终美术／连续运动主观验收未完成，清单与 `provisional` 保留临时标记。原走跑、黑猫、防御及剑风素材未被本轮替换。

## 特效

接触核心、剑刃边、方向性火花、命中切线与材质碎光均为项目内Graphics几何。反斩光带复用原WeaponTrail真实采样，不添加与剑脱离的独立圆弧。无外部纹理、无全屏特效、无镜头震动。

## 证据体积

核心交付为短MP4、正常比例PNG、中文小型JSON与文档。大型原始帧追踪、Playwright追踪、冻结运行副本、原始WebM保存在已忽略的 `.parry-local/v3/`，不作为可提交核心证据。历史报告保留；并行专项输出不纳入本轮素材结论。
