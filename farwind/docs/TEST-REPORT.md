## 真实输入主线

从新游戏开始，使用键盘移动到守风人 → E 接任务 → 采集药草、浆果、木材、石材 → 步行进入森林 → 点击背包制作 → 键盘挥剑战斗取得结晶 → 步行进入遗迹 → 按顺序互动风石 → 修复路标 → 使用已解锁捷径 → 回村交付 → 手动保存 → 关闭页面 → 同一浏览器上下文、同一来源重新打开 → 点击继续。

断言包括任务已完成、奖励标记、背包一致、风石顺序和捷径保留。测试未直接设置玩家位置、背包、任务或胜利状态。诊断入口 `window.__farwind()` 只返回深拷贝，游戏没有测试跳关接口。

## 性能边界

本机有头 Chrome、1920×1080、村庄短距离往返后静止，总计约 13 秒；读取 Phaser 的帧 delta，取最后 600 个有效样本。平均约 120.02 FPS，中位约 120.05 FPS，低 5% 分位约 117.65 FPS。原始记录：`test-evidence/performance.json`。

这是高刷新率屏幕上的单场景短测，不能推出全地图、长时间或其他设备均稳定达到 60 FPS。无头测试中的软件 WebGL 不作为硬件性能依据。素材解码约 18.4 MiB，地表分块约 30.2 MiB；未计驱动副本、帧缓冲和浏览器缓存。

## 首因和修正

- 开发时热更新曾中断在跑的浏览器测试。此后按“完成修改后再跑测试”执行，未把中断结果计为通过；原始证据保留在 `test-evidence/first-run-hmr`。
- 测试导航曾直穿树干、新增的宝箱占地和碑文占地。碰撞正确触发；修改测试真实绕行路线，没有禁用碰撞或瞬移。
- 检查发现关键结晶可丢弃将造成有限掉落耗尽后的主线死路，已禁止丢弃并增加逻辑测试。
- HUD 非按钮区域曾可能把鼠标传给画布，已拦截并用实际点击验证没有攻击。
- 自动保存使用调用时快照并串行写入，“继续”指向实际提交成功的同一快照。
