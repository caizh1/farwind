# 其他对象接地排查

日期：2026年10月4日。此记录接续用户对原野物件光影和浮空感的反馈，仅记录本轮确认问题、修复及验证边界。工作树包含并行修改。

## 确认问题与修复

| 对象 | 确认的问题 | 本轮处理 |
| --- | --- | --- |
| 主角、伙伴、居民、卫兵、怪物及首领 | 通用绘制器仍默认把整张立面图压成硬剪影 | 默认只分配柔边接触影；整图投影仅显式启用。重甲近卫取消显式启用投影 |
| 怪物、练习投影及非人物柔影 | 旧软影向下偏移并扩大成宽云团，加重离地视觉 | 位移从6改3，匹配既有怪物脚根的负3偏移；宽度倍率从1.45改1.15，高度从1.8改0.8，取消斜转 |
| 旧村庄室内家具 | 桌、床、书架等仍使用统一宽影 | 沿真实实体底缘绘制短接触影；地毯沿用地面物件规则 |
| 训练靶 | 抬高的稻草身体额外投地面影，与底座重叠 | 移除身体的地面阴影，由既有训练底座承担接地影 |
| 裂岩斧卫、崖羽投矛者、峡牙猎兽 | 图格底部并非脚底；侧身、背面等图格还串入下一行的局部图案 | 三类共144帧记录脚部原点和主体底缘；显示层排除底部串格，脚部区域避开斧刃、矛尖及垂尾 |

怪物原点校准不改变逻辑坐标、体型、攻击计算、碰撞或存档。峡牙猎兽跳扑和裂岩斧卫挥斧沿用站立脚根，保留姿态自身腾起及正式攻击抬升。脚部采样由离线工具完成，运行时读取固定数值，不新增逐帧像素读取。

飞行弹体继续使用相差28单位的身体与地面脚根；小宝继续使用独立的地面根、腾起位移和缩小的影。战利品的文字是抬高的拾取提示，落点沿用原坐标。没有将这些有意离地的表现强制压回地面。
