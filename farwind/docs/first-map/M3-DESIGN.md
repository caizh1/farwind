# M3 南部采集路线闭环实施设计

状态：M3 已通过，见 [阶段记录](M3-REPORT.md)。M2 的四向通路与捷径不等于野外内容已交付。

代表路线从药师小院或公共委托簿领取南部补给委托，经过芦苇渡口、药草洼地，清理孢根巢地后回村交付。主角可独立完成；小宝仍可自行选择随行或守村。公共委托簿提供关键居民死亡时的替代入口。

先接入三组有稳定身份的遭遇：渡口单只近战、药草洼地远近组合、孢根巢地固定守卫。它们消费已有五种正式战斗原型，不计入新怪物交付数量。完整三十二组遭遇与新增敌人留在 M4 实施。

地图只提供静态活动区、家园、组合、巡逻点、据点归属与重生规则。遭遇运行记录按固定组和固定成员槽位保存，包含当前批次、生命、位置、死亡和未领取掉落；重生替换当前批次，不向永久击杀列表追加身份。清剿据点作为唯一持久事实，由任务与威胁共同消费。

同一只野怪仍使用 World 的唯一敌人身体及现有伤害入口。玩家、小宝和卫兵三条死亡路径收敛到同一结算，避免清剿漏记或重复奖励。卫兵击杀普通怪不自动提供任务资源。角色离开视野不抹掉在途攻击或受伤单位；仅对没有交战的远处普通单位降低更新频率。

清剿后孢根巢地保持清空，附近已清理巡游停止补充，该方向不再消耗据点袭击预算。夜间计划沿用同一个持久化调度入口，不能增加另一个独立刷怪计时器。M5 再扩成统一的骚扰、强袭、预警和恢复调度。

委托使用独立身份 south-supply；接受、交付、奖励均经过同一保存锁。材料与药剂、铜币的变更在存储成功后发布；满包、材料不足、保存失败均保持原状态。奖励具有固定领取记录，读档和重复点击不得重新发放。

验收包括：正式构建从新游戏领取委托，实际移动与战斗，清剿前后压力及巡游规则不同，返村领取与保存重开。逻辑检查覆盖重复死亡、满包掉落、重生冷却和距离、离线及暂停无进展、保存失败、关键居民死亡替代入口。测试状态样本与自然键鼠游玩分别记录。
