# 实体阴影补齐与验证

日期：2026年10月3日。本轮基于当前共享工作树实现，保留原有未提交改动，没有提交、推送或部署。

## 首因与处理

普通怪物原来创建填充透明度为0.2的椭圆，每帧又将对象透明度设置为0.2乘身体透明度。正常存活时有效透明度只有约0.04。野外与袭村怪物都有该路径。同时，普通小怪统一使用45×15的阴影，脚底中心在逻辑根上方3像素，宽体素材容易把影子盖住。

已去掉野外、袭村和史莱姆试玩场的重复0.2衰减。原阴影对象继续提供位置、显隐、飞行缩放和生命周期，硬边填充由共享柔边接地影替代，透明度只随身体淡出一次。

## 覆盖范围

| 类别 | 当前表现 |
| --- | --- |
| 十四种普通小怪、精英、袭村怪物 | 按体型调整接地范围，四足和滚兽更宽；当前帧轮廓投影随方向、镜像、攻击姿势、倒地旋转和淡出变化 |
| 四位首领及战斗机关 | 更大接地影与当前底图轮廓投影，显隐读取正式首领表现层，兼容多页图集 |
| 主角、小黑、小宝、居民、守卫 | 柔边接地影与当前素材轮廓投影；小宝飞行继续消费原地面根和缩放；居民睡床时隐藏人物影 |
| 塔上弓卫 | 影子保留在塔面，轮休或进入房间后随正式人物层级切换 |
| 建筑、树木、围栏、井、喷泉、灌木 | 加深静态轮廓投影，柔化边缘和接地层，烘焙到原地面区块 |
| 低矮花簇与岸边植被 | 小型柔边接地影随装饰一同烘焙 |
| 宝箱、采集物、路牌、据点、修路障碍、封印 | 动态阴影跟随真实物件的贴图、尺寸、透明度和显隐，避免静态缓存残留 |
| 回声石坪的三块可破坏石 | 明确排除静态烘焙；破坏后跟随正式碎石高度及透明度 |
| 训练靶、练习投影、室内家具、床、风铃挂架 | 补上接地影，立体贴图另有轮廓投影；地毯、菜畦等平面装饰不伪造立体投影 |
| 飞行弹体、战利品 | 小型接地影；弹体爆散、物件销毁或战利品领取后随源对象清理 |

动态接地影白天透明度为0.66，夜间降至0.50；轮廓投影由白天0.34降至夜间0.12。室内使用固定柔和强度。阴影保持统一东南方向。

## 渲染与生命周期

- 动态投影复用原图集纹理和四个网格顶点，不新增高清图集，不逐帧读取像素或上传画布；所有接地影共享一张128×64柔边纹理。
- 普通地面影位于地面区块之上、攻击地面预警之下，不会把影子画到人物身上，也不会盖暗红色危险区。室内影位于地毯之上、家具与人物之下。
- 可变化物件与静态烘焙分类互斥，回声石块按稳定编号识别。场景数据、碰撞、路径、攻击判定和存档结构不因阴影变化而改变。
- 动态影绑定源物件及原接地影的销毁事件。场景关闭时注销绘制监听并清理本场景条目；视窗外跳过投影更新。

## 实际验证

当前源码类型检查、生产构建、60项相关逻辑测试通过。五项开发构建浏览器专项和一项生产构建浏览器专项通过。

固定对照同时绘制十四种小怪，四位首领逐一切换，沿用正式首领图集缓存的单首领预算。按暂停、方向、地面、光照和动作控件检查；原版对照恢复真实旧路径的双重透明度。

草地同帧像素对照：十四种小怪脚底附近新增340至1577个暗像素，平均亮度降低约25至42级。此数据用于确认阴影实际可见，不代表用户已经认可最终美术。另检查林地、石路，四方向，白天、黄昏、夜间、室内，以及十四种普通小怪死亡后两层影子同时消失。

正式游戏验证包括：新档角色和全部采集物、宝箱接入；野外负坐标遭遇；手动保存、刷新继续、重新启程后数量不累积；室内家具排序、按E离屋后隐藏家具影；按E采集后物件与阴影同为原强度的30%；通过正式交付材料修路后障碍与投影同时隐藏。生产构建另核对村庄、野外画面及保存刷新，开发阴影快照没有进入生产出口。

已用Chrome真实界面启程查看当前工作树村庄，并通过固定对照控件查看增强前后画面。生产构建与野外截图另保存并人工检查。没有修改用户5173站点的正式存档来制造验收画面。

## 首轮失败记录

1. 首轮野外专项读到接地影0.132，确认普通怪物每帧仍有额外0.2衰减；修正正式世界、袭村怪物和试玩场的全部同类调用后，正式野外读到0.66，像素对照也明显加深。
2. 刷新后过早读取数量，得到170而初始为183。差值13对应尚未首帧创建的12名守卫与1个练习投影。改为等待正式首帧对象齐全，再检查数量一致和重启不累积，没有放宽最终数量断言。
3. 几何单测把数值负零与正零当作不同坐标；改用零坐标的数值近似断言，投影函数本身不需要修改。
4. 生产冒烟测试初稿等待了未导出的帧字段；改为等待已有正式驻防快照的12名守卫齐全。该错误来自测试条件，不是生产渲染。
