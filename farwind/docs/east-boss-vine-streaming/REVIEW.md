# 连续播放优化审查

VERDICT: PASS

## P0/P1 BLOCKERS

无。完成当前实现及调用链的审查和反证后，没有成立的 P0 或 P1 阻塞项。

## 审查与反证证据

- 预测状态隔离：动画器、实体、攻击及战斗记录均先建立副本。复用攻击创建函数只作用于副本；它写攻击编号、步进状态和召唤时钟，没有写入共享的根节点、同伴、冷却或伤害对象。预测返回姿势清单，不注册攻击、危险区或实体。只读回归验证真实实体、攻击和动画器序列化结果不变。
- 正式时钟：实际显示姿势仍读取原采样器；预测只决定纹理请求。暂停不推进真实时钟，保存恢复继续使用原数据。17 项实战及主端口复核覆盖真实界面的暂停、保存与刷新。
- 双实体：已排定动作的预测遵守原大招互斥和接近范围；正在移动时不预取假定的原地施法。没有调用选招函数或改变真实排程。第一次试验的错误预测已修复并加入回归，不存在于当前代码中。
- 中断与生命周期：已取消攻击不预测后续连段；已经结束的旧攻击不再次制造暴露窗口。死亡优先实际死亡姿势，预测不会复活实体。原纹理世代检查、失败页防重试、在途加载退出清理仍保留，并通过相关单元测试。
- 内存与公平性：两实体仍按当前帧和交错预取顺序共享预算。移动入口只保留当前支撑相附近的短片段，没有复制完整图集或取消上限。驻留、预载、长藤及光束材质合计在四个最终样本和 5173 复核中均小于 192 MiB。
- 兼容性：没有增加存档字段、改变技能编号、动画清单格式或图集内容版本；PNG 和压缩透明度路径未变。当前规则、伤害几何与锁向继续由正式战斗系统执行。
- 测试反证：专项门槛同时覆盖非关键回退、关键缺帧、失败页和预算，防止仅通过战斗规则测试而掩盖明显播放退化。最终完整浏览器回归及主仓库 134 项相关单元测试均通过。

## UNVERIFIED RISKS

- 低性能设备、公网加载、长时间战斗及驱动／浏览器总内存尚未测量；本轮只能证明当前设备和固定场景的结果。
- 用户最终动作观感不由工程测试代替。实战录像原始采样为 25 帧，不能用于证明所有单个渲染帧的质量。

## NON-BLOCKING FINDINGS

- P2：PNG 双实体仍有 2～3 次非关键回退，属于资源未就绪时的既有有界降级；没有延迟命中、冻结战斗、隐形实体或关键出手缺帧。PNG 读取负担仍较高，后续可按实际目标设备继续优化传输与解码。
- P2：双实体 PNG 接近纹理上限，后续素材必须继续计入共享预算，不能把两个实体的预载分别当作独立 192 MiB。
- P3：当前实际背景中藤束与提示可辨认，复杂树林的最终可读性仍需更多自然战斗场景和用户试玩评价。
