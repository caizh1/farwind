实际查看了现有旅人动作图、史莱姆和叶灵素材、森林／村庄真实截图，以及此前 [统一视觉基线](../enemy-design-v2/references/visual-baseline.png)、四怪设定板和上下／侧向弹反帧。使用同方向角色参考维持身份，内置图像工具实际生成完整连续姿态；输入及参考可追溯至 [生成记录](review/generation-records.json) 与 [方向修正](review/generation-repairs.json)。

共 **588 张独立透明姿态**，朝下、朝上、朝右三组；左向由正式镜像规则显示，不计为额外生成帧。共 **93 个动作 GIF**，另有 [五怪被弹反动画总览](animations/parry-overview.gif)、15 张逐方向全帧板、5 张干净攻击板、5 张标注攻击板和5张反馈板。孢子弹与打散效果另有2张真实生成素材。

前摇包含锁向：史莱姆120、镰灵150、孢卫120、林豕160、鸦妖120毫秒，不重复累加。攻击采样读取实际实例边界，关键姿态不是等时播放。镰灵保留现有650毫秒前摇，避免改变原训练与战斗节奏；其余新怪使用表内时序。

普通弹反600毫秒、精准800毫秒，均使用12个独立姿态并到达撑稳恢复末态；精准只延长失衡停滞段。普通受击姿态压缩到实际攻击硬直，避免敌人已经恢复出手却仍显示受击。死亡保留落地轮廓后淡出，林豕撞墙有850毫秒独立失衡，不使用红闪或旋转整张角色代替反馈。

## 游戏接入

五怪通过同一正式攻击实例、方向锁定、接触裁决、弹反窗口与动画采样运行。孢子弹单独飞行，不同时产生喷口近战伤害；远处弹反只打散弹丸，不能隔空让本体硬直。林豕撞墙停在最后合法位置、取消冲锋并失衡，不沿墙滑动继续造成伤害。

原有史莱姆与叶灵ID、主线推进和掉落类别保持；新增森林孢卫、林豕和鸦妖各一只，分散在独立林地，出生点彼此及与原主线怪保持至少500像素距离，避免首次接近叠加多个新追击区。死亡使用现有击杀ID持久化。敌人改动没有新增存档字段。本工作区同时存在其他任务的剑风技能与存档版本升级，已保留并纳入当时完整工作区单测，不把其存档升级归为本轮敌人修改。

普通敌人显示46×5像素即时血条；伤害残影保持250毫秒，再于500毫秒消退。血条在角色上方，弹反提示移至侧上方，攻击预警落在地面，避开脸和攻击部位。日夜布局图使用仓库真实背景与正式尺寸参数，明确标为**设计合成图**；`evidence/` 内的正式实战截图单独保留。

正式素材另放在 `public/assets/enemies-v1/`，没有覆盖原史莱姆、叶灵或此前已验收文件。160×160图集单元由640×640干净帧等比例缩小，脚底锚点为320、550；长角、叶镰与冲锋形变均完整容纳。打包只裁切、透明缩放、固定画布及排版，不复制角色帧凑数量。
