# 弹反证据索引

所有浏览器用例均通过正式键鼠输入。夹具只在标题界面导入合法存档，设置初始站位、体力、生命、任务和已击败列表；不修改运行中的生命、敌人位置、计时器或成功状态。

## 主要录像

- `success-combo.mp4`：普通、精准及主动反击二、三刀，正常速度，真实游戏音轨。
- `failure-rescue.mp4`：按早、按晚、背向失败、空弹后风步补救；训练生命不扣。
- `adventure.mp4`：正式史莱姆普通弹反与24伤害反击，保持原生命与攻击强度。
- `two-enemies.mp4`：两只正式史莱姆连续接触，第一下成功、35毫秒后余势格挡。

音轨旁路采集现有音量设置下的实际音频输出，按采集启动偏移同步；仅裁掉加载前段，没有变速、配音或补音。`*-media.json`记录同步偏移。主示例为1280×720、25帧视频、48千赫兹AAC音轨；初次验证音轨最大电平约-11.1分贝，无削波。主观音色与用户手感仍待验收。

## 截图和只读结果

- `normal.png`、`perfect.png`：普通与精准接触。
- `early.png`、`late.png`、`back-failure.png`：不同失败反馈。
- `guard-down.png`、`guard-up.png`、`guard-left.png`、`guard-right.png`：四方向动作。
- `adventure-normal.png`、`two-enemies.png`：正式战斗。
- `fixed-preview.png`：十二姿态统一固定根预览。
- `*-summary.json`：精确接触时间、唯一实例、裁决结果、体力及生命。
- `runtime-snapshot.json`：冻结当前源码及资源的本地等内容副本摘要，隔离并行热更新。未发布或部署。

## 合法初始条件

- 慢速／史莱姆／叶灵／收手训练：玩家(850,720)，满生命和体力，任务第三阶段；默认木桩仍不主动攻击。
- 四向与输入：玩家(1640,620)，满生命和体力。
- 正式单敌人：(2380,1060)，已击败第二只史莱姆与两只叶灵；保留第一只史莱姆原生命48。
- 正式双敌人：(2672,1000)，已击败两只叶灵；两个史莱姆保持原始出生点、生命48、伤害10和速度60。站位使二者正常寻路进入同一防御扇形，实际接触并非强制触发。

夹具通过 `initialState()` 生成且由正式导入校验接收。固定夹具副本位于 `fixtures/`。原始逐帧采样、失败首因、浏览器追踪包及未合成音视频留在 `.parry-local/` 并忽略，不作为核心交付。
