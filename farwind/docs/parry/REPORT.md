## 三阶段实现

### 判定与输入

- 敌人攻击拥有唯一实例编号、起手／锁向／接触／收招时间、固定方向、扇形范围、允许弹反标记及取消／结算状态。史莱姆450毫秒前摇、最后120毫秒锁向；叶灵650毫秒、最后150毫秒锁向。保留原生命、伤害、速度、冷却、寻路、回家和异常位置修复。
- 敌人产生精确模拟时间的接触事件，由集中裁决依次检查实例、空间、遮挡、保护、余势、弹反和受伤。一击只有一个结果；成功从未先扣生命再补回，已有保护也不产生奖励。
- 键盘和画布鼠标共用带时间及序号的输入入口。弹反120毫秒单份预约，不续期；消费时才扣体力并开放窗口。原生右键菜单只在画布内阻止。长按不重复，暂停和失焦清理输入。
- 时间轴将输入墙钟映射到帧预算，切分于输入、锁向／接触及动作边界；同刻输入先于敌人接触裁决。世界模拟停顿，继续读输入，未冻结预算扣停顿，多目标取最大值。30／60／120赫兹及抖动轨迹有一致性测试。
- 第一、二刀按前摇／有效期／收招权限取消，第三刀只在最后120毫秒收招取消；风步只在结束时接受有效预约，保留原风步权限。进入弹反清除旧攻击预约，新攻击最多一份。冲突输入按风步、弹反、攻击排序，失败不回退。

### 战斗闭环

- 全部玩法数值集中在 `PARRY` 与 `ENEMY_ATTACK`。零启动延迟，精准70、有效180、收势260、空弹冷却400毫秒；小步60像素／秒，四方向沿现有角色输入映射，左右各80度防御。
- 真正启动扣12体力、自然恢复暂停300毫秒，普通退款12，精准退款18，上限100，并保持耗尽锁存。成功从接触起经过60毫秒模拟时间恢复，成功停顿中可预约攻击、风步或下一次弹反。
- 普通／精准失衡420／600毫秒、停顿55／75毫秒、小幅安全击退6／8像素。普通攻击按最大截止时间合并硬直，不能缩短弹反失衡；取消的敌人攻击不会恢复接触。
- 600毫秒单份反击机会由玩家主动攻击消费；首刀统一解析为24／30伤害、55毫秒前摇、18像素踏步，其余沿用首刀，后续仍为20、30伤害二、三刀。时长、命中、动画、剑风、木桩和诊断均读取同一实例配置。
- 成功80毫秒余势保持原方向，额外格挡不退款、不加机会、不加停顿或完整成功音效。开始新动作结束余势。真实受伤、死亡、标题、新游戏和读档清理反击机会；存档结构不保存这些临时状态。

### 表现与教学

- 新生成正面、背面、右侧面的十二姿态设计图，分别表现架剑、受力、拨开、就绪；左向交给Actor统一镜像。固定地面根，不按逐帧含剑包围盒缩放。成功裁决在角色绘制之前完成，停顿呈现受力帧，接触火花位于架剑剑刃。
- 受击红色反馈与独立金色收拢风纹分层，敌人蓄力逐渐压低身形，锁向后不再追踪。静音也能观察节奏。没有全屏闪白、大幅震屏或长慢动作。
- 架剑、普通弹反、精准弹反有独立音效分支，沿用音量设置；余势不叠成功音效。录像采集实际游戏音轨，没有后期补音或变速。
- 靠近现有木桩可主动打开“迎风架剑练习”，选择900毫秒慢教学、史莱姆、叶灵或轻击收手链。默认木桩不攻击。训练使用正式实例和裁决，不扣真实生命、掉落或推进任务，不放开村庄和碰撞限制。
- 反馈区分按早、按晚、朝向错误、不可取消、体力不足、普通与精准成功；没有实际接触的空弹不追认为按晚。轻击链直接观察首次轻击，避免菜单后固定等待漏掉首次输入。

## 首因与修复

1. 清除弹反表现后，旧攻击预约可能倒用到260毫秒恢复之前。动作锁定截止改为独立字段，边界测试验证不得提前启动。
2. 浮点累计可能使精确锁向／接触边界偏差极小。仅事件比较使用数值误差容限，不扩大70／180毫秒弹反窗口。
3. 多个本地Vite服务共用依赖缓存，Phaser请求出现504，验收停在空白页。采用当前源码等内容运行副本和独立缓存，保留摘要，避免热更新与输出目录互相干扰。
4. 源图透明区域的RGB被查看器显示成深色背景；Alpha检查及浅色底预览确认透明有效，没有把错误候选当成最终素材。正常比例运行发现角色偏大，将整套裁切从420统一为460像素，剑刃采样同步变换。
5. 命中发生在帧内后，剩余停顿不等于完整请求时长。旧测试改为断言第三刀确切58毫秒请求预算，并继续保留世界冻结断言，没有放宽停顿。
6. 旧绕树用例在敌人尚未进入首刀距离时挥空。现在只读确认原85像素以内站位后才真实出招，仍要求原18伤害和完整碰撞轨迹，没有移动敌人或放宽范围。
7. Playwright默认开启持续焦点模拟，原生标签切换不会产生失焦。焦点用例恢复原生浏览器焦点行为再切换标签；没有给游戏派发伪造失焦或成功事件。
8. 成功停顿内第二次K请求原本被当作空弹重复拒绝。现在只有未成功的旧窗口拒绝重复，成功后新的按下沿可预约60毫秒恢复处启动；增加独立回归。

## 参数实测调整

玩法参数均按用户首轮基线保持，没有扩大窗口、减少伤害或降低敌人生命／追击强度。唯一美术调整是整套图集统一裁切460像素，使正常显示比例贴合现有角色；不是逐帧缩放。教学链选择后直接观察第一刀是输入可靠性修复，不改变敌人450／650毫秒节奏。

## 运行与操作

在项目目录运行 `npm run dev`。J／画布左键攻击，K／画布右键架剑，L风步；成功后主动J，继续J衔接第二、第三刀。靠近村中或原野木桩，点击“迎风架剑练习”选择模式，原木桩三连训练保留。

复核命令：`npm test`、`npm run typecheck`、`npm run build`。本地浏览器验收使用 `tools/playwright-parry.config.ts`，运行当前源码副本；原始追踪包与录音录像留在忽略的 `.parry-local/`，核心截图、正常速度带音轨录像和结果索引留在 `docs/parry/evidence/`。
