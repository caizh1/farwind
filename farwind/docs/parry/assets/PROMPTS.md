# 新弹反动作设计图

采用内置图像生成工具，以现有角色正面、侧面素材为视觉参照，生成独立防御动作，不使用普通挥剑图染色。

设计要求：透明画布，十二格，三行分别为正面、背面、右侧面。每行依次表现架剑、剑刃受力、拨开来招、持剑就绪。保持红围巾、棕色服装、深色头发及原有手绘冒险风格；架剑必须可见双手与斜置剑刃，受力压低重心，拨开只做短幅手腕动作。角色脚底固定，镜头、比例、光照一致，无文字、全屏光效、背景或普通挥剑替代帧。左向仅通过角色系统统一镜像。

首图的透明区域保留深色RGB，但Alpha为零；图片查看器初次显示了底层RGB，造成误判。实际检查确认透明通道有效，并以浅色底固定预览复核。后续背景编辑候选没有被选用。

选用源图为 `parry-design.png`。所有姿态统一裁切460像素并缩至160像素，游戏显示145像素，固定地面根为[80,154]。最初420像素裁切的角色比例在运行中偏大，统一改为460；没有逐帧按含剑包围盒缩放。剑刃采样采用同一变换。

固定预览见 `../evidence/fixed-preview.png`，真实四向截图见证据索引。新素材保留临时标记，用户主观美术验收尚未完成。
