## 文件与数量

- `frames/<enemy>/<direction>/frame-01.png` 至 `frame-12.png`：五怪 × 三方向 × 十二帧，共一百八十张透明单帧，画布为 512 × 512。
- `boards/<enemy>-<direction>-clean.png`：十五张透明干净设计板，无文字与辅助线。
- `boards/<enemy>-<direction>-frames.png`：十五张标注板，包含顺序、阶段、持续时间、候选地面根和游戏建议尺寸。
- `boards/overview-<direction>-max-stagger.png`：三张五怪最大失衡静态总览。
- `previews/<enemy>-<direction>-normal.gif` 与 `-perfect.gif`：三十个动画预览；另有三张五怪动图总览，共三十三个。
- `source/`：十三张选用源图。史莱姆、镰灵各一张朝右十二格和一张上下二十四格；其余各三张十二格。鸦妖朝上精选源图采用十格初稿和图像工具修正的首尾两格，后期只作裁切合成。
- `review/generation-prompts.json`：内置图像工具的实际中文输入与参考；`frame-manifest.json`：全部单帧、阶段、时序、裁切边界与摘要。
- `animation-config.json`：建议锚点、尺寸与时序。所有文件均为候选，不能直接替换生产图集。

英文文件前缀：`moss-slime` 为苔团史莱姆，`branch-reaper` 为裂枝镰灵，`ashen-spore` 为灰冠孢卫，`armored-boar` 为棘甲林豕，`dusk-raven` 为暮羽鸦妖。`down`、`up`、`right` 分别表示朝下、朝上、朝右。

## 动作区别

| 敌人 | 弹反打断与恢复 |
|---|---|
| 苔团史莱姆 | 前缘凹陷、胶体向后拉长、后折压扁、回弹复原；保留青绿胶体、黑亮眼、粉颊和双叶芽 |
| 裂枝镰灵 | 叶镰反掀、肩胸后仰、根足错步、低蹲撑稳，双镰逐步回收 |
| 灰冠孢卫 | 喷口回缩、菌盖翻起、菌柄侧弯、根足失衡，盖体放平恢复；四枚孢囊随身体摆动 |
| 棘甲林豕 | 冲角抬起、前蹄离地、后蹄承重后坐、前蹄重新落地，区别于撞墙缩颈与侧跪 |
| 暮羽鸦妖 | 颈喙后仰、双翼反张、双爪落地错步，撑稳后折翼放低喙 |

朝上与朝下独立绘制，不靠翻转互换。朝左可由角色镜像朝右；原画的烘焙高光会随镜像变化，正式动画阶段需验证世界左上光照的一致性。

## 时序与触发边界

十二帧并非等时长：普通持续时间为二十、二十五、三十、三十五、五十五、九十、九十、六十、五十、五十、四十五、五十毫秒，合计六百毫秒。精准弹反只在第六、七帧各增加一百毫秒，合计八百毫秒。

读取了当前 `src/game/systems/combat.ts` 的普通／精准弹反硬直六百／八百毫秒，以及 `World.ts` 当前对敌人的处理方式。这里只把已有硬直作为审阅节奏参考，没有改变代码。新增四怪尚未接入游戏，精灵切换、近身弹反触发与正式反馈规则仍待后续确认。

动图格式按十毫秒粒度量化累计时间边界，保持片段总长。交互页沿用原始毫秒配置。循环间另有九百毫秒待机，便于审阅，不计入硬直。

灰冠孢卫的本体近身打断和远处孢子弹打散分开处理。本次是本体失衡帧；远处弹丸被弹反打散不自动让本体失衡，也没有新增这项战斗规则。

## 参考与自检边界

实际查看了第二轮母版、四怪方向板、攻击稿和第一轮史莱姆参考，沿用已有俯视斜角与游戏建议体量。场景源是 `references/forest-day.webp` 与 `references/village-night.webp`，上一轮已与参考提交逐字节核对。

方向内使用同一缩放，保留真实压扁、拉长、后仰和附肢变化，不逐帧把可见高度强行归一，也不通过平移、旋转、复制站姿补足帧数。候选地面根为画布中的（256，440），按足底包围盒中心对齐；正式接入前需逐帧校准承重足，不代表已验证根运动。世界击退与碰撞不在本页模拟。

已修复史莱姆朝下恢复阶段误画背面、镰灵朝上末帧方向错误、鸦妖朝上首尾误露正面。少帧的孢卫合并稿未采用，改为朝上、朝下各十二格独立生成。棘甲林豕合并请求实际只生成朝下十二格，明确作为朝下选用，并另生成朝上十二格。鸦妖修正稿只取完整的首尾两格，保留原稿其余十格，避免采用被裁掉的翼尖。镰灵朝上末帧上方的两个断开残片通过透明区域隔离裁切去除，没有改绘角色主体。

自行检查不代表用户验收。造型身份细节、帧间稳定性、失衡力度、恢复节奏、最终尺寸、承重足锚点和真实运行效果仍待用户审阅与动画样片阶段验证。推荐确认后先完成史莱姆的完整动画样片，再验证镰灵方向与横扫。
