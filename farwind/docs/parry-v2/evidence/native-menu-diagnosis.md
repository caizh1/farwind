# 原生菜单销毁阻塞首因

完整回归的游戏输入、四方向、暂停、原生切标签、标题续玩断言已通过，最后销毁page／context却等待超时。追踪最后成功操作为读取诊断与保存证据，窗口销毁未返回。首轮与后续失败包分别保留在忽略目录的full-first-attempt、full-second-attempt、full-third-attempt。

关闭录像作为反证实验，仍然挂起，因此不能认定为录像编码故障。原生界面工具实际看到Google Chrome for Testing的远风页面仍有菜单：查询、复制、搜索、打印、检查、语音和服务，菜单提供Cancel动作。网页内模拟点击已经执行标题和继续，但系统菜单依然存在。

执行原生菜单Cancel后，游戏窗口立即消失，等待的测试完成。没有改游戏状态，也没有伪造blur事件。最终把“界面右键未阻止”移到独立的无窗口真实鼠标事件用例，保留两条默认行为断言；原生失焦用例仍用实际标签切换并录制画面，避免默认菜单留在系统嵌套交互中。临时关闭录像的诊断改动已经恢复。
