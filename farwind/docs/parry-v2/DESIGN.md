# 迎风架剑第二轮

## 操作与状态

J／画布左键攻击，K／画布右键弹反，L风步。成功自动反斩；成功时刻及之后的新J预约第二刀，再按J接第三刀。未按J只完成首刀。右键菜单只在游戏画布中拦截。

来招路径：蓄力 → 锁向承诺 → 有效攻击段及身体／叶刃接触 → 收招。弹反路径：输入收到或单份缓冲 → 合法架剑立即生效 → 接触裁决 → 首帧受力、剑闪、声音 → 短命中停顿 → 拨开 → 接触后60毫秒模拟时间自动反斩 → 主动接后续连段。

自动反斩是正式第一刀攻击实例，只有实际有效段命中才扣伤害。固定成功主目标与四方向，优先只伤害该主目标；不追踪、不瞬移，不扩大距离，不绕过遮挡。目标移走允许挥空。没有旧的手动反击机会与自动反斩叠加。成功恢复点的新风步／防御优先，可以取消尚未执行的反斩，取消后不补放；首刀开始后沿用正常阶段取消权限。

进入弹反清除旧攻击预约，成功再清除成功前产生的J意图。新J最多一份，成功停顿期间接收。真实受伤、死亡、新游戏、读档、标题清除临时动作和意图。普通暂停／失焦清输入；冻结的世界没有独立提示定时器。

## 采样、判定与预测

`sampleEnemyAttack` 返回阶段、进度、固定方向、姿态帧、表现偏移、累计真实移动量、当前与前次攻击几何、预警阶段。冲顶身体前沿与叶刃胶囊读取这些采样；身体移动沿现有碰撞扫掠，表现后仰与物理根分离，不整体缩放怪物冒充运动。

有效段首次真实接触才发出事件。扫描失败不消费整个实例；取消、实际结算或有效段结束才终结。普通轻击把全部阶段时间统一延后，包含起点，避免姿态与缩圈继续播放旧时间。

扫掠端点之间若不可直达，首次接触查询也沿同一碰撞扫掠取点；不使用穿过墙角的直线插值写入物理根。预测与真实扫描共用这一规则。

预计接触复用同一动作采样、几何及移动查询，包含尚未结束的普通受击硬直以及正式敌人的家园／村庄移动边界，预测对象是保持当前站位的玩家。村庄保护或家园边界使攻击不具备伤害资格时，不显示可按威胁提示。没有可达接触时不显示强烈精准提示；移动会更新预测，真实裁决服从实际接触。旧字段 `contactAt` 仅兼容保存攻击段起点，绝不在该时刻直接扣血；首次真实接触记为 `actualContactAt`。

敌人圈表示现在按的预计结果：提前90至小于240毫秒为普通区，提前0至小于90毫秒为精准区。稳定目标刻度提前显示，普通区有亮弧与底线，精准区有中心菱形和双线，不只靠颜色。多个威胁按预计接触与稳定编号排序，次要圈降低亮度。玩家自己的架剑剑边与HUD显示输入缓冲、动作发动、收势、体力／动作限制；连段提示按实际阶段及期限清除。

模拟层的意图朝向在方向输入时更新，松开保留，缓冲中可修正，启动后锁定，不回读上一渲染帧。中心重叠时用固定来招方向回退防御法线。同刻输入优先于接触；早于帧内晚输入的接触先裁决，不能倒用。

## 动作、音效与练习

新图集十八姿态，正面、背面、右侧各六个，左向只由Actor镜像。整套460像素统一裁切到160帧，显示145，脚根固定在80、154；不按剑的包围盒逐帧缩放。反斩姿态及尾迹使用真实剑尖标注。接触核心和少量碎光在模拟时钟中衰减，停顿不会提前消失。反斩尾迹150毫秒，普通三连保持110毫秒；只沿实际武器历史连接。

怪物被弹时立即进入独立失衡表现：史莱姆偏倒回弹，叶灵后仰拨偏，最后恢复。后续轻击只合并硬直截止，不能覆盖长失衡。架剑、蓄力、出手、接触共鸣、拨开、反斩风声分层；同类短时事件限次，输出压缩器控制峰值，沿用音量设置。

靠近木桩点击“迎风架剑练习”，可选慢速、史莱姆、叶灵、收手链。显示明确的练习投影，正式木桩默认不攻击。投影复用正式攻击动作、采样与裁决，训练不扣生命、不掉落、不推进任务、不解除村庄和障碍规则。菜单可关闭来招指示器；暂停菜单进入设置，音量调至零可核查纯视觉节奏。

## 根据画面核查所作的调整

史莱姆前冲采用原型允许的34像素；总时间保持330／120／100／260毫秒。第一次关闭指示器的截图操作等到锁向末尾60毫秒才看见蹬起，实际输入晚于接触135毫秒。现在蹬起帧在完整120毫秒承诺段可见，保留渐进表现偏移，给熟悉动作的玩家提前预判；没有移动真实攻击起点、扩大伤害范围或延长精准窗口。画面驱动用例同时缩小取图区域以减少观测延迟，完整录像仍为1280×720正常比例。

反斩和拨开共用连续姿态：接触后前20毫秒受力、后40毫秒拨开；反斩前摇前20毫秒继续拨开，再35毫秒进入反斩起势，随后正式115毫秒有效段和145毫秒收势。这些是姿态衔接调整，没有增加控制锁定。

接触第一帧的局部射线由8像素直径调整为24像素直径，之后展开至56像素直径；核心半径4.5像素、寿命160毫秒、反斩尾迹150毫秒集中于PARRY.visual。核查录像发现原始首帧射线过短，调整只增强剑刃附近的瞬态，保持控制、伤害和停顿时长不变。
