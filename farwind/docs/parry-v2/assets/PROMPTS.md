# 动作素材生成与处理记录

使用内置图像生成工具制作新动作设计图。参考现有旅人的红围巾、棕色旅装、发型和持剑比例，生成透明背景的十八连续姿态：正面、背面、右侧各六格，依次架剑、受力、拨开、反斩起势、反斩挥出、跟随收势。动作强调双手承力、剑刃迎击、向外拨开和短促反斩，不把普通挥剑帧染色作为架剑。

左右动作只统一镜像右侧。要求固定脚根、相同人物比例、连续身体重心关系，无文字、无全屏闪光。生成原图为本目录的hero-design.png；不是逐像素绘制的最终美术资源。

脚根与剑尖人工标注后，用tools/pack-parry-v2.mjs固定460像素裁切到160像素帧，显示145像素，脚根80、154。按接近脚根的主体连通区域去掉相邻格子的碎片，保留越格的高举剑，再用真实像素断言核查四方向剑尖。没有按含剑包围盒逐帧缩放。

敌人身体复用现有四帧，新增完整阶段、物理冲刺、叶刃扫描、表现后仰、旋转与恢复。enemy-design.png是固定正常尺寸的动作采样设计示意；运行录像是动作完成情况的证据。
