## 最终布局与实现

| 位置 | 返修结果 |
| --- | --- |

| 药师小院 | 保留房屋、井与药师；东侧两块手绘药床保留三个原采集点编号。木栏与低篱形成有凹角的连续院界，南侧院门、门前站位和短支路明确。原孤立围栏与方块药圃删除。 |
| 东北练习场 | 三个场内靶的位置和稳定编号保持原值，教学桩仍位于广场东缘，总数为四。自然边缘夯土、连续矮栏与侧篱围成独立场地；南侧入口由短支路连接主路。路牌移到入口内侧，避免被树篱挡住交互视线。 |
| 东村口 | 手绘木门按南北道路轴线摆放，两侧短围栏衔接。两个柱脚各有独立碰撞，透明门洞可走；横梁与柱身分层排序，整个门框没有实心矩形碰撞。原路牌保留并移到路外。 |
| 工程标注与装饰 | A–G 仅在开发构建且显式传入 layoutDebug=1 时显示；正常画面与生产构建均关闭。地图区域名、路牌与交互提示保留。湖岸花簇和返修区地面点缀排除道路、桥面、门洞、NPC站位及练习空间；村口过渡区生成灌木也使用该规则。 |
