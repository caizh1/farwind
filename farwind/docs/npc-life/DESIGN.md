# 居民生活系统设计与实际边界

## 工作区与人工基线

目标仓库为 caizh1/farwind，当前分支为 codex/initial-game。开工时已有昼夜、弹反反馈、驻防安全及资源修改；保留这些修改，没有提交、推送、合并或部署。实际框架是 TypeScript、Phaser 4.2.1、Vite、Vitest 与 Playwright，没有升级依赖或引入服务器、大模型、账号及外部素材。

旧流程的三居民是固定交互点；观察日程、转移、救护与恢复没有可执行行为。目标用户为键鼠探索玩家，输入为本地世界、已有驻防事实和正式存档。验收样本为三居民、九卫兵、固定一日与五日模拟、既有来袭命中、公开标记的伤情与维修演练。自动生活无需玩家逐人发令，但尚未用玩家研究量化阅读与判断精力，不能宣称减少人工八成。确定性安全、资源、死亡和幂等错误的可接受数量为零；演练事件不计入自然事件准确率。

## 模块与唯一状态

| 模块         | 实际职责                                                                             |
| ------------ | ------------------------------------------------------------------------------------ |
| 人物生活数据 | 十二个稳定身份、职业、性格、日程、家、独立床位、朋友、愿望、设施容量和集中阈值       |
| 生活存档     | 平民身体、行动、需求、公共库存、预约、任务、认知、有限记忆、提交序号与字段白名单     |
| 生活运行器   | 目标评分、低频决策、行动中断、分级警报、任务租约、救护、维修、转述与关系             |
| 空间导航     | 复用现有局部寻路；室内家具碰撞、明确门口过渡、有限重试与有界静态缓存                 |
| 驻防系统     | 九名卫兵的位置、空间、生命、死亡、攻击与回复的唯一权威；接受和平行程，负责召回和战斗 |
| 表现与界面   | 复用居民素材，跟随位置与空间绘制；室内、工具与药箱附件、居民笔记、开发诊断           |
| 世界场景     | 接入共享模拟、空间交互、暂停和一次读取后分发的驻防通知，不承载生活规则细节           |

平民各有身体状态。卫兵的生活记录中身体字段为空，查询时读取既有驻防身体，没有第二份生命和位置，也没有新增第二个卫兵实体。战斗优先；警戒时取消生活预约并真实走回岗位。返岗近战卫兵遇到岗位范围内的近敌，立即交还原战斗逻辑。弓手上下塔有一段楼梯过渡，离岗、室内或不在射击岗位时不能发箭。原有自然回复照常继承，救护每次增加三十生命；死亡不接受治疗、轮休或迁移恢复。

每门至少两名生命达到六成五、仍在室外值守的守卫，最多一人轮休。三个窗口错开，伤亡不足则明确说明推迟。普通袭扰只召回对应城门；其他门在附近三百二十像素有活敌或全村二级危机时召回。远方森林敌人不会取消全村日常，返岗过程不能重新领取轮休。三个箭塔分别配置经过碰撞核验的楼梯落脚点，避免北门落进旧风塔、南门落进工坊边缘。自然来袭的既有准入还要求完整三人准备就绪，这比轮休规则保守，因此轮休可能延后来袭，不会凭空填充守备。

## 时间与决策

世界时间为累计游戏分钟，每模拟秒推进一点五分钟；战斗、移动、行动与租约使用模拟毫秒。正式生活决策约每九百毫秒错峰执行，移动复用每帧寻路预算。暂停、对话、交易待保存、失焦与后台沿用现有冻结规则。关闭游戏不补算现实时间。

决策先检查阵亡、失去行动能力和直接危险，再筛选安全目标，按职业职责、需求、日程、性格、路程和切换成本评分。日程是有界窗口，错过不补课。配药材料不足或药品达到上限时等待或改活动，椅子、床和工作位争用时选择备用等待。完成当天午饭后转为休息，避免同一午饭窗口连续吃光库存。睡眠到窗口结束前保持连续动作与床位预约。

岚爷爷的责任心增加清点和工作优先级，较低恐惧使他不提前因远处威胁放弃日程；小满的同情心增加已知伤员救护优先级，恐惧使她只走安全路线，并在近期遇险后留药房画图鉴；阿禾责任心增加维修优先级，恐惧让他在近敌时放弃取物先转移。岑风下岗仍检查岗位；青禾更愿意去和已知位置的小满交谈、探望休养者；弦雨对临水路线的威胁更谨慎，离塔后不参与塔射。其余卫兵使用同一职业模板和独立床位、偏好及错开的窗口。

行动包含目标、可选设施与任务、阶段、进度、失败次数、开始时刻和独立提交号。共享动作覆盖行走、进出门、等待、坐席、吃饭、睡觉、工作、取物、习惯、交谈、避难、清点、治疗、陪同转移和维修。小满与阿禾先到指定位置整理药箱或工具，才继续救护、避难或维修；近敌时允许放弃财物。普通动作最短三秒，取放物品一点五秒，分数滞回十二分；安全约束和警报可立即中断。三次通路失败后释放预约并冷却该目标三十秒；睡眠与休养改选旅馆备用床，其他动作重新评价日程或安全等待。

## 住所与空间

岚爷爷使用北侧预留住宅，小满使用原商店建筑的药房卧室，阿禾使用西侧住宅，九卫兵合住既有营房，各有具名床位。既有归风旅馆增加公共客房空间与六张单人临时床。住宅入口、主人床位不可用、床位争用或连续通路失败时，预约安全空床并真实行走入住。满床或旅馆不可用时等待；卫兵取消普通轮休并返岗，不突破守备额度。住所恢复后沿路回家，不重置原住所归属。室内模板有真实可走区域、床、餐桌和工作台，人物不会因碰门而只消失。床、餐桌、私人储物箱和中央工作台参与统一碰撞与视线。

玩家只改变观察和交互空间；不重建世界、驻防、来袭与生活运行器。不同空间不计算有效交互和攻击距离，室外敌人不会追逐室内的相同数字坐标。黑猫与玩家一同进出，保留原跟随行为。

药房白天及营房公开来访；私人住所先敲门，得到半小时紧急拜访许可，再按交互键进入；较高信任也允许来访。这条有限路径保证主线人物夜间可找，不提供私人物品取用接口。门牌及居民笔记说明住所、通常作息和玩家亲眼见过的去向，不公开实时坐标或关系数值。

静态人物元数据仍保留稳定任务引用，但对应静态图像和交互点已从运行时排除。交谈按当前实体、当前空间、距离和真实视线选择。现有主线、交易确认、满包校验和关键材料保护仍由原模块处理，单纯谈话不扣材料。

## 危机、认知与恢复

一级警戒表示村门袭扰或村门内侧四百五十像素范围的实际威胁，只影响相关岗位和危险路线，不让全村停工。生活安全检查读取附近全部真实敌人，不限于已被驻防接管的敌人。敌人越过居民警戒线、进入广场周边，或来袭门守备失效才升为二级集结。村内危险与有效来袭解除后持续确认十秒才解除警报，先处理已有伤情和维修需求，再重新评价当前日程。普通袭扰不会形成小满长期改变下午安排的遇险记忆。

事件有稳定递增编号、世界时间、空间位置、来源、参与者、结果与调试标志。驻防命中通知附带攻击实例键，生活层保留有限接收凭据，重复分发或读档不再生成同一伤情事件。通知一次读取后同时交给生活和界面，不再竞争消费队列。

人物仅通过可见范围与视线、警铃或实际近距离转述获知事件。卫兵命中由守备报告送到可听到报告的药师，报告位置不是持续全知追踪；救护者接近后才能更新移动伤员位置。木匠只认领亲眼可见或已获报告的维修需求，不从任务列表获得隐藏损坏的全知记忆。未知同伴只报告下落尚未确认。集结点有容量与备选；不允许性格压过危险约束。近敌逃离允许逐步增加与敌人的距离，不能因已经身处危险而无法选择任何退路。

救护任务只能被一人认领，租约持续刷新，取消、超时和目标失效释放。小满实际到场执行五秒治疗并消耗一份公共药品。平民由受伤或失能进入休养，急救后恢复有限行动能力，再由救护者陪同到救护点；失能者不能自行走路，三小时休养后恢复。卫兵沿用既有可死亡规则，新增治疗不会复活或一瞬间补满。

本轮没有扩展敌人攻击平民或建筑的自然目标链：自然伤情来自既有驻防命中。平民伤情与风铃、木工台损坏由明确标记的开发演练验证；普通游戏不会场外随机制造这些损失。阿禾取工具，到损坏点工作七秒，消耗两份公共木料修复五十点。设施受损时在原位置显示裂痕与剩余状态，恢复后标记消失；首版损坏不改变碰撞。没有损失就不生成重建与悲伤事件。

记忆每人最多二十四条，世界事件最多八十条，任务最多十六条，接收凭据最多八十条。近期记忆到期，重要帮助或阵亡保存更久；有界凭据及裁剪水位保证裁剪后同一旧事件不再增加关系。晚到但仍在保留范围的消息可以被转述。关系为稀疏的熟悉、信任与戒备，正向同类行为有两小时冷却，不生成未实现的承诺或归责。对白使用手写事实模板，区分亲眼所见与听说。

## 资源、提交与存档

公共药品上限十二、药草十六、木料十二、家庭食物二十四。药草每个游戏日最多补充四份；家庭每日补六份食物与两份木料。配药每份消耗两药草，完成才产一药品。生活库存与玩家背包、玩家可交易库存隔离；不会自动消耗任务材料或无限创造可出售物。

主存档版本仍为六，沿用既有一至五迁移链，再创建生活状态；生活子版本增加为二，显式迁移旧版本六中的未标版本生活数据，保留其他子系统的版本判断。保留任务、钱物、地图、技能、商店和驻防伤亡，不奖励、不治疗、不复活。在途目标、空间、取物或工作进度、提交序号、关系与记忆保存；预约和任务读档后检查有效性。导航缓存、闭包与 Phaser 对象不保存。字段白名单剔除未声明载荷，损坏字段和超限记录拒绝。

原二十万字符存档限制保留。完成效果同步原子修改必要资源与序号；不到场、未完成进度、旧行动和已提交序号都不能再次提交。中断半成品直接丢弃进度、不扣料、不产出。保存失败沿用既有有效档，不用新生活系统覆盖错误。

## 表现和首版限制

人物复用原手绘居民与卫兵素材，朝向、脚底排序、空间可见性、受伤颜色、睡眠、药箱和工具附件跟随状态。药品瓶数量、木鸟阶段、具名床位和门口灯与实际活动关联。阿禾木鸟与小满图鉴在空闲时间有限推进，不要求玩家打卡。

室内家具为代码绘制的可玩首版，尚未达到手绘室外的最终美术品质；居民原素材只有两帧轻动作，没有冒称完整职业动画。十二人各有具名床边储物箱和一件不可交易的私人物品，已实现实际取出、携带和归还，箱盖、归属说明与角色附件随状态变化。这个库存只有一件物品的两个合法位置，不模拟额外私人材料经济，也不开放玩家取物。青禾已实现交谈、探望和安全护送差异：药师实际急救后，附近可见、路线安全且本门仍留两人的积极卫兵可接下护送，先到场会合，完成后返岗。危险或守备不足时仍由小满陪同。未实现背负失能者穿越战场，必须先急救恢复行动能力。环境闲聊尚未扩成区域气泡系统。受邀访问可用，未加入复杂犯罪或物品所有权交易。

开发入口只在开发构建且带指定查询参数时出现。快进推进整个战斗、行走、时间与职业模拟，不只改时钟。正式构建隐藏调试操作。性能记录是本机固定模拟和软件图形浏览器样本，不能承诺目标设备稳定六十帧。

## 继续开发：取放与备用住所的事务约束

私人物品类型来自静态定义，位置由人物的 `gear` 字段唯一记录为箱中或随身；不再另存药箱、工具的布尔副本。小满有药箱，阿禾有工具包，岚爷爷有风向笔记，卫兵有独立的整理盒、保养布或巡逻手册，这些物品不改变既有战斗武器和装备。取物需走到本人储物箱的使用位，整理一点五模拟秒，随后切换同一行动的旅行阶段；生产与治疗还必须完成实际到场和工作进度。中断保留已取得的物品。用餐与睡眠前安全允许时先归还，紧急救护优先于归还。归还同样需到本人箱子并完成一点五秒，不消耗公共物品或玩家背包。

生活子版本一到二把旧的小满药箱、阿禾工具携带事实转换为唯一物品位置；旧取物动作若尚未携带，则从真实箱子重新整理，半成品不保留消耗或产出。已有行动提交号、资源、伤亡、记忆和事件凭据不变。白名单校验物品位置、主人床位归属、不可用设施、临时床容量和归还目标。

室内入口停用只禁止进入，已在房内的人可以实际离开；不会重画地图或更改碰撞缓存。床位停用保留家具碰撞，仅撤销使用资格与预约，人物不在无效床上继续睡。入口处继承已有重叠逐步分离规则，增加拥挤时小步侧让；侧让使用相同的空间、碰撞、视线和安全约束，不能新挤进其他人物。网格起步点也避免选到队列前人的脚下。

开发床位与入口开关产生带调试标志的访问事件，关闭事实可保存和恢复。旅馆保留室外原有付费补给服务；临时床用于居民日程，不改玩家购买、生命或库存。
