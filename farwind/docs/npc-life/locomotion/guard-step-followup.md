# 近战卫兵返程脚步复查

用户新录像中的禾岩在轮休返程时虽然不再定格滑行，但双脚仍没有交替。此前的检查只确认两个旧行走帧会切换；逐帧查看后发现正面、背面和侧面旧帧均基本由同一只靴子领步，因此播放逻辑正确也无法补出另一只脚。此项属于此前验收遗漏。

这次保留原守卫的站立、攻击、受击和倒地素材，只为八名共用近战渲染路径的卫兵新增三方向各两种行走步相。每个方向保留原迈步帧，并用内置图像生成补出相反靴子迈步帧。打包时只裁切、等比缩放并将脚底对齐到同一地面根；左向仍由角色镜像。行走帧按真实位移每三十二单位切换，暂停、停步、攻击或受伤不会继续踏步。

## 验证

- 新图集六帧透明边缘与脚底高度一致。直接测量每帧靴子下缘的像素重心：正面从左侧约六十九变为右侧约九十九，背面从约六十九变为约八十七，侧面从约七十四变为约八十三；并人工检查正面、背面和侧面的完整姿态。
- 新游戏自然返程中，禾岩在开发版有二百二十一个、正式构建有二百五十一个实际移动样本，两个步相都出现；停步切回原站立图。两种运行环境的同一用例均通过，开发版另保存两张高分辨率步相截图与实录。
- 复查岚爷爷、小满、阿禾的自然移动，以及四门弓手从合法轮休任务返程；七人各自覆盖六帧行走。分帧寻路使木匠和西门弓手的起步晚于旧用例的固定观察窗口，延长取样后均实际起步并通过；这两次初始失败未被计为动画缺陷。
- 相关素材与守卫朝向测试十七项通过；类型检查、正式构建和差异格式检查通过。

证据：`evidence/development-guard-step-phase-0.png` 与 `evidence/development-guard-step-phase-1.png` 是可见的返程两步相，`evidence/development-guard-step.webm` 是完整实录；`evidence/development-guard-step.json` 和 `evidence/production-guard-step.json` 为开发版与正式构建的只读状态采样，`evidence/guard-step-other-npcs.json` 汇总其他七名移动角色的复查。图集和生成源图分别见 `public/assets/village-defense/m3/guard-walk.png` 与 `sources/guard-*-opposite.png`。

新素材尚待用户主观美术与手感验收；没有将软件渲染的浏览器采样当作用户设备性能结论。

## 审查

VERDICT: PASS

P0/P1 BLOCKERS: 无。核查了八名近战卫兵共用路径、攻击和受伤优先级、贴地锚点、方向镜像、跨空间和塔楼、停步与暂停、正式构建资源加载；没有发现具有可达严重后果的阻塞问题。

UNVERIFIED RISKS: 用户主观美术与设备性能尚未验收。

NON-BLOCKING FINDINGS: 仅用两个有明显不同靴位的步相；若后续要求更细腻的行走节奏，可继续扩充过渡帧。
