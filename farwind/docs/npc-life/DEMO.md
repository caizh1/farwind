# 居民生活首版演示

## 启动与正常游玩

在游戏目录安装现有依赖后执行 `npm run dev`，打开本地页面。开始新游戏会要求覆盖已有存档，演示建议使用独立浏览器配置；不要覆盖要保留的旅途。正式游玩不需要开发参数。

1. 早晨到广场附近找岚爷爷，照原流程交付主线。按居民笔记快捷键或按钮查看三居民住所与通常日程。
2. 到村北药田观察小满。九点到十二点通常在原商店建筑的药房配药，走到门前按交互键进入；沿下侧走廊到右侧工作位交谈。原药师服务仍需选择服务并确认交易。
3. 午间观察她去餐桌吃饭休息，下午外出整理药草，傍晚收药，晚上回药房画图鉴，然后到独立床位睡觉。近期获知危机时，她可能改为留在药房画图鉴。
4. 阿禾上午和下午使用西南木工台，傍晚回西侧住宅雕木鸟。岚爷爷检查风铃、在广场讲旧事，夜间回北侧住宅。私人住宅先敲门，关闭回应后再按交互键进入。
5. 在东、北、南门观察守卫，十九点后可进入风铃营房观察弓卫实际到床休息。每门最多一人轮休，其余继续值守；弓手离岗后塔位不再开火。伤亡不足会推迟轮休，不补人、不复活。
6. 房内按南侧出口交互键返回。观察室内时室外仍运行；暂停、对话、交易和后台会一起冻结世界。

## 已有存档

通过现有导入存档按钮导入旧文件，或使用同一来源的继续旅途。版本一至五自动迁移为六。先核对任务、背包、钱物、技能与卫兵伤亡，再观察生活；旧档不会按关闭后的现实时间补算伤害或生产。阵亡守卫仍阵亡，受伤守卫仍保留生命，随后才按原自然回复与新增救护规则推进。

可导出新档，分别在移动、配药、取箱、睡眠和转移途中保存并重新加载。读档后位置和必要进度保留，已完成配药不会再扣料或重发产物。自动化测试包含旧伤与阵亡固定样本，不把调试伤情当自然命中。

## 可复现的开发演练

执行 `npm run dev` 并打开带 `npcDebug=1` 查询参数的本地页面。独立验收入口也可执行 `npm run test:npc-life`，使用隔离端口和报告目录，避免其他任务热更新中断。

1. 新游戏后打开 NPC 调试，推进两次一小时。快进以固定一百毫秒推进整个世界，小满实际走进药房并工作。
2. 点击调试集结警报。此按钮明确标记为演练，持续十五模拟秒，不声称自然袭击。观察配药被取消且没有半成品消耗，若药箱尚在家中，她先到自己的床边箱子整理取出；已有药箱则直接沿门口转移到安全集结处。
3. 选择岚爷爷，点击调试伤情，再点击调试木工台损坏。这两项都是标记清楚的测试来源。损坏点出现裂痕和待维修标记，修好后标记消失。推进一小时，观察小满取箱、到场治疗、陪同转移；阿禾取工具，到木工台消耗木料维修。
4. 再推进一小时，检查事件流中的救治、维修和解除，伤员休养、设施恢复，日程重新评估。去实际人物身边交谈，亲历和听说的对白不同；没有收到消息者不使用这段经历。
5. 用东门来袭演练触发既有真实敌人和驻防战斗。普通村门袭扰通常仅一级警戒，不能用它声称全村突破。敌人实际命中卫兵后产生真实伤情；如果原自然回复先恢复了轻伤，不会强行消耗药品。保留旧伤的固定样本用于自动化验证真实新命中后的到场医疗。

调试观察按钮仅跟随同一空间中实际可见的人物；人物进房后应亲自到住所观察。诊断显示行动阶段、候选分数、需求、空间、预约、失败及近期事件。正式构建不会显示这些按钮。

## 证据与限制

截图位于本目录的证据子目录，包括白天药房、演练恢复与夜间住宅；测试报告区分自然战斗和调试来源。室内和工具是可玩首版表现，专用手绘室内与职业动画仍待美术验收。平民不受敌人自然攻击，建筑不自然随机损坏，卫兵可接下安全的急救后护送，尚不支持背负失能者穿越战场。未承诺六十帧或量化八成人工节省。

## 新增取放与备用住宿演示

1. 上午进入药房，小满配药时可见随身药箱。沿房间左侧到她的床边储物箱，按 E 查看归属和当前位置。对话不扣材料，也没有取走私人物品的按钮。午饭窗口开始后，小满先到箱子归还药箱，再到餐桌；箱盖与说明随事实变化。下午工作时重新取出。
2. 夜间在归风旅馆门前按 E 进入公共客房。只有住处受阻或主人床位不可用的居民会预约这里的空床，不生成第二个居民。实际到达床位后才显示睡眠。
3. 受控演练：导入晚间旧档，或全世界快进到小满二十二点的睡眠窗口；选择小满并点击“调试床位开关”或“调试住所通路开关”。这是开发访问事件。继续推进一小时，观察她离开原空间，沿村路到旅馆占用单独床位。恢复入口或床位后观察沿路回家。
4. 保存并加载旅馆室内的旅途，玩家空间、居民床位、关闭事实与私人物品位置都应保留。卫兵营房演练同样每门只允许一人离岗；旅馆满床或不安全时取消轮休。
5. 主存档六的旧居民数据自动升级生活子版本二；导入前后核对公共药品、背包和阵亡卫兵，不应多物或复活。
