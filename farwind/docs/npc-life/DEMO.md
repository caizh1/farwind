## 启动与正常游玩

最新本机正式预览为 `http://127.0.0.1:5183/`，构建指纹和实际结果见[最终验收](evidence/facility-final-validation.json)。不同端口属于不同浏览器存档来源；原旅途应从原页面导出，再通过这里的正式文件导入，不能认为换端口会自动迁移。

在游戏目录安装现有依赖后执行 `npm run dev`，打开本地页面。开始新游戏会要求覆盖已有存档，演示建议使用独立浏览器配置；不要覆盖要保留的旅途。正式游玩不需要开发参数。

1. 早晨到广场附近找岚爷爷，照原流程交付主线。按居民笔记快捷键或按钮查看三居民住所与通常日程。
2. 到村北药田观察小满。九点到十二点通常在原商店建筑的药房配药，走到门前按交互键进入；沿下侧走廊到右侧工作位交谈。原药师服务仍需选择服务并确认交易。
3. 午间观察她去餐桌吃饭休息，下午外出整理药草，傍晚收药，晚上回药房画图鉴，然后到独立床位睡觉。近期获知危机时，她可能改为留在药房画图鉴。
4. 阿禾上午和下午使用西南木工台，十三至十四点通常巡视广场风铃挂架，傍晚回西侧住宅雕木鸟。岚爷爷检查风铃、在广场讲旧事，夜间回北侧住宅。私人住宅先敲门，关闭回应后再按交互键进入。
5. 在东、北、南门观察守卫，十九点后可进入风铃营房观察弓卫实际到床休息。每门最多一人轮休，其余继续值守；弓手离岗后塔位不再开火。伤亡不足会推迟轮休，不补人、不复活。
6. 房内按南侧出口交互键返回。观察室内时室外仍运行；暂停、对话、交易和后台会一起冻结世界。

## 可复现的开发演练

执行 `npm run dev` 并打开带 `npcDebug=1` 查询参数的本地页面。独立验收入口也可执行 `npm run test:npc-life`，使用隔离端口和报告目录，避免其他任务热更新中断。

1. 新游戏后打开 NPC 调试，点击“推进至09:00”，再真实等待诊断显示小满“配药与接待 / perform”。不要继续跳过整个上午，否则有限药草可能已经用完。快进以固定一百毫秒推进整个世界，仍需实际旅行到工作位。
2. 点击调试集结警报。此按钮明确标记为演练，持续十五模拟秒，不声称自然袭击。观察配药被取消且没有半成品消耗，若药箱尚在家中，她先到自己的床边箱子整理取出；已有药箱则直接沿门口转移到安全集结处。
3. 选择岚爷爷，点击调试伤情，再点击调试木工台损坏。这两项都是标记清楚的测试来源。损坏点出现裂痕和待维修标记，修好后标记消失。推进一小时，观察小满取箱、到场治疗、陪同转移；阿禾取工具，到木工台消耗木料维修。
4. 再推进一小时，检查事件流中的救治、维修和解除，伤员休养、设施恢复，日程重新评估。去实际人物身边交谈，亲历和听说的对白不同；没有收到消息者不使用这段经历。
5. 用东门来袭演练触发既有真实敌人和驻防战斗。普通村门袭扰通常仅一级警戒，不能用它声称全村突破。敌人实际命中卫兵后产生真实伤情；如果原自然回复先恢复了轻伤，不会强行消耗药品。保留旧伤的固定样本用于自动化验证真实新命中后的到场医疗。

调试观察按钮仅跟随同一空间中实际可见的人物；人物进房后应亲自到住所观察。诊断显示行动阶段、候选分数、需求、空间、预约、失败及近期事件。正式构建不会显示这些按钮。

## 新增：真实平民伤情闭环

普通新档不会为了展示系统强制造成伤亡。小满上午九点后在药房配药，平时可以按原步骤到门口 E 进入找到她。完整守备通常把危险挡在村门，居民仍正常生活。

确定重现使用[配药危机存档](evidence/pharmacy-encounter-save.json)：这是正式校验的固定旧档验证样本，小满正在药房工作位配药，进度三秒，随身两份药已经从公共库存扣除；另含北门三名卫兵既有死亡、已经突破的一只史莱姆和原有轻伤的岚爷爷。它不是普通新档，也不是本轮随机灾难。标题页点击导入存档选此文件即可，无需打开调试或改写运行对象。[原室外药师样本](evidence/civilian-encounter-save.json)仍保留，最新自动化使用配药样本。

1. 导入后真实等待约一秒。突破警报打断小满配药，半成品取消不扣药草；她离开药房前并不知道室外岚爷爷的精确伤情。敌人按原前摇、碰撞和攻击几何命中正在撤离的岚爷爷，他失去行动能力后不再自行走动；标签显示需救护，小满带着药箱沿安全路线转移。
2. Esc 保存旅途、刷新、继续旅途。核对失能和北门死亡保留。向北走到伤员附近，按敌人当前方向移动并用 J 挥剑击退；玩家普通攻击不会伤害岚爷爷。
3. 危险清除后等十模拟秒确认。小满根据自己的目击寻找伤员，真实走到身边治疗五秒，消耗药箱中一份；伤者恢复有限行动能力，得到陪同转移并开始休养。她的后续交谈会记得救治事实，未获知此事的阿禾不会立即知道。
4. 在休养途中保存与重载，不能再扣同一份药。恢复需三小时游戏时间。可以正常游玩等待；开发环境带 npcDebug 参数也可点击三次推进一小时，必须说明这里使用全世界同步快进，不能称作真实等待。

自动验收：`npx playwright test tests/npc-life-combat.spec.ts --config tools/playwright-npc-life.config.ts` 覆盖配药真实中断、失能、暂停、两次加载、真实玩家击退、到场照护与同步快进恢复；正式构建的 `npc-life-production.spec.ts` 另覆盖健康居民被命中后的九十生命轻伤，完全不用伤情或快进按钮。查看[真实失能](evidence/civilian-real-injury.png)、[实际急救](evidence/civilian-real-care.png)、[恢复](evidence/civilian-real-recovery.png)及[正式轻伤照护](evidence/civilian-production-minor-care.png)。

## 分步规划、环境短句与真实补给

1. 正常游戏上午去小满药房，按 E 进入并走近正在配药的小满。她会说一次“这批药还在配，救护用的要先留好”，文字浮在人物上方，不弹窗口。台面上的研钵随实际工作进度活动，完成前不会增加药品。停留不会连续复播，保存重载后当天同类句仍不重复。
2. 开发演练用 `?npcDebug=1`：在小满配药时选岚爷爷，点击“调试伤情”。来源是明确标记演练。小满知道报告后会先在药房装药，状态显示“装药”，药箱最多两份。装药完成前公共库存不变；完成后公共药减两份、包中加两份。此时保存、加载或中断不会复制药。
3. 继续真实等待，或使用全世界快进。受伤的岚爷爷可能先回家休养，小满会实际走到伤者所在空间再执行治疗；救护不限定只能室外发生。一次消耗包内一份，剩余药继续留在药箱。需要区分演练伤情与原浏览器用真实驻防敌人命中的自然伤情，两者证据分别记录。
4. 阿禾看到或听到明确标记的维护点损坏后，先取工具，再到工坊领取两份木料，再到损坏点修复。观察他携带的木料附件、公共库存与包中余量，不应只在远处修复瞬间扣仓库。无安全路线、缺料或工作位被占用时可延后。
5. 导入生活子版本二旧档：公共药、木料、背包、任务、卫兵伤亡不变，包内初始零。进行中的救护或维修会补走领取流程；已经完成的事件不重结算，旧经历不会上线后集中刷短句。主存档版本仍为六。
6. 开发面板中查看当前路径是否分步规划及每批展开数。人物规划期间仍在原位置，已有门口重叠可局部侧让，真正行程继续按原速度行走。快进同时推进移动、战斗、生活和工作，不能把规划等待当作瞬移。

## 新增：真实维护点受击与阿禾修复

普通新档十三至十四点可到广场看阿禾巡视挂架。完整守备尽力阻止突破，系统不强制发生损坏。

确定演示使用[设施遭遇存档](evidence/facility-encounter-save.json)。它是明确准备的验证样本：第一日十三点、北门旧死亡、已有一只突破敌人，三居民最初在自己的住所。标题页正常导入，无需调试按钮。
