# 居民职业与家具候选素材

本轮使用内置 imagegen 技能与工具，输入为项目原来的岚爷爷、小满、阿禾和房屋素材，没有使用来源不明的外部图片。没有升级框架、添加依赖或运行时图像生成。生成素材商业权利和最终美术尚未复核，不登记正式美术验收。

- [实际中文输入](prompts.json)保留五次生成提示。身份参考为 `public/assets/elder.png`、`healer.png`、`carpenter.png`，家具画风参考为 `house.png`。
- 原始床、桌子与三职业横向图集保存在 `sources/`，不随正式游戏静态目录分发。人物源图均为一行四列，尺寸二千一百七十二乘七百二十四。
- [切分记录](manifest.json)记录实际透明边界、源文件、脚部中心与原角色脚底行。运行图集各五百一十二乘一百二十八，每帧一百二十八。床与桌子以透明主体裁切并等比例缩放，运行表现仍保持图片比例。
- `npm run assets:npc-life` 使用项目已有 Sharp，仅裁切、缩放、切帧及对齐，保留原始生成图。人物以脚部中心对齐，避免工具或抬手导致整个人左右跳动。
- 小满研药、阿禾木工、岚爷爷记录各有四个不同手臂和身体姿势，只在对应工作实际执行时播放。行走、治疗和个人习惯继续沿用既有角色和附件，不声称新增完整四方向职业动作。
- 床和共享木桌已接入所有现有室内模板，床和桌子没有改变设施归属、容量、使用位或碰撞。地板、私人箱、灯光与动态台面附件仍为原代码绘制。

逻辑与资源单元检查覆盖四帧差异、透明安全边和固定脚底；浏览器检查实际四帧、暂停冻结、加载进度、睡眠遮挡和人物交互。截图见上层验收报告。床源图没有严格满足提示中的宽高比例，运行保留其自然长床比例；不扭曲图像去凑提示尺寸。生成动作仍需后续专业美术检查循环过渡及各角度一致性。
