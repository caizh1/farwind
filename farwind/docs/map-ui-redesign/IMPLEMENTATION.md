# 风息全景地图界面实现

用户选择第二组的第2张「风息全景」，参考 `design/exploration/wind-panorama.png`。仅重做地图展示界面，保留已认可的大陆底图、真实道路与建筑数据、连续缩放和游戏状态。

## 界面

地图占满窗口；顶部显示风纹徽记与「远风舆图」，底部提供缩放、世界全貌、当前区域、定位主角和收起。地区目录默认收起，按需显示九境、服务地点、据点与商路进度。中文地名采用轻量描边文字，主角使用金色方向标记；状态和点击范围独立于底图。

地区介绍在区域尺度放在左下；世界尺度放在右下，避免遮住西南「？？？」岛。窄屏世界图为介绍预留独立网格行，工具栏排成两行；320×420展开目录时缩减目录与介绍高度。全部图标及控件使用正常文档流的 flex/grid，没有绝对定位。

新增风纹徽记、原野气氛缩略图、边缘薄雾和海域水纹先由 imagegen 生成，再做尺寸与透明度校核，记录在 `design/assets/`。薄雾以0.22透明度叠加，不引入迷雾玩法。原野缩略图是气氛插画，不用于导航；切换其他地区时隐藏。大陆原图外侧24像素仅做运行时接缝柔化，地图几何与原始资源不变。标准操作图标使用 Feather 的外部 SVG，保留原始 MIT 许可。

## 接入与生命周期

主要文件：`src/game/ui/worldAtlas.ts`、`src/world-map.css`；地形模块仅扩展底图参数以支持预处理画布。复用 Interface 的暂停、M／Esc、焦点和返回逻辑。目录改变视口尺寸时由 ResizeObserver 重算；指针仍按当前画布逻辑尺寸转换。关闭清理事件、观察器、动画、指针捕获、地形缓存及预处理画布。异步素材完成后检查已关闭状态；装饰失败可继续操作，必要地形失败显示加载错误。

没有新增依赖、存档字段或玩法门槛，没有提交、推送或部署。并行城市、伙伴与战斗改动保留。

验证见 [专项验收](VALIDATION.md)、[审查](REVIEW.md)；视觉检查见项目根目录 `design-qa.md` 的「风息全景」增补。
