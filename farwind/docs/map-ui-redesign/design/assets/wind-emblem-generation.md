## 最终生成提示

用途：远风手绘开放世界游戏地图界面的标题徽记。参考图仅用于青绿色风纹、线条气质和颜色，不复刻其具体图案。制作一个单独的原创风纹徽记：三道宽而优雅的弯曲风流环绕一粒极小的中心风种，整体接近圆形，轮廓清楚，青绿松石色发光线条，微弱暖金点缀，古老风之符文与自然流动感，简洁、克制、精致。适合在深海蓝游戏界面标题旁以30像素显示，笔画应足够厚且图形最多三层，不要密集细纹。正面、完全平面，无透视，无投影卡片，单个居中符号占画布约80%。必须真实透明背景，周围透明。无文字、无字母、无边框、无眼睛造型、无任天堂或塞尔达商标、无三角神力图案、无水印。

## 校核结果

接入素材具有真实透明通道，36,864 个像素中 15,992 个完全透明。缩放至30像素后，青绿色旋转风流的外轮廓和中心点仍可辨识。最终图形实际为四片旋转风流，视觉结构清楚，符合原创自然风纹方向；金色微纹在小尺寸下仅保留色彩点缀，不承载交互信息。未发现文字、眼睛、三角神力或商标。深蓝预览未出现黑色背景矩形，透明度与色彩可接入。游戏运行截图对照由主任务完成，当前仅验证素材层。
