# 地图边缘薄雾素材生成记录

使用内置 imagegen，透明背景开启。参考方案 2 的海蓝色全景舆图，只提取边缘空气感，不生成地图、文字、人物和控件。

## 首次生成说明

制作宽高比 1440:900 的透明画布。青白色、略带深海青蓝的轻薄手绘云雾仅沿左右边缘最外侧各 5% 宽度散布，少量角落缕状薄雾。中央至少 80% 宽度完全透明，顶部中央标题区域与底部工具栏留空。不能厚云盖住地图，不带任何文字、地图、框线、人物或图标。

首次生成的云雾过厚、边缘占宽约 15%，未接入项目。针对这一问题进行一次收窄生成。

## 最终生成说明

修改透明边缘雾素材：大幅削弱云雾厚度与密度，仅保留最外侧左右各 3% 宽的纤细半透明烟雾，左右雾气不得超过画布宽度的 5%。雾的最大不透明度约 15%，像细薄清晨空气。画布中间 90% 宽全部完全透明。最上方 10% 高与最下方 12% 高全部完全透明，留给游戏标题与底栏。移除角落厚云和所有蓝色实心面，仅两条松散纤细淡青白雾沿侧边中段。真正透明背景，不要棋盘格、文字、地图、框线或人物。横向 1440:900 比例，整片中间空白。

## 保存与校核

- 原图：`edge-mist-source.png`，1586×992，保留生成透明通道。
- 游戏素材：`public/assets/map-ui/edge-mist.webp`，1440×900，已有 sharp 缩放与格式转换，无新增依赖。
- 透明度统计：`edge-mist-alpha.json`，透明度范围为 0 至 255。
- 中央 80% 的最大透明度残留为 1，几乎完全透明。两侧云雾仍存在局部较高透明度，运行时建议总体透明度不超过 0.25，确保不遮挡地形。
