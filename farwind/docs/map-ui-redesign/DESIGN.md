# 地图展示界面重设计

本轮目标是增强地图界面的游戏代入感。用户已确认地图本身没有问题，因此范围限定为展示界面的结构、材质、控件与信息层级。地图地理、真实坐标、缩放交互、服务点与存档均继续复用现有实现。

## 设计预览

三张图按照对话中的显示顺序登记：

1. [皮革地图册](design/leather-atlas.png)：沿用现有商店的书册语言，地图与旅途札记分列。
2. [行旅卷轴](design/travel-scroll.png)：扩大地图阅读面积，目录收拢为书签，地区介绍置于下缘。
3. [风纹木匣](design/wind-map-case.png)：采用暗绿边框与纵向索引，浅纸地区介绍位于地图下缘。

调用内置图像生成工具，三次独立生成。参考当前世界地图实机图与现有商店实机图，提示词中文说明见[生成记录](GENERATION.json)。本次只保存设计预览，等待选定视觉方向后实现。

## 视觉校核

- 三图均去除浏览器、系统栏与桌面宠物；地图仍为主体，具备缩放、全貌、当前区域、定位和收起入口。
- 第一张与现有书册式商店材质接近；侧页保留目录，但缺少明显的放大查看入口，落地时需补齐。
- 第二张地图阅读面积较大；标题与目录书签占用地图边缘，落地时必须移至正常文档流，避免遮挡与窄屏冲突。
- 第三张暗色边框与浅纸札记层次清楚；概念图目录中重复海岸条目，落地时必须由现有区域数据生成，恢复准确名称、数量与状态。
- 三张概念图均有生成式地理重绘、文字与装饰差异，不能作为真实地形底图替换。成品继续使用当前已认可的地图资源，只提取选定方向的界面框架与材质。
- 不增加地图轮廓、虚构地点、传送功能或进度，不把概念图上的插画视为已实现内容。

## 落地约束与验证边界

地图信息、按钮、图标和工具栏使用正常文档流的弹性或网格布局。文字与地图交互独立绘制，保留原有事件清理、暂停返回、键盘焦点与触屏缩放。窄屏优先保证地图和操作控件可见，目录可折叠。

当前未修改游戏源码，没有新增依赖、提交、推送或部署。本轮完成设计预览与初步校核；实机匹配、响应式布局、缩放性能与键鼠回归尚未验证，需在选图实现后验收。
