# 更强探索沉浸感的第二组预览

用户要求新出一组，参考塞尔达等开放世界游戏的地图设计。保留原地图内容，重点借鉴地图占据主视野、古代器具与世界观呼应、轻量标记、信息按需展开的视觉原则。

已通过浏览器查看[任天堂官方地图截图](https://www.nintendo.com/my/news/assets/article/4lw0KPoChaf42SJdzRNc76/7.jpg)，其来源为[官方探索提示页面](https://www.nintendo.com/my/news/article/4lw0KPoChaf42SJdzRNc76)。不复制其地图地理或专属纹样，不引入传送、天空与地下层、图钉等本轮未授权的新功能。

## 本组对话显示顺序

1. [古风石盘](design/exploration/ancient-stone.png)：纤薄石纹器具框架、少量青光、底沿操作与收拢目录。
2. [风息全景](design/exploration/wind-panorama.png)：地图铺满视野，边缘轻量提示与按需地区信息，取消实体边框。
3. [林风遗器](design/exploration/forest-relic.png)：原创木骨架、青铜与叶脉风纹，左侧控制轨、底部地区信息。

三张均以当前世界地图截图和官方参考截图作为图像输入，内置图像生成工具独立生成，中文提示词见[生成记录](EXPLORATION-GENERATION.json)。选择编号仅对应本组上述显示顺序。

## 初步视觉校核与落地修正

- 三张均降低地区标签的矩形卡片感，地图主体明显扩大，开放状态、主角、未知海岛与收起入口可见。
- 第一张原野信息浮页略大，落地时缩减或纳入底栏，保证拖动后不遮挡地图地点。
- 第二张最接近整屏探索氛围，边缘云雾只是装饰预览；实际实现应限制在视口外围，不新增地图迷雾机制，也不遮住地形。
- 第三张左侧控制轨在窄屏和短屏需转为紧凑横排或网格，不能直接等比例缩小到不可点按。
- 各图对大陆轮廓、道路、建筑及地区字形均有生成式重绘差异，概念中的风圈也不是合法区域边界。成品必须继续使用当前已认可的地图资源和真实坐标，不能直接整张预览替代运行地图。
- 区域标签、目录数量、未开放与部分开放状态继续由现有数据生成。海上仅保留黑紫色“？？？”，不显著写出魔王岛。
- 图标和操作控件保持正常文档流布局，缩放、拖动、双指操作、服务点、旅途进度与关闭返回继续保留。

本轮仅出设计，没有游戏源码变更。尚未选图实现，因此窄屏可读性、实机视觉匹配与交互回归未验证。
