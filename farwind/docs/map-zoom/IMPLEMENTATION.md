# 连续缩放地图实现

M 直接容纳当前位置所属的原野、商路或城市，最远显示大陆，最近约1000单位宽。滚轮与触控板以指针为锚点，双指以手势中心为锚点；拖动平移，按钮围绕视口中心缩放。当前区域、主角定位、世界全貌和地区目录均可用键盘操作。区域文字及标记独立绘制，重叠时优先保留主角与追踪目标，目录与地点按钮提供等价入口。

## 输入与边界

地图只读正式状态，室内以保存的室外入口定位。大陆范围独立于实际玩家、掉落与导航边界；没有存档结构变更。开放区域点击后缩放，未开放区域只显示介绍。风语城显示“部分开放”，未实现室内、地下与章节首领保留提示。商路地点显示当前波次和已击退人数。

实际坐标、道路宽度、桥面、水域、树木、城墙及建筑占地直接读取现有世界登记。生成概念图只用作视觉参考；新增材质来自 imagegen，按真实几何裁剪。未开放地理底图属于规划，不代表可以步行到达。

## 生命周期与性能

共享暂停菜单和 M／Esc 返回机制，地图自身使用 AbortController 管理输入，ResizeObserver 适配视口。关闭时断开观察器、取消动画和绘制帧、释放捕获、清空画布及地形缓存；异步素材返回先检查本次视口是否关闭。无持续空闲动画循环。

相机附近分块绘制，三个采样尺度共用地理坐标；最多96块缓存，淘汰时释放画布。画布像素比最多2。工具栏、图标按钮、状态及关闭栏使用正常文档流中的 flex／grid，无绝对定位。窄屏仍保留可缩放画布和可滚动详情；低矮横屏将详情放到右侧，低矮竖屏压缩详情高度，保证关闭栏可用。

## 文件入口

- `src/game/ui/mapViewport.ts`：坐标、范围、缩放与拖动。
- `src/game/ui/mapTerrain.ts`：真实地形纹理及分块缓存。
- `src/game/ui/worldAtlas.ts`：地图视口、地点、交互、生命周期。
- `src/world-map.css`：响应式布局。
- `tests/map-viewport.test.ts`、`tests/world-atlas.spec.ts`：逻辑及真实输入专项。
- `tools/prepare-map-reference.mjs`：从当前数据导出设计底稿。
