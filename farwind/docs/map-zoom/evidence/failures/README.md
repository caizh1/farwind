# 首因证据

这些记录来自修复或验收调整前，保留供复核，不代表最终专项结论。最终结果见上层 `VALIDATION.md`。

- `plains-combat-failure.json`：初始角色不还击，林地遭遇耗尽六瓶药后真实阵亡。改为正式邀请同行并在接近敌人时还击，不授予属性、不传送。
- `fixed-duration-failure.json`：软件渲染的实际运行帧数不能由固定500毫秒键盘时长推导。等待实际恢复并按真实位移与体力验收。
- `gift-dialog-failure.json`：返程实际获得风赐并打开奖励页面，脚本只有普通关闭按钮，停在奖励页。现点击正式“稍后再选”，保留待领候选。
- `animation-observation-failure.json`：文字进入世界层级时动画尚未达到精确最小倍率。改为等待相机终值。
- `button-state-observation-failure.json`：读取放大按钮启用状态后，排队绘制将其禁用，后续自动点击等待。现每次按钮缩放等待实际倍率，边界用真实键盘验证钳制。

首次旧档导入等待及分数像素锚点证据亦保留在本机 `.map-zoom-local/first-run`；正式源码修正和反证见 `REVIEW.md`。

- `rest-close-race-failure.json`：休整事务成功后自动关闭页面，与录制辅助动作点击关闭产生竞争；页面已恢复通行，但驱动仍等待隐藏按钮。地图往返移除无关的额外休整，并在辅助点击中识别已经关闭的页面，不重放动作。

- `extra-village-waypoint-failure.json`：已真实返程跨桥、穿过原野回到村庄，额外直达出生点的航点被建筑阻挡。本次需求是城市往返原野，最终验收止于原野东口，避免把不相关的村内寻路混入地图结论。
