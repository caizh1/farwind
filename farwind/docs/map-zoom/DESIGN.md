# 连续缩放地图设计与校核

日期：2026年10月3日。先使用内置 imagegen 生成世界、原野、城市及材质图集，再接入统一视口。生成说明见 `design/GENERATION.json`，真实坐标底稿由 `tools/prepare-map-reference.mjs` 从当前地图数据导出。

## 已选视觉方向

精细正交俯视地形图，采用自然青绿、石灰、沙金、青蓝水域；不采用旧手绘示意图的透视与夸张城市比例。世界、原野、城市三个尺度使用同一地理坐标。黑紫色未知岛屿只标“？？？”。中文标记独立绘制，避免随底图缩小变糊。

## 出图校核与修正

世界图的九境方向、原野到城市的水平路线、溪河横桥和西南未知岛屿符合设计。原野图体现混合田野、分散林地与湿地；城市图保持主要街道及现有建筑结构。

生成图不是碰撞地图：原野预览增加少量未登记农舍及东侧水道；世界图城市预览增加住宅。这些差异不得接入已开放区域。为此额外调用 imagegen 生成十二格材质图集，最终已开放区域按真实数据裁剪地面、水域、道路、桥梁、城墙和建筑，而不是直接叠加带有多余地物的概念底图。城市风塔使用当前真实锚点。材质来自设计图，几何来自游戏，三个尺度保持统一比例。

大陆展示范围为横向36000、纵向26000单位，左上角（-12000，-11000）；这是地图展示坐标，不改变16000×4800的可行走范围。其他区域仅为规划地形，不代表已实现内容。

## 交互与默认范围

打开默认容纳当前完整大区域和主角位置；原野东边界4290，城市西边界9690。室内使用保存的室外入口坐标。滚轮、触控板、双指缩放保持指针或手势中心对应的世界位置；拖动只移动地图。最远显示世界，最近约1000单位宽。工具栏和区域列表留在正常文档流，地图标记绘制于画布，并提供等价可访问按钮。
