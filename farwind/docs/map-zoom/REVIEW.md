# 地图机制与实现审查

VERDICT: PASS

P0/P1 BLOCKERS: 无。

已检查地图打开、暂停入口、关闭、异步素材返回、视口调整、滚轮及触控事件、指针捕获、世界边界、旧档读取、室内定位、分块资源生命周期及并行改动。对候选问题先核对真实调用约束、已有防护及可达影响；修正已确认问题后，未发现当前支持范围内成立的 P0/P1。

## 已确认问题与处理

- 新档商路节点数组为空：原直接读取节点状态会中断地图绘制。现使用可选读取，尚未生成的一趟显示尚未触发；真实新档专项覆盖此路径。
- 画布 CSS 尺寸可能包含小数：直接使用像素指针而视口使用取整尺寸，会使指针锚点偏移。现按真实边界换算逻辑坐标，专项在非整数坐标验证缩放前后世界位置一致。
- 城市外缘主角：城市规划框不完全包含允许站立的边缘坐标。默认范围扩展到主角周围，窗口调整继续容纳主角，不修改存档位置。
- 查看其他开放区域时，地点列表原仍显示起始地区：现随选定地区更新，商路同时显示当前波次和击退数量。

- 旧面板样式给画布添加上边距，造成可见区域底部裁切。地图专用规则现清除该边距，专项检查画布完整边界与关闭栏位置。

## 关键反证

- 大陆规划坐标不是玩家移动边界：新增模块只参与地图计算，不修改保存、掉落和导航校验；地图操作前后正式状态对比。
- 关闭前的加载请求不会操作新面板：每个视口独立关闭标志；已关闭则不创建地形或访问新 DOM。事件控制器、观察器、动画与缓存均在共享关闭路径清理。
- 地图拖动不会进入战斗输入：世界暂停，画布输入自身处理并隔离；关闭后仍通过正式奔跑路径验证恢复。
- 概念图增加的地物不会制造错误导航：开放区域使用真实数据裁剪材质。所有倍率保持统一世界坐标，未开放底图仅为展示。
- 缓存有确定上限：最多96块，不按整个大陆分配像素；淘汰和关闭主动释放画布，无空闲重绘循环。

UNVERIFIED RISKS:

- 最终美术偏好、低性能真机、移动浏览器及实体触控板手感未由本机专项完全覆盖。浏览器触控协议验证不等同实体设备验收。
- 记录的是地图绘制耗时，不能据此宣称全游戏战斗帧率或所有目标设备达到某个性能门槛。
- 最终完整往返样本待领风赐为0；不据此声称有待领候选的实战刷新覆盖。地图只读状态的数据流已审查。
- 全项目所有并行战斗改动不属于本轮地图回归覆盖，相关专项通过不能外推为全游戏验收。

NON-BLOCKING FINDINGS:

- 地点在世界全貌时按信息密度省略，进入区域后显示；可从地区目录和地点列表定位。
- 生成设计图存在额外建筑，已校核并在正式地图按实际几何替换；源图作为设计过程保留。
- 低矮横屏采用地图与详情左右分栏；低矮窄屏压缩详情高度并独立滚动，避免关闭栏被内部最小高度覆盖。
- Vite 仍提示既有大分包，未增加依赖或调整无关构建结构。

当前执行证据和固定构建见 `VALIDATION.md`，审查不替代尚未完成的目标设备及用户美术验收。
