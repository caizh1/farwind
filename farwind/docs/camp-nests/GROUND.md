# 巢穴周边地形过渡

四处巢穴各自增加独立地表，从脚点下的实地材质逐渐过渡到原有草地或林地。南侧是湿菌土与朽木菌丝，西侧是碎岩硬土与兽爪痕，北侧是翻掘红土与蹄印，东侧是枯根林土与暗红落叶。

后续清剿联动：完整清剿后恢复原底图，实时缓存切换和刷新回读见[地面净化记录](PURIFICATION.md)。本页运行截图保留未清剿时的四种过渡效果。

地表只在地形区块生成时烘焙；材质坐标和羽化轮廓均由世界坐标决定。区域底图先绘制，再绘制巢穴地表，随后原水面、道路、桥面覆盖，因此不把土纹铺到水中或桥面上。没有添加碰撞、修改路线、搬动怪物或写入新的存档字段。

巢口附近覆盖完整，椭圆基础轮廓叠加不规则起伏，65～75世界单位的内外羽化总计形成约130～150单位渐变带。覆盖在包围盒外降为零，保持相邻区块采样一致。

## 实际生成提示词

使用内置图像生成，四张素材均为不透明地面纹理，由游戏地形遮罩融合；没有修改上一轮巢穴建筑原图。
