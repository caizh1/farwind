# 巢穴清剿后的地面净化

四处巢穴完整清剿后，不再绘制湿菌土、碎岩硬土、翻掘红土或枯根林土，恢复该位置原有草地或林地。原道路、水岸与桥面继续按原顺序覆盖；巢穴地标沿用现有清剿外观，保留据点识别与风忆入口。

判定使用正式据点的清剿标记。驻守怪清除、首领预警或战斗中仍保留巢穴地表；完整击败后地面即恢复。无需重新进入场景，也不增加存档字段。读档、开始新游戏和同场景进度切换均由同一缓存刷新路径处理。

地形渲染前比较四处清剿状态，只淘汰状态发生变化且与巢穴过渡包围盒相交的地面块。可见块当帧重建，视野外块按既有缓存预取规则生成。状态稳定时不重复重建，不将原静态地表改为逐帧像素合成。

风忆只对正在挑战的方向显示本次独立进度，其余方向保留正式净化结果。结束风忆后恢复正式清剿地面；风忆重开和首次清剿互不写回。

## 验证

71项巢穴、地表、过渡和首领专项测试通过；生产构建通过，仍有既有大包提示。单元检查覆盖四向驻守清除与首领正式击败后的判定，以及真实通关样本与四方向风忆退出的进度隔离。

2项浏览器检查逐项通过：通过正式导入界面读取已有真实通关样本，刷新回读后真实键盘步行至四个据点截图；通过正式界面开启、主动结束东侧风忆，用同场景的地面块创建与释放计数及画面核对局部缓存切换，不篡改玩家站位或清剿结果。本轮不将导入样本视为重新完成四场首领战。首轮行走时限失败保留如下，不能称为首次整批全绿。
