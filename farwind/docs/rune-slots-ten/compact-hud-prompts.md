# 可收起符文 HUD 设计

默认只显示符文入口图标；点击后展示临时十槽面板，点击收起隐藏。归风不占自由槽，正式符文页面沿用十槽书册设计。本轮为图像设计，未改游戏代码。

## 默认收起状态提示词

编辑输入图中的 Farwind 游戏HUD设计，输出一张横屏完整游戏画面，保持原图画幅和现有村庄手绘美术、角色、黑猫、生命体力、任务、笔记按钮、物品快捷栏。只重新设计底部符文入口。要求默认状态极度紧凑，尽量让游戏画面露出。
彻底移除右下方那块大面积“符文 10/10”面板，包括其标题、所有10槽、归风徽章、共鸣文字、配装按钮、面板边框和底色。原来被遮挡的村庄屋顶、路面、手推车自然补全为背景，保留原村庄风格。
保持底部物品栏8个格子的布局和编号1至8。将原物品栏作为一个横向正常文档流的底栏组：物品栏右侧间隔12像素添加一个单独的方形符文按钮，宽高约44像素（以1280×720逻辑视口计），深绿半透明底色，细古铜边框，内置清晰的浅青绿色手绘符文印记，图标不是文字，不用大图标、不显示十槽、不显示共鸣数量、不要加红点或数字角标。按钮下面在独立正常行空间写“符文 R”，小号但清晰；图标与文字不要重叠。这个新按钮与物品栏并排且底部对齐，整个底部组居中，留12像素屏幕安全边距。笔记按钮保持左下。底部之外不添加任何符文UI。
固定归风也不出现在默认收起的HUD，不改变实际能力，不再显示大型归风快捷框；该帧专注展示收起状态。确保世界中心和下半部可见面积显著增加，UI没有遮挡中央角色。保留原有中文内容，上方状态面板与右上任务位置尺寸保持一致。画面中不加“收起状态”等设计注释，不添加新玩法。所有UI图标排版通过正常水平或网格行列布局组织，禁止漂浮角标叠压。成品像正式游戏的真实截图。

## 点击展开状态提示词

展开图实际使用新生成的收起状态图作为输入，并追加约束：输入图已是收起状态，不存在需要删除的大面板；保持物品快捷栏、小符文入口与世界内容不动，只在小入口上方增加紧凑展开面板。

编辑输入图中的 Farwind 游戏HUD设计，保持原图画幅、现有村庄手绘美术、角色、黑猫、生命体力、任务、笔记按钮、物品快捷栏。只重新设计底部符文入口与点击后展开的临时符文面板，输出一张完整横屏游戏截图，简体中文。
移除输入图右下方原有大面积符文面板以及巨大归风徽章，补全其背后的屋顶、路面、手推车，恢复村庄。底部物品栏仍保留8格一行、编号1至8，在其右侧间距12像素加44×44像素的小符文按钮，深绿半透明底色、纤细古铜边，浅青色手绘符文印记，下方独立小字“符文 R”，底栏整体居中且屏幕底部12像素边距，按钮与物品栏水平正常布局。该按钮显示轻微选中淡金边框。
这是点击符文按钮后的展开状态：在按钮附近、底部组上方留8像素间隙显示一个十分紧凑的临时面板，以1280×720逻辑视口计算宽约300像素、高约140像素，不得比物品栏还宽。面板贴近底部，不遮挡世界中央角色；不是常驻大面板，不要巨大展示。面板深绿半透明、薄古铜边框。顶部短标题“符文 10/10”，右侧明确小按钮“收起”，二者留在同一正常布局行。下面恰好十格，以2行×5列网格组织，图标约28像素，格子约38×38像素，间距6像素，每格仅绘制一枚手绘符文图标，不添加长名字、说明、快捷键编号或状态小字：第一行回风的浅青风旋、留痕的浅绿风纹、续势的金色风带、破岸的蓝色潮浪、轻羽的浅绿羽毛；第二行雷触浅蓝闪电、霜籽冰蓝晶体、镜步金色镜弧、酿毒紫色药瓶、猎矢浅绿箭剑。不多不少10格，符文不会被画成主动施放键。
面板最下方一条简短功能行：左侧小归风印记约20像素并文字“归风 G”，右侧按钮“打开符文页”。归风印记只是小图标，不占十槽、不出现巨大第11格，不增加第二个详情区域。所有区域紧凑但清楚、留足空隙，图标、标题、按钮、归风均保留正常行列布局，不要叠字。整个展开面板占画面少量面积，收起入口始终可见，默认物品栏不被遮挡。不要箭头、设计注释、“展开状态”外部标题或新的游戏功能。
