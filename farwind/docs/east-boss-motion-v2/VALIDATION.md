# 东侧首领动作精修验收记录

日期：2026-10-06。第四版模型不变；本轮只精修追赶、转弯、双镰、收势与左右镰弹反入口。其余招式保留原姿态与时序。

## 实现与范围

- 第一阶段起手 750／400 毫秒，第二阶段 700／350 毫秒；有效期均为 200 毫秒，首击换手收势 80／60 毫秒，末击收势 220 毫秒。正式攻击时钟的两次有效期起点相差 680／610 毫秒。
- 第一次收势结束立即开始第二次准备，首击末姿势与次击首姿势相同。骨盆、腰、肩、头与枝叶分开设置曲线和延迟。
- 追赶上限 68，加速 200、减速 340，转速 225 度／秒；四段移动转弯各 45 度、200 毫秒。超过 90 度先减速。步频依据实际位移和相机投影步幅推进；转弯结束不重播起步。
- 攻击步进上限 24／18，复用正式扫掠碰撞和危险区预测。锁向后落脚不足时选择原地挥镰，避免稳足素材随根点滑动。该情形实际威胁范围随取消步进同步缩小；攻击半径 135、伤害与弱点规则保持。
- 左右镰分别有普通、完美弹反入口。取消首击不会生成次击。运动状态不进入存档，已有战斗数据恢复动作进度。

## 真实操作证据

所有初始样本通过正式导入入口进入独立端口 5366；之后通过键鼠操作，未修改运行时生命、坐标、攻击时钟或通关结果。5173 的旅途存档没有导入或覆盖。

- `eight-directions-gameplay.json`：八方向追赶、逐方向转身、首镰与次镰；出手段缺页累计为零。
- `gameplay-moving-turn*.webm`：玩家真实左右移动，首领加速追赶并在移动中转弯。四段转弯素材均交付；实战采样不是对每一种脚相切入点的穷举。
- `gameplay-combo-native.webm`、`gameplay-phase-two.webm`：两个阶段完整连斩、收势和后续招式。几何实际接触可能发生在有效期内，因此接触事件间隔不必等于有效期起点间隔。
- `gameplay-parry-normal.webm`：第一镰普通弹反，接触时架剑约 157.85 毫秒；进入左镰失衡，未补播第二击。
- `gameplay-parry-perfect-right.webm`：第二阶段右镰完美弹反，接触时架剑约 41.62 毫秒；进入右镰失衡。
- `gameplay-obstacle-final.webm`：正式地图障碍边缘的两次挥镰均选择稳足版本，整个样本根点保持 `(3527.50, 944.13)`，没有穿过障碍。
- `save-refresh-full.json`：第二镰准备段保存；刷新后首个战斗样本继续第二镰，动作时间从 67.12 毫秒加上恢复后约 27.5 毫秒成为 94.62 毫秒，位置保持。51 个暂停样本的模拟时间完全相同。
- `gameplay-final-no-effects.webm`：关闭攻击特效仍保留正式地面预警，检查转向、追赶、两次出手和收势。固定机位新旧、侧面与四分之一慢放见 `motion-comparison-*.mp4`。
