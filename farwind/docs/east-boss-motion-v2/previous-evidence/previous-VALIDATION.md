# 东侧首领逐帧动画验收记录

验收日期：2026-10-06。已将第四版模型接入正式世界；原版美术源文件保留。工程完成与美术最终认可分别判断。

## 可玩结果与证据

正式战斗使用真实八方向逐帧动画，共四十个动作片段。覆盖移动、起停、转身、现身、七个招式、受击、普通及完美弹反、风核暴露、阶段转换和死亡。双镰两击之间保持衔接，持续招式按进入、持续、退出播放。新路径停用旧身体网格扭曲，刀尖和风核特效跟随导出挂点，危险区域仍读取原攻击几何。

实际键鼠操作完成首领二千五百生命至零、阶段转换、死亡和奖励保存。测试使用独立端口的合法初始存档，装备、药品与守卫条件见 `fixtures/README.md`，不是正常旅途流程通关。运行中没有修改生命、坐标或战斗时钟。整场录像由三段连续战斗片段拼接，段间暂停用于归档；保留各段原始录像及只读记录。

实机记录观察到方向零至七、阶段一和二，以及十字镰斩、棘针齐射、缠根封路、护心结茧、移步换阵、缚枝仪式、赤环灭光。普通弹反、完美弹反分别保留录像；撤退后巢穴重置、暂停时钟冻结、保存后刷新继续、透明图片兼容路径均实际操作检查。恢复后当前战斗状态重新推导动画；精确时间相位一致性另由单元测试验证。

死亡结算先保存奖励，再允许动画继续至倒地结束，随后显示胜利界面。暂停仍冻结该过程，避免弹窗提前截断死亡动作。其他首领的表现路径不变，未增加存档版本，未修改伤害、攻击范围、命中时刻和二阶段规则。

## 性能与工程检查

设备为 Apple M5 Pro、四十八 GiB 内存；内置浏览器视口 1280×720、画布 1920×1080。同场景同长度前二十四秒记录：

| 帧间隔 | 旧版 | 新版 |
|---|---:|---:|
| 中位数 | 8.3 ms | 8.3 ms |
| 百分之九十五 | 10.3 ms | 10.0 ms |
| 最大值 | 18.7 ms | 18.0 ms |

完整战斗含胜利保存的百分之九十五为 15.7 ms，最大 100.1 ms，不能将胜利结算卡顿从整场性能结论中省略。录像输出为 1080p／60fps，视频采样率不等于游戏实测刷新率。

十一组专项与战斗回归共二百一十五项测试通过；生产构建通过。覆盖攻击相位、两击衔接、曝光优先级、中断、方向、位移步态、纹理预算、加载失败回退、清理并发、传输自动解压和奖励保存等。

源工程与渲染副本逐片段起中止骨骼矩阵最大差为零。共检查一千六百二十九帧的指定镰刃与腿、臂叶碰撞及连接关系，报告零异常；死亡全过程最低网格高度约 0.004。该检查不是全身所有表面的无穿插证明。接触表已人工查看，最终动作力度和自然性仍以完整视频与试玩判断。

可编辑工程的七张外部来源图片均已内嵌，保留可编辑原材质。运行清单、母版记录和工程摘要一致，打包只读取匹配当前工程的母版记录。源文件与工具在本目录及仓库 `tools/` 内；重建命令见主说明。

## 审查结论

VERDICT: PASS

P0/P1 BLOCKERS: 无。审查范围包括战斗时钟、动画优先级、取消攻击、死亡保存、资源并发与预算、加载失败、兼容路径和其他首领隔离。对候选问题检查现有保护与可达路径后，未发现仍成立的阻塞问题。此结论针对当前本机工程与已验证场景，不代表达到参考游戏美术完成度。

UNVERIFIED RISKS:

- 弱网和低端设备没有实测。完整资源体积仍大，实际整场下载约一百八十一 MiB；公共网络发布前需要专门的加载时延与缓存验收。
- 未用独立显存分析器验证驱动开销；预算计数覆盖图集与预载，不能代表浏览器全部内存。
- 所有片段已导出并纳入清单检查，但实机记录没有覆盖每个起停和转身变体的全部组合；长期反复进出巢穴也未做耐久验收。
- 慢放和碰撞抽查不等于全帧全身无穿插保证，最终美术与战斗手感由实际试玩验收。

NON-BLOCKING FINDINGS:

- 部分页切换有短暂帧等待；后续可根据实战方向分布调整预取，保持现有预算。
- 胜利保存阶段有约一百毫秒峰值，可单独优化保存与界面展示成本。
- 本轮没有提交、推送或部署；运行素材包含多种兼容副本，发布打包应按目标分发，避免全部重复下载。
