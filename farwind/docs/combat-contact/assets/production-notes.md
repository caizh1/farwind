# 背向素材制作记录

工具：内置 `image_gen`，非外部付费API。最终源图透明PNG均已复制进本目录，不依赖用户目录中的生成缓存。未获得或自动登记用户美术验收。

## 第一刀提示

为现有二维俯视手绘游戏制作一组真正背面向上挥剑动画素材，参考既有侧向源图的人物体型服装红围巾棕色背包与短剑、旧图集背面视角。透明背景PNG，无文字无剑光。只画同一个人物的第一刀连续六姿态，规则3列2行，等尺寸单元格，完整人物和剑，根位置与人体尺寸一致，单元格间充分透明间隔。相机固定从后上方看，始终能看到背包，人物面对画面上方，不可画成侧面旋转。依序：持剑在右侧低位准备；腰肩转动把剑带到右上方蓄势；右手朝前伸展、剑斜指右上；剑横扫经过正上方目标；随挥到左前方；收住左低位持剑准备反斩。第3到5姿态要有明显连续的右上→正上→左上扫动和不同肩肘，背包遮住在身体前方的手臂部分，剑从肩侧露出。不要倒向面对镜头，不画重复姿态，不改变武器长度，不加背景/地面/阴影。

定向修订：只修改右下第六姿态，把剑收在身体左侧低位，右臂横过身体前方大部分被背包/躯干遮挡，剑尖从左侧露出朝左下；前五姿态不变。最终文件 `back-first-source.png`。

## 后续动作提示

延续完全相同的背面角色和短剑风格，规则3列6行18姿态，与参考头部肩髋尺寸一致；始终背朝镜头朝上，背包完整可辨，不出现正面或侧脸，不旋转侧面素材，无文字背景地面剑光。

前两行反斩：承接参考左低位；肩腰向左蓄势；剑指左上；经过正上方目标；剑到右上；顺势上举中央准备终结。中两行终结斩：上举双手；后压蓄力屈膝；爆发向上前方偏右；前下斩、手臂被头肩遮挡；随挥到左侧；结束低位持剑。末两行：自然站立剑在鞘中；伸手握柄；半抽出；完全抽出低持；收回鞘口；恢复普通背面闲置。

实际输出887×1774，与请求尺寸不同。按真实尺寸与各行实际边界标注，不假称1536×3072。反斩生成首帧没有正确承接左侧，打包时用已完成第一刀末帧作为同一动作边界，后面五姿态独立；不通过重复帧填充有效挥击。最终文件 `back-follow-source.png`。

## 停手过渡提示

同一背面向上角色两组停手收剑，透明背景3列2行六姿态。上排：左腰低持剑；右手在身前将剑滑回左腰鞘、露半刃并逐渐站起；归鞘恢复自然站立。下排：双手头顶竖剑；降低至右前肩斜向右上；降低至右腰低位准备收剑。维持背包、围巾、右手、短剑、头部尺寸与脚下基准。

定点修订提示：只改左上和中上两格，其他四格保持；剑必须在画面左边，右臂跨身前被身体遮挡，金色护手在背包左下旁，刀刃朝左下延伸；第二格只露半刃。不是左右翻转整个人，围巾背包头脚保持不变，真实透明。最终文件 `back-settle-source.png`。

## 打包与标注

`back-metadata.json`记录真实源格、行边界、根与统一裁切尺寸。三张源图各自按身体基准使用600、440、700逻辑源画布统一缩放，非逐帧包围盒缩放。输出30格160×160，统一显示145、根[80,154]。`tools/pack-combat-back.mjs`可重建。握点/剑尖与姿态时刻位于 `src/data/animation.ts`，测试同时检查连续面积与真实刀刃像素，不仅检查非空图片。
