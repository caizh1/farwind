# 森林怪物样片代码审查

VERDICT: PASS

P0/P1 BLOCKERS:

无成立问题。

## 审查范围与反证

审查两种素材的源图分离与图集布局、正式预加载、显示比例和地面根、方向与镜像、动画分支、攻击阶段、伤害与受击几何的调用关系、死亡和弹反优先级、练习投影与防御敌人的共享显示路径、保存与读档、验收配置及测试覆盖。已有无关工作树改动保持原样。

一、候选风险：新增姿态导致方向跨块或空帧。反证：两种角色每方向四十八帧，基础采样器的方向步长也为四十八；攻击与移动分别落在十二至二十三、四至十一的局部范围；反应继续读取基础采样器的二十四至四十七。左向只由 Actor 镜像；最高使用帧为一百四十三，图集末尾空格不可达。独立方向与首尾检查通过。

二、候选风险：锁向时已显示有效攻击，导致判定被视觉变更提前。反证：本轮没有修改攻击控制器、几何、接触和发射逻辑。表现阶段直接读取实际 lockAt、contactAt、activeUntil 和 recoveryUntil；边界前后一毫秒及重复同一时刻的检查通过。源姿态是否足够明确属于美术可读性，仍需主观验收。

三、候选风险：高分辨率图导致怪物与碰撞整体放大。反证：原身体 height 保留七十八与七十二；加载尺寸独立于身体有效高度，显示按 height/nativeHeight 统一缩放。受击与伤害几何不读取精灵的显示宽高；固定根、等比例缩放与原尺寸运行画面已经核对。

四、候选风险：新增动画覆盖死亡或弹反状态、或取消后继续攻击。反证：先由既有 SlimeAnimation 处理死亡、弹反、真实硬直及有效攻击，仅对已选定的移动和攻击做帧映射；其余返回基础反应。死亡高于弹反、弹反高于攻击和受击的检查通过，取消攻击返回待机。

五、候选风险：测试清空常用试玩存档或制作假通关。反证：验收配置只替换数据库常量，变化时主动报错；实际请求已检查为独立数据库。浏览器从正常新游戏和键盘开始，诊断只读；死亡结果只结算一次，保存和读档后角色维持死亡。常用数据库不出现在验收浏览器的数据库列表中。

六、候选风险：完整轮廓裁切混入邻格，或将两角色当成一格。反证：源图必须检出二十四个主要透明连通轮廓且每行四个，否则拒绝；每个源像素按连通标签分离，邻格轮廓不进入本帧。成品越界与空帧均拒绝，重复摘要拒绝。原始反应与动作图逐方向联系图已经审阅。

UNVERIFIED RISKS:

- 新图集增加约九十一点四一 MiB 未压缩纹理数据。当前浏览器能够加载显示，但没有设备帧率、总显存、长时间混战及移动设备测量。该项不作为已确认的严重缺陷，也不视为性能通过。
- 主观美术、换向观感、正常速度下的肢体连续性和攻击可读性仍待用户验收；临时美术标记未取消。
- 浏览器专项覆盖当前工作树的开发入口，生产包已构建，但本轮没有单独对生产包执行森林浏览器回归。

NON-BLOCKING FINDINGS:

- 部分生成帧的叶簇、菌冠与体块仍有轻微变化，属于样片细化项，不能以帧数或摘要唯一代替动画质量验收。
- 两只样片保持同一画法，但其余怪物仍沿用旧素材；后续推广需在用户确认这两只的画风后进行。
- 预览零毫秒移动首帧及验收存档隔离的首轮问题已经定位修正，首次失败证据保留。

验证证据：一百三十四项相关逻辑检查、三项浏览器专项、类型检查与最终构建通过。报告与运行截图见 evidence。
