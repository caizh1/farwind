# 风铃村房屋细节设计

本轮按“先设计图，再对照实现”执行。范围为村庄内十栋房屋的外观；旧风塔、水井、围墙与野外旧农庄不属于房屋外观替换范围。

## 视觉目标

沿用当前暖色手绘、红陶瓦、浅石墙、深木梁和正面略俯视角。以现有房屋素材及当前主工作树新游戏截图作为参考。十栋房屋分别体现居住者和用途，附属用品贴墙，正门石阶保持净空。

## 实现与验证边界

从设计素材板直接裁切十张素材，避免二次生成偏离设计。每张保持透明背景，按原有显示宽高和脚底中心显示；原建筑标识、位置、碰撞、入口、服务和居民归属保持一致。素材生成并检查后才修改运行代码。

检查十栋覆盖率、透明边缘、尺寸和正式加载链路；使用固定合法存档镜头记录各房屋，并通过真实键盘操作验证门前通行与服务入口。固定镜头不代表任务通关或居民全天行为验收。

本轮属于视觉资产制作，不宣称生产力功能减少人工百分之八十。最终美术偏好与目标设备长期性能仍由实际验收决定。
