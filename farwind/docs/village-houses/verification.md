# 房屋外观实现与验收

## 本轮交付

先基于当前村庄截图和四张现有建筑参考，使用内置图像生成工具制作十栋房屋设计图，再从同一源图裁切十张透明素材接入当前主工作树。提示词保存在 `prompt.txt`，设计总览为 `design-board.png`，原图为 `design-source.png`。

十栋房屋覆盖：西巷旧宅、岚爷爷的家、阿禾的家、西巷小屋、风铃杂货铺、阿禾的木工坊、溪石铁匠铺、小满的药房、风铃营房、归风旅馆。本轮丰富房屋外观和贴墙生活用品；室内布局未重做。

## 运行链路

`villageHouseArt.ts` 按已有建筑标识选择新纹理。`World.preload` 加载透明网页图片，原有道具生成循环替换对应纹理。`Prop.art`、脚底锚点、建筑位置、显示尺寸、深度、碰撞占地、入口和服务数据沿用原定义。旧风塔、水井和野外农庄仍使用各自原有素材。

十张运行素材共 957448 字节，解码像素约 8.43 兆字节，未增加场景对象。设计图与运行素材直接来自同一原图；素材清单保留实际裁切框、尺寸、锚点和字节数。
