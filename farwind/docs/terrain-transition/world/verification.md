# 全图地形过渡验收

已将本轮设计接入当前工作树的正式地形绘制。保留原有清晰材质主体，以世界坐标固定的轻微起伏和窄幅透明度渐变处理所有同类自然地形接缝。效果在地面块首次生成时烘焙，后续从现有缓存显示。

## 覆盖范围

源码清点确认：六个区域，其中五个外围区域使用共同的区域过渡；三十五条道路，共一百四十七个线段，全部与村庄广场一起取并集后羽化；练习场夯土、药师院内土地区与训练磨损地面；四处荒野池塘、林间河道和村庄主湖的岸线。所有这些对象都走同一绘制入口。

道路移除硬色描边，交叉处不重复叠加透明边。土地区外缘逐渐露出草地。水岸从草地经岸土过渡到水面，主湖在原有水面着色器内增加浅水羽化。桥梁、建筑、花床木框等实体仍保留清楚的材质边界。地图判定、碰撞、道路宽度、任务与存档逻辑未修改。

## 生成开销与边界

新增采样只在静态地面块生成时运行，共用原有两个离屏画布与像素缓冲，不增加逐帧地形合成。范围外地形跳过，路段按当前块筛选，远离路边的主体与空白直接返回。每两个世界像素采样一次，四边各保留一个采样点供跨块插值。

测量定位到离屏画布合成为主要开销后，将离屏合成留在像素缓冲中，并限制实际填充及复制范围。练习场诊断样本：调整前单块最大一百一十一点一毫秒，其中画布最大一百零三点五毫秒；调整后诊断样本最大四十八点九毫秒。同场景旧绘制的分项对照样本最大一百点二毫秒，画布最大九十四点一毫秒。详见 [调整前诊断](after/training-profile.json)、[调整后诊断](after/training-profile-cpu.json) 与 [旧绘制诊断](before/training-profile.json)。

最终十五个起点的单块最大生成时间范围约三十七点二至五十四点三毫秒，详见 [最终报告](after/report.json)。修改前十五个样本的范围约四十三点二至八十三点六毫秒，详见 [修改前报告](before/report.json)。这些数据受浏览器及系统负载影响，只覆盖本次起点的同步生成，不能证明持续帧率改善。未完成长时间连续移动、跨设备帧率与冷启动体验验收。

旧绘制对照服务在启动时冻结当时的地形模块；默认已包含上一轮区域边界过渡，尚未包含本轮道路、土区和水岸过渡。它只冻结地形模块，其他模块来自当前工作树；修改前截图在本轮修改水面着色器前完成保存。
