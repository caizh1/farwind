# 地形平滑过渡验收

后续已完成全图道路、土区与水岸扩展；当前验收结果与全部对照画面见 [全图验收](world/verification.md)。下文保留首次区域边界修复的历史记录。

本轮处理北部山林与遗迹石地的矩形硬接缝。区域纹理改为沿世界坐标起伏的边缘，并以约六十四个世界像素的带宽逐渐融合。遮罩每两个世界像素采样一次，四边各保留一个额外采样点供跨块插值；计算缓冲复用。所有室外区域复用同一绘制入口，效果随地面块生成后缓存。

- 重载后的最终实现采样纹理校验值保持为 `3611394971`，驻留地面块为十个，低于三十个的验收预算。

## 设计图提示词

用途：现有游戏截图的地形过渡设计参考。输入图是唯一编辑目标。只修改画面中央偏右草地与浅黄石路之间整齐的竖直分界线，使两种地形有自然平滑过渡。保留原图的浏览器、所有中文界面、人物、黑猫、岩石、位置、比例、光照和现有手绘游戏画风。把直线边界改成轻微不规则的草边，窄幅泥土过渡带、稀疏草丛与苔藓向石路边缘延伸，少量边缘石子半埋入草地；过渡宽度约为人物身体宽度的一点五倍。草地和石路主纹理保持清晰，过渡柔和而不糊，不出现灰色大面积渐变或明显条带。不要新增建筑、角色、文字、标注或场景。

实现采用现有纹理的起伏边缘与透明度融合；设计图中的额外草簇和石子为视觉参考，不作为已经接入的新素材报告。

## 复核入口

运行游戏开发服务器后打开 `/tools/terrain-preview.html`。页面自动载入本目录的固定起点，经正式导入流程启动。页面中的 `terrain-check` 输出采样差异、跨块纹理校验值、地面块数量及生成耗时。原绘制对照可运行 `tools/serve-terrain-baseline.mjs`，只在独立端口替换地形模块。
