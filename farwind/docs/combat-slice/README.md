# 战斗体验验证切片

本切片优先验证操作响应、来招可读性与正式命中反馈。保留远风之地的角色、探索地图和既有素材；没有引入原作代码、素材或平行战斗系统。

## 使用

启动现有开发服务，访问 `/?combatSlice=1`。标题装载完成后点击“重置隔离预设”；可切换近战、冲撞、远程或混合遭遇，收起验证面板后进行实际操作。

方向键或 WASD 移动，J／左键攻击，K／右键架剑，L 风步。方向输入确定连续瞄准；每次起手锁定攻击向量，后续移动不改变当前攻击。新连段起手重新读取当前意图并选择相应四向显示素材。没有增加鼠标指向瞄准或自动追踪。

`CombatSlice` 继承正式 `World`，只选择独立场景与隔离起点。输入、连段、取消、体力、碰撞、敌人 AI、弹反、剑风、伤害和反馈仍走现有入口。开发验证使用独立数据库 `farwind-combat-slice-isolated`；正式旅途数据库不参与此切片。生产构建不开放此开发入口。切片默认关闭开发环境的免费剑风，勾选解锁只设置隔离样本初始条件，不证明正式学习流程通过。

## 支持边界与验收基线

目标用户是战斗体验验收者，输入是现有工程、已有素材和真实键鼠操作。验证范围包括旅人三段近战、已存在的第四段剑风、风步、架剑和普通近战／冲撞／远程敌人。

人工基线是逐项手动检查起手、连段、取消、命中次数、敌人锁向和反馈开关；固定逻辑测试将这些结算与时刻转为可重复断言，浏览器测试保留真实输入和录像。此任务是体验验证切片，不宣称减少人工工作达到 80%，不以自动化代替玩家对手感、美术和音效的主观验收。

质量门槛：每个攻击对每个目标最多一次正式结算；输入缓冲最多预约下一刀；取消后旧预约不复活；锁向后路线不追踪；关闭命中特效与反馈音效不改变伤害、体力、位移、命中停顿或动作执行时刻。不同步长的模拟按既有时间轴事件边界推进，结果一致。

## 实现

- `CombatController` 的攻击实例新增锁定的连续瞄准向量，显示仍用四向朝向；旧实例兼容回退到原朝向。
- 近战扇形、攻击前移和剑风出生／飞行共用 `attackVector`，反斩方向在成功接触时锁定。
- 攻击阶段采样集中到 `sampleAttackTiming`。判定窗口、旅人动画和敌人表现读取同一组起止时间；敌人前摇保留“蓄势／锁向”两个已有表现子阶段。
- 表现继续消费正式结算产生的反馈快照；关闭附加命中特效和反馈音效保留必要预警、角色动作、飞行弹体及命中停顿。
- 新增测试纳入 `npm test`、既有浏览器发现入口和 `npm run test:combat-slice`。

## 证据与限制

相关单元测试、全量逻辑入口、浏览器测试、类型检查和构建的最终结果在验收记录中列出。实际运行录像覆盖混合遭遇、近战架剑反斩、林豕锁向后侧移、孢子锁向后侧移；录像来自真实浏览器和实际按键，不是动画样稿。

沿用现有角色及敌人资源，没有新素材；现有 `provisional` 临时标记与验证面板的“素材待视觉验收”保持有效。四向挥剑姿态与斜向连续判定的主观一致性、听感以及目标设备性能仍需玩家验收。

## 首因记录

首次全量逻辑检查有两项长模拟超过默认 5 秒限制。最终串行入口保留同一超时门槛，59 个文件、1142 项测试全部通过；不放宽断言或增加重试。

冲撞躲避的一次失败保留在 `evidence/boar-locked-dodge-first-failure.json` 及对应截图和原始录像。正式风步开始于模拟 549.704 毫秒，接触发生于 582.908 毫秒，间隔 33.204 毫秒；无敌窗口从风步开始后 40 毫秒生效，因此受到 20 点伤害符合规则。原测试先传输完整世界快照再输入，且固定向右可能沿冲撞路线退开；现改为轻量取样并按锁定路线的垂直方向躲避。边界逻辑另外由固定模拟测试验证，没有延长无敌窗口。

两次浏览器运行共用固定临时输出目录导致录屏／追踪文件被另一轮清理。输出目录改为每次运行唯一，不依赖重试。后续浏览器回归串行执行。

混合遭遇的一次失败保留在 `evidence/mixed-runtime-first-failure.json` 及对应截图、录像。按固定墙钟等待后，攻击在模拟 52.083 毫秒开始，架剑在 65.283 毫秒发动，仅相隔 13.200 毫秒，早于 75 毫秒攻击前摇；取消后没有命中符合规则。测试已改为等待第二刀实际进入恢复阶段，并接受正式结算的打断、破防、保护命中等完整反馈语义。
