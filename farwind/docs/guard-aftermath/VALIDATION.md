# 卫队阵亡善后与补岗

核对日期：2026-10-04。当前工作树存在城防、人物落脚、商路等并行改动，本轮保留原有改动；此报告只认定卫队善后相关证据。

## 实现规则

- 正式战斗致死立即写入姓名对应的身份代次与阵亡世界时间。旧档阵亡登记为日期不详，保持原生命与死亡事实。
- 无活跃来袭、村门及营房周边无敌人、无飞行弹丸、营房可用，并连续安全12秒后收殓；遗体与姓名同时隐藏，原死亡事实保留。
- 收殓后的次日06:00起，安全时举行简短悼念。收殓和悼念通过游戏消息、遗体显示变化和持久纪念记录呈现。
- 营房门牌或室内守备地图办理补岗。每次80金币，安葬后才能登记；等待3个游戏小时，安全时新卫兵从营房实际走向原岗位，弓卫沿原登塔流程归位。
- 新卫兵拥有新姓名与身份代次，生活状态重新初始化，旧任务、关系、记忆、路径和临时说话状态不继承。原身份的纪念、日期与献花永久保存。
- 营房西南侧纪念碑位置为（1880，780），可从南侧靠近按E；安葬后可免费献一束庭院风铃花一次。旅途手记与居民笔记同步记录。
- 招募与献花使用现有快照事务和保存队列，写入成功后才发布；失败不扣款，旧存档保留。暂停不推进善后时钟，睡眠跨日后的下一正式模拟步处理到期事务。

## 人工基线与支持边界

原版本没有善后或补岗服务，玩家无法通过正常界面处理遗体或恢复阵亡岗位。目标用户为继续游玩的既有存档用户；输入为正式战斗伤亡或合法历史伤亡存档。

验收目标是四门十二个岗位均自动完成收殓、安葬，并在玩家一次招募操作后实际返岗；危险期间不提前善后，原身份不被重新赋予生命，扣款与补岗不因刷新重复。验收覆盖所有十二个岗位、两种职业及代表性的旧档浏览器流程。本轮不据固定样本推算长期游玩的人工节省百分比。
