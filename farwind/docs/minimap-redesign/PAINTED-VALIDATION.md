# 手绘小地图设计落地与验收

日期：2026年10月4日。本记录替代首版材质小地图的完成结论，验收目标为已选设计图的美术质量与布局，并推广至全部室外区域。

## 最终实现

小地图采用独立的手绘素材绘制器，草地、土路、水面、石路、树冠、岩石、草丛、屋顶、石桥与木桥均使用生成并检验透明度的图像素材。金色植物边框、深绿纹理面板、标题线、金色方向指针与塔楼图例同样使用独立素材。没有用静态桥梁图片替代实时导航，也没有把概念图中的虚构道路、建筑或岩崖写入正式地图。

真实道路、水域、桥面、建筑中心和树根来自现有世界数据。建筑保持俯视屋顶的素材比例，桥梁以三段伸展中部桥面，保留两端柱帽。材质镜像拼接避免方形接缝。地形分块绘制，移动只更新视野内的新增块；几何修订纳入缓存键，缓存最多24块，超出后释放旧画布。单块384×384，瓦片像素数据上限约13.5MiB，不包含素材解码及材质画布内存。

逻辑画布320×160，视野2800×1400单位，等比例、适配设备像素比。标题、北向、主角／地标图例、完整地图按钮均在正常文档流内。桌面面板348×约235像素，设计图按同宽缩小约232像素高。390像素窄屏底栏换行，面板右边界380，完整地图按钮右边界372，页面无横向溢出。

所有区域使用同一绘制器。玩家、伙伴、服务、挑战完成状态、追踪目标为实时标记；名称避让主角和其他标签。主角箭头显示最近一次实际行进方向，静止转身不改变箭头。室内使用室外入口，并将标题改为“室外入口”。绘制只读游戏状态，不修改存档、通行、碰撞、任务和奖励。完整地图继续使用其独立绘制器。

## 设计比对

最终结果：通过本轮美术方向落地、布局与导航专项验收，个人观感仍由用户确认。

已实际打开并比较 `painted-comparison.png`：左侧为概念图按348像素宽缩小，右侧为最终真实界面截图，未以生成图改写运行截图。已检查四区域组合 `painted-regions.png`、桌面全画面及390像素窄屏。

- 结构：保持细金植物边框、居中宋体标题与分隔线、右侧北向、约2:1地图窗、底部主角／地标／完整地图及M键。
- 美术：使用手绘图像表现水纹、草地、林冠、石岸、桥栏与屋顶，取消首版规则圆盘林木及矩形桥梁表现。
- 比例：首轮桥面过大与面板过高已修正；最终面板高度与参考同宽缩图相差约3像素。
- 可读性：导航标记和文字略大于参考缩图，保留实际地标名称，便于真实游玩。
- 有意差异：实际商路包含石铺道路、近直线河段和固定林木分布；不复制概念图虚构的弯曲河岸与岩崖。金叶、标题线和塔楼为依据参考重制的素材，细节不等于原图像素复制；窄屏底栏正常换行。

没有剩余可执行的P0/P1/P2布局或交互问题。上述有意差异属于实际地图内容与小尺寸可读性选择，不能据此宣称原图逐像素一致。
