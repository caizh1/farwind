# 右上角地形小地图改造与验收

日期：2026年10月4日。

本文件保留首版材质小地图记录；当前实现、设计比对和最新验收请见[手绘版本验收](PAINTED-VALIDATION.md)。

## 改造目标与实现

原小地图把河流和桥梁绘制为大色块，地表透明叠在战场上，无法辨认森林、建筑与路线。此次复用完整地图的地形绘制器：真实林木、地表、水域、道路、建筑、城墙与桥梁使用既有材质；石桥增加桥栏杆与端柱。概念图仅提供风格参考，没有把虚构地形作为导航底图。

面板增加周边地形标题、北向、200单位比例尺、金色主角箭头与光圈、青色服务点、红色挑战点。名称避让主角和其他名称。主角箭头表示最近一次实际行进方向，静止转身不会改变箭头。保持原折叠偏好、完整地图入口和真实进度标记。室内投射室外入口；所有导航绘制只读状态，不改变存档、通行、碰撞、任务和奖励。

画布逻辑分辨率288×192，适配设备像素比，等比例展示1400×约933单位。HUD以原有约0.1秒更新节奏绘制；地形缓存最多24块，约6MB像素数据，折叠后不再绘制。首次展开才加载已有地图材质，失败时仍显示基础导航几何。

图标、比例尺和按钮使用正常文档流的弹性布局；未新增绝对定位。

## 验证结果

- `npm run build` 通过，含类型检查；仅有原有大体积构建块提示。
- `npx vitest run --maxWorkers=1 tests/minimap.test.ts tests/map-viewport.test.ts`：11项通过。包含只读状态、桥头投影、等比例、世界四角和室外入口。
- Chrome原正式页面5173端口，通过“继续旅途”进入现有风语城存档，确认地形材质和服务点显示；未向正式存档导入验收样本。
- 5312端口的生产构建，使用内置浏览器经正式文件选择器导入独立桥头样本。小地图坐标7100、1600，渲染器为材质地形；桌面1280×800与窄屏390×844均有运行截图。
- 鼠标操作小地图进入完整地图、关闭返回、折叠与展开均通过。
- 390像素窄屏页面内容宽390；小地图面板左199、右380，画布宽167；北向、按钮和图例在面板内，全部为正常文档流。比例尺随实际画布显示宽度改变。
- 室内样本通过正式导入后，显示“室外入口”，小地图坐标1060、790，没有使用室内坐标700、910。
- 静止桥头单次采样约0.4毫秒、12缓存块；正式城市单次采样约0.6毫秒、12缓存块。这些只说明本机当次绘制成本，不代表全游戏帧率、移动时首次生成耗时或长期性能。
- 本轮没有执行全项目回归；既有行囊、桥柱与战斗改动属于其他进行中的任务，不纳入本轮完成结论。

## 对抗式审查

VERDICT: PASS

P0/P1 BLOCKERS:

无。已检查界面调用关系、只读状态边界、室内与世界边界投影、像素比、正常文档流布局、素材异步加载、缓存上限、完整地图共享渲染器及关闭返回路径。删除的旧地图方法仅有两处HUD调用，完整地图继续使用独立舆图模块。完整地图的默认缓存上限仍为96，仅HUD使用24。

候选风险反证：新增渲染器不会写入存档，地图入口复用原事件处理；材质失败仍保留基础几何与动态标记；缓存有上限，不会因连续移动无限积累；室内采用室外入口，避免独立空间坐标误投射。未发现满足严重影响和真实可达完整因果链的P0/P1。

UNVERIFIED RISKS:

- 最终美术观感待用户验收。
- 长期移动、持续几何修订、素材加载失败、其他GPU和设备性能未完成专门实机验收。
- 正式城市与固定桥头来自不同浏览器和场景，不能作为性能前后对照。

NON-BLOCKING FINDINGS:

- 建筑采用实际占地的俯视投影，不是透视场景截图缩小；主角箭头表示最近行进方向，不表示静止攻击朝向。
- Chrome自动文件导入受到扩展的本地文件访问权限限制。本轮转用内置浏览器完成正式导入流程，没有修改扩展权限。
