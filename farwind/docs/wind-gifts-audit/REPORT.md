# 其他风赐特效粗糙问题调研

日期：2026年10月3日。当前目录61种风赐、18组共鸣；闪链已独立重做，黑洞斩使用独立动画。本轮逐项筛查其他59种风赐、18组共鸣，共77项。

## 结论与验证范围

存在类似粗糙问题。根源是多个能力复用少量几何模板，专属形态、材质和动作阶段不足。当前已经使用24个透明材质组件与连续曲面，旧六帧图集已退出运行；不是简单的换帧问题，单纯加亮或加粒子也不能解决身份重复。

完成77项共享绘制器在18%、42%、74%生命周期的231个阶段预览，保存七页浏览器截图，并检查正式触发、回流端点、路径、常驻状态及视觉预算。对照现有概念板和历史实战记录。预览使用固定位置与透明主体占位，用于看效果本身，不能冒充实战。少数长效果被小格裁切是调研布局限制，不是游戏裁切结论。

补充用当前工作树、隔离数据库和真实I按键走通命中，面板显示两次原生命中、一次派生命中。[当前预约截帧](i-current.png)落在蓄势期，没有捕获峰值，因此不作为剑风品质证据。八秒补录被并行代码热更新重载中断，没有获得完整本轮录像；未重复录制掩盖首次原因。[历史I实战画面](../wind-gifts-vfx-redesign/runtime/evidence/i-video-frame.png)只辅助观察组合轮廓，不代表此次工作树完整验收。其他组以当前预览和代码为依据，逐项正式存档触发仍未验证。

本次未修改生产特效、伤害、存档代码，正式用户存档未改动。下列美术优先级是整治排序，不是P0/P1严重性，也不是设计相似度的量化测量。

筛查排序：优先重做23项，中等修整43项，暂保留11项。共鸣已包含在统计内。

## 代码证据与反证

- [形态编排](../../src/game/entities/windGiftChoreography.ts)：重击共用压力、防御共用甲片与风垫、伙伴共用连接，共鸣多复用基础形态。
- [连续绘制](../../src/game/entities/windGiftMotion.ts)：压力是贴地椭圆和小折线；风垫受压量只改中心位置；尾流没有主体剪影；连接主要为曲线及小贴片；常驻标记大多是通用脚边弧线。
- [正式触发](../../src/game/systems/windGiftCombat.ts)：掠影在真实躲避后发出，但未保留旧角色姿态；残风确实沿真实移动路径发出；归息具有敌人到玩家的向内回流，不能说方向完全没有实现；回潮真实持续两秒。
- [主场景](../../src/game/scenes/World.ts)：基础风步尾迹是两段短线，不能补足掠影剪影。
- [教学演示](../../src/game/ui/windGiftPreview.ts)：L动作额外绘制三个淡色角色影像，属于教学展示层，不能当成正式掠影已实现剪影。
- [视觉预算](../../src/game/entities/windGiftVfx.ts)：四个近期效果和十八个活跃效果上限，以及共鸣优先策略已有保护；高持有量时某项未显示不能直接判为能力失效。未证明限流本身是缺陷。

## 建议顺序及审查

完整逐项方案见[风赐特效逐项修复计划](REPAIR-PLAN.md)，包含77项的目标形态、动画阶段、实现改动与验收场景，以及闪链和黑洞斩的回归要求。该计划尚未实施。

先做震刃／沉锋／山鸣破阵，再做初幕／缓创／风甲成幕、掠影／残风，随后做伙伴传递、控场和双刃共鸣。每组先确定专属峰值和收尾，再按图落实；不新增现有规则没有的范围、控制或伤害。伙伴效果应温暖传递，电弧感只属于闪链。

后续每组需真实按键录制触发前、峰值和收尾，检查单项、组合、简化、降闪与高持有量，核对主锋、敌方前摇、人物和血条可读性。全目录预览不能代替以上验收。黑洞斩本轮没有新的艺术质量结论；闪链参见独立实机记录。

VERDICT: PASS

P0/P1 BLOCKERS：无。新增调研页只读目录并独立绘制，不读写存档、不触发伤害，生产逻辑未改；没有发现满足可达路径和严重影响要求的P0/P1。美术差距均属于非阻塞问题。

UNVERIFIED RISKS：其他风赐逐项正式存档实战峰值、组合遮挡、长期设备帧率未完成本轮验收。补录热更新中断，结束时源码指纹不能把历史录像转换为当前构建验收。

NON-BLOCKING FINDINGS：上述形态重复、受压无变形、主体残影缺失、共鸣辨识度和回流过渡问题；自动截帧可能选中蓄势期，不能单张截图就宣布峰值合格或失败。
