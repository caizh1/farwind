# 停运行商与城墙外出生点修复验收

日期：2026年10月5日。范围：未通商的行商位置、门前怪物出生位置、普通商路遭遇与裂牙巢穴的关系。保留工作树既有城防第五版等改动；本轮没有提交、推送或部署。

## 问题与修复

停运逻辑原先仍用跨城道路节点寻找返摊路线：旧档中滞留道路的行商会沿商路回摊，城市驿站的室内坐标也会误参与室外长距离返摊计算。现在停运期间只允许所属城镇与驿站之间移动，构造、状态发布和每次更新均检查旧位置；非法位置归回所属本地摊位，保留生命、货物、库存、关系和旅程记录。四名行商恢复两地本地交易，清剿完成但未向将军回报时仍停运。

怪物原出生约束只检查旧商路矩形和碰撞，斜向扩建城墙后，墙内空地仍符合旧范围。现在所有普通商路新出生入口统一按实际城墙前缘加140单位缓冲筛选，同时保留地面碰撞、道路肩部与离主角距离检查。开通后的门前危险节点改到南侧支路（9250，2050）；小地图与舆图共用相同节点位置。已出生单位保留实际追击位置和伤势，不传送、不伪造击杀；它们仍可经过真实通道追入城市。
