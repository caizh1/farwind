# 岚铎统一对话页

日期：2026年10月5日。

## 变更

原将军页面调用通用服务弹窗，产生居中的浅纸色大标题、居中文本和通栏按钮。现在首次交谈、停运说明、接取、位置说明、清剿回报和领奖都调用现有 `Interface.dialog`。

沿用森林绿底、木质边框和底部叙事布局。人物身份固定为“守城将军 · 岚铎”，剧情阶段放在小标题，台词左对齐并分段；回应选项采用右侧编号卡片，奖励数量为次要文字，商路与待领奖状态独立显示。窄屏上下排列，短窗口维持两列，长正文和回应区分别可以滚动。编号是选项顺序，未新增数字快捷键。

选项、编号、按键提示均使用正常文档流的网格／弹性布局。按E或Esc只离开，接取、回报和领奖必须明确选择；保存事务、奖励凭据、存档版本与玩法数值没有改动。巢穴现场路牌使用路牌身份，避免把远处将军显示为现场发言人。

统一对话默认隐藏HUD和旧提示，因此新增页内反馈，容量不足或保存失败不会只出现在不可见的HUD中。普通无选项对话继续沿用原按钮及立绘规则；没有给将军借用其他角色的脸，也没有放大世界精灵充当立绘。
