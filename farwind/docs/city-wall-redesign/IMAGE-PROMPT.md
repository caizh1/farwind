# 城墙整体重设计图像提示词

生成方式：内置 imagegen；参考用户提供的当前实机截图。产物是设计概念图，不是已接入游戏的截图。

用途：游戏场景建筑重设计概念图。输入图片是《远风之地》当前实机截图，仅作为画风、材质、人物比例和城内外关系参考。请重新设计截图中的城墙、城门、塔楼和登城梯，输出一张精致清晰的16:9横向整体效果图，非实机截图，不带任何HUD、界面、文字、标题或标注。

核心目标：一眼看出这是高耸、厚重、连续的城防建筑整体。墙顶必须明显高于街道，城墙、门塔、城门楼、登城梯的结构真实连接，不能是互不相干的独立贴图。

构图：采用与参考图接近的2.5D手绘游戏俯视斜视角，稍微拉远镜头，完整展示一座西城门及其两侧连续墙段。左边是城外草地和通向城门的道路，右边是城内石板广场，保留参考风格的红瓦市政小楼作为右上角背景。城防线由画面上方延伸，经画面中部的城门组，继续向画面下方延伸；选择能清楚看到城门拱洞及城内侧厚墙立面的斜视角。城外到城内的道路必须穿过城门洞，有连续可见的路面。画面构图应让高墙立面和门洞都清楚可读，不要让塔楼遮住整个城门。

建筑：浅米灰色石砌城墙，墙高约普通人物身高的3至4倍，墙顶宽约2至3个人，墙身底部厚重略向外收坡，立面有大块砌石、数道完整水平石腰线、少量合理的厚实扶壁和箭窗。必须露出宽阔、完整、纵向落到地面的墙身立面，不能画成铺在草地上的走道，也不要以几根斜线冒充立面。墙顶步道有前后女墙和稀疏垛口，少量守卫站在上面作为高度参照。

连接结构：两座宽厚的方形门塔嵌在城墙线上，塔身与墙身石砌相咬合，共用连续基座。墙顶步道直接接进门塔中层平台的门口，同一标高，无缝、无空隙、无突兀断头。两座门塔之间是有厚重石拱承重结构的城门楼，门楼上方是与两侧墙顶等高且连续可通行的守城平台，平台直接连接两座塔楼。下方是一个高大、深邃的贯通拱形门洞，洞内能看见地面和另一侧的亮光，打开的木门贴在洞侧，吊起的铁栅门嵌在门洞上缘。门楼两侧必须接到塔楼和城墙，不悬空、不分离。塔楼比墙顶再高一层，用参考图的小面积红瓦尖顶和蓝金旗帜点缀，塔身矮壮有承托力，不要瘦长独立灯塔。

登城梯：城内侧一座石制宽楼梯依附于墙体，底端确实落在石板地面，顶端接入与墙顶步道同高的宽平台，平台与门塔入口相接；有石栏和实体承重，绝不出现楼梯抵在墙的侧立面却无法上墙的结构错误。

画风与光照：忠实延续参考中的温暖中世纪奇幻、细腻手绘2.5D建筑素材、浅石墙/陶红瓦/蓝金旗帜配色。建筑边缘干净，适合作为游戏美术定稿参考。左上方日光，墙顶偏亮，城内侧立面偏冷暗，门洞有清楚的深度遮蔽，墙脚投下连贯的柔影，塔楼投影与墙体相连。地面的旅人与墙顶守卫使用参考图的相近身高，通过人物比例让高差明确。保留开阔的可行走道路，不额外增加不相关装饰，不添加水印。

验收重点：完整门洞可辨认；道路穿洞；墙身有显著高度与厚度；连续步道进入塔楼；门楼连接双塔；石梯连接同高平台。建筑是一套协调的整体，而不是塔、墙、门各自悬空摆放。
