# 图像生成与排版记录

生成工具：环境内置 imagegen。三张美术底稿分别独立生成，之后使用原生 HTML/CSS 排版真实中文和技术示意。

底稿不是最终交付界面，也不是游戏截图。最终设计图使用现有旅人立绘，不使用生成底稿里的重绘人物。

## 底稿提示词

### A · 人物档案

生成《远风之地》游戏内「旅人技艺」人物能力展示面板的高保真美术底稿。方案名称：旅人档案。目标尺寸1440×900，严格横向8:5构图，正交平面UI，非透视实体展示。参考图1为当前游戏界面，参考图2为已有旅人立绘：棕发、红围巾、灰棕旅行服，保持主角形象一致。图3为已实装装备页，延续它的细腻手绘纸质、旧金边线和墨绿按钮。绘制一张安静、克制、可读的游戏面板底稿：画布外围墨绿半透明遮罩，中间覆盖宽1336高800的纸质人物档案册。左侧约248宽为墨绿布面竖向人物档案区，含原有旅人形象；中间约320宽暖纸目录栏，四个轻分隔条目；右侧約700宽更浅的暖纸详情，顶部技能标题留白，中央效果示意留白，下方学习经历留白。用非常克制的叶纹、风痕、旧金细边和红色布书签，避免复杂雕饰与纹理干扰。不要生成文字、数字、字母、图标、技能树、经验条、升级按钮、商城、巨大圆盘。所有功能文字将以真实中文后期排版。不要改变主角服饰、脸型、颜色；不要增加伙伴。图中只有一套面板，不包含多个方案，不要浏览器或设备边框。该图用于独立设计样稿，尚未接入正式游戏。

### B · 双页旅途手册

生成《远风之地》游戏内人物技艺面板的高保真美术底稿。方案名称：双页旅途手册。目标1440×900，横向8:5，正交平面UI构图，非透视实体展示。参考图1是现有装备页纸质和红围巾人物形象，图2是现有旅人立绘，保持相同主角脸型、发型、红围巾、灰棕衣物，不画新角色。参考图3是现有村庄游戏氛围。画面是一册打开的暖纸双页旅行手册，书册在墨绿游戏遮罩上，边界约四十像素；与人物档案方案明显区分：两页占幅接近左40%右60%，中央有细书脊、线缝及自然纸页阴影。左页上方用已有旅人立绘的小型摘要，左页下方四条阅读目录与墨绿、红布页签；右页上方为选中剑风的标题空间和淡雅演示空白，中部永久五阶段的五个小离散节点，下方三段学习经历及下一条线索区域。只画细腻但低对比度的纸页、墨绿书签、旧金线、细小风纹，重点是旅行记录，不是后台。所有内容区域必须干净宽敞，图标、文字将后期用真实中文排版；不要画任何文字、数字、字母、假符号、技能点、经验条、升级按钮、圆形天赋树或商城。不要密集卡片，不要大装饰遮挡正文。只有这一张独立方案，不能多方案拼图；不要浏览器、设备边框。只用于设计目录，不接入正式游戏。

### C · 紧凑人物页与图鉴卡片

生成《远风之地》游戏内人物技艺图鉴的高保真美术底稿。方案名称：紧凑人物页与图鉴卡片。目标尺寸1440×900，横向8:5，正交平面UI，没有透视、浏览器和设备边框。参考图1为现有游戏装备页，图2为清晰的现有棕发红围巾主角立绘，保持形象与服饰；参考图3为真实村庄场景。与竖向档案和双页书册两个方向做出结构差异：一块薄纸质图鉴板铺在模糊墨绿游戏背景上，整体克制、明亮、轻便。左上横向紧凑人物摘要，使用已有立绘的头像大小；左下为两列两行的四张图鉴卡，墨绿的选中卡与暖纸普通卡；右侧约680宽完整的浅暖纸技能详情区域，顶部技能名称空白、作用示意空白，中下方五个离散成长节点和学习经历空间，右边缘细金阅读标记。配色墨绿、暖纸、旧金、红围巾小点缀，细腻手绘纸页和风痕，不要装饰遮挡正文。所有文字与技术图形将后期精确排版，因此禁止生成文字、数字、字母、emoji或伪字符。禁止经验条、技能点、升级、购买、装备技能按钮、巨大天赋圆盘、科幻光效、运营后台和技能商城。图中只放这一张方案。此图仅用于设计样例，不代表已实装。
