# 攻击穿身修复验收

日期：2026-09-29。范围：当前本地源码的主角攻击前冲与方向移动。

## 根因与修复

攻击前冲与方向移动原先只检查地形和静态障碍，没有检查活敌身体。修复前的确定性复现中，敌人在前方35像素，四次出招累计前进63像素，主角穿到敌人身后。

在现有位移扫掠中加入活敌身体的连续接触计算，并精确截停在首次接触处。普通敌人的脚底接触间距为40像素，依据主角34像素与敌人45像素的阴影宽度校准；首领使用56像素。普攻前冲和正常方向移动共用这份计算。死亡和禁用目标释放占地；已有重叠允许向外退开。

## 验收证据

- 相关逻辑测试：8组、223项通过。包括四向连续出招、下一轮第一刀、30/60/120帧与抖动步长、连续扫掠、切边绕行、已有重叠退出、自动反斩、多敌阻挡、死亡释放、风步及地形回归。
- 浏览器：持续按住向敌人的方向键，真实输入三段普攻；灰冠孢卫与苔甲守卫两个场景通过。活敌最小间距均为40像素，越到敌人身后采样数均为0，正式命中阶段均为第一、第二、第三段。
- 孢卫死亡后，主角正常走过其原站位，证实死亡释放占地。
- 类型检查、独立生产构建、差异格式检查通过。浏览器验收使用当前开发源码；生产构建通过不代表已完成生产包试玩。
- 完整数据与源码摘要见 `evidence/validation.json`；具体采样见 `evidence/spore.json`、`evidence/guardian.json`，对应截图为 `spore-after.png`、`guardian-after.png`。
