# 东侧首领攻击增强验收记录

本轮仅调整缚枝祭主。第四版模型、八方向动画、七个招式、双镰节奏、单次伤害与阶段转换保留；正式战斗接口继续统一结算伤害和碰撞。

## 已完成的规则

| 项目 | 结果 |
| --- | --- |
| 双镰 | 每击半径 190、总角度 120°；第一／第二击步进仍为 24／18，命中间隔仍为 680／610 毫秒。预警与刀气读取正式扇形。 |
| 八向光柱 | 判定全宽 28、长度 430、持续 5000 毫秒，屏幕坐标中顺时针每秒 36°。同一目标八束共享 1000 毫秒冷却，伙伴与主角分别记录。 |
| 三环 | 固定半径 140／250／360；同时刻线、随后沿各自轨迹追爆。刻线带宽 12、追爆带宽 26，每圈每目标每段最多命中一次，圆心和圈间空隙安全。 |
| 招式时序 | 蓄力 1200 → 光柱 5000 → 换式 250 → 刻线 1450 → 蓄爆 500 → 追爆 1450 → 收势 900 毫秒。完整时长 10.75 秒。 |
| 抗打断 | 普通伤害不取消施法、不插入受击动作；普通和完美弹反仍能取消双镰连招并进入失衡。破茧、击破祭印仍产生暴露和减防，施法及危险区继续。 |
| 命中停顿 | 仅命中东侧首领的普通攻击不请求全局命中停顿；扣血、闪光、音效保留。弹反反击反馈保留。暂停与原有减速继续使用正式战斗时钟。 |
| 黑洞 | 东侧首领每秒牵引 130，入场与转换时保护；多个裂缝选择最近的有效裂缝，只执行一次。复用扫掠、墙体、实体和追击边界；排除首领自身占地，避免自碰撞阻止牵引。 |
| 原点与步态 | 光柱跟随真实首领位置；进入刻线时锁定圆心，后续灼痕不随首领滑动。强制位移不计入自主步态、转向和攻击进度。 |
| 保存 | 新激光快照使用可选样式版本 2，保存三环、圆心与相对命中冷却；旧快照继续完成 600 毫秒光柱、230 单环。总存档版本未增加。 |
| 资源 | 原图集与透明格式、内容摘要未更改。读档优先预热正在施放的片段，加载和缓存释放保持 192 MiB 上限。三环只占一个危险区。 |

## 正式运行验证

开发对照端口 5367 使用本轮开始前的源码，5368 使用增强版。各样本通过游戏可见的正式导入入口载入，之后执行正常键鼠、暂停、保存和刷新。没有直接改写运行中的生命、位置、招式或弹反状态。黑洞通过独立开发面板确定触发随机数，后续位移、伤害、阻挡全部走正式世界。

共覆盖 17 个浏览器用例，分批完成：旧版、新版第一／第二阶段、PNG、持续施法中的黑洞、四裂缝重叠、护心结茧受击、普通／完美弹反、障碍边缘双镰、光柱期间击杀、真实离开据点触发撤退、低闪光与简化装饰、祭印击破、完整旧版赤环／新版赤环／双镰录像、树墙边的牵引阻挡。新场景的关键出手缺帧均为 0，未记录脚本异常。

黑洞样本累计牵引约 110.40 世界单位，最多四个裂缝同时存在；按采样时间差计算的牵引速度上限约 130。树墙样本保留实际阻挡，没有穿越障碍。暂停时模拟时钟保持不变；刻线期间保存刷新保留三环、战斗尝试号和固定圆心。普通／完美弹反均通过正式 K 键产生成功记录，而非强制设置结果。

护心茧用例在持续段实际受到近战伤害，施法保持、普通命中停顿为零。祭印用例使用两处残血祭印初始条件，正式攻击击破后仪式持续，危险区未清除。死亡用例在光柱持续段通过普通攻击击杀，撤退用例通过方向键及空格疾跑离开据点并等待正式撤退时钟，两者都清理危险区。

这些是可复现的战斗初始样本，不代表从村庄开始的一整条自然旅途。没有向 5173 导入测试存档。
