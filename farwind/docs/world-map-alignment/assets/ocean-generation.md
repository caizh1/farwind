# 外海材质生成记录

## 用途与边界

用于世界大陆图外侧海面，使外海与本轮动漫手绘大陆统一。参考大陆原图的外海蔚蓝色，不采用内陆湖泊的浅绿松石色。不参与区域几何、坐标、碰撞或导航。

## 生成与输出

采用内置图像生成工具，引用 `public/assets/world-map/aligned/continent-source.png`。生产图 `public/assets/world-map/aligned/ocean.webp` 为 512 × 512 像素；源图 `public/assets/world-map/aligned/ocean-source.png` 为 1254 × 1254 像素，保留原始输出。

目视检查为均匀青蓝海面与细小水彩笔触，没有云、岸线、岛屿、角色、文字或大涟漪。要求可平铺，实际地图中的接缝及外围衔接由主流程验收；没有只凭生成要求宣称数学无缝。

## 完整生成输入

用途：动漫手绘世界地图外侧的生产用海面重复平铺纹理。输入参考图仅用于提取画风与外海色彩，严格只画海水，不能复制大陆、云、岛屿或岸线。生成全新正方形海面材质，细小而柔和的水彩动漫波纹，薄纸感，边到边填满，图案四边自然连续可重复平铺。色彩必须取参考图最上方中部以及最下方中部的外海青蓝：较深但明亮的蔚蓝底色，微小浅青蓝笔触，整体中等饱和。不要使用内陆湖泊的浅亮绿松石颜色。纹理均匀、低对比、尺度细小，波纹仅为很短的横向弧形与淡淡漫涂，没有明显焦点，没有中央亮斑，没有明暗渐变、没有边缘暗角、没有大涟漪、没有粗白线或高对比波浪。2D动漫手绘、水彩与清晰柔和的平涂相结合，匹配参考的清新冒险世界地图。全画面只允许蓝色海水与细小笔触，不允许云、岸线、沙滩、岛、山、陆地、船、人物、动物、文字、数字、标记、边框、水印、地平线、3D渲染、照片写实、高反差浪花。
