# 村庄泉水交互修复验收

核对日期：2026年10月5日。本轮只修复泉水交互和状态提示，不改变恢复数值、村庄碰撞、安全门禁或存档结构。

## 故障路径与修复

原来的世界交互先调用战利品领取，再执行画面显示的设施或人物目标。因此，泉水旁存在掉落时，即使画面提示“饮用泉水”，按一次 E 也只会领取掉落；背包已满时甚至持续无法走到饮用分支。提示与实际动作不一致。

修复后，E 优先执行画面已经选中的交互目标，无目标时仍能领取室外战利品。已清剿营地的风忆入口保留原有优先级。泉水提示与恢复事务共用同一个限制检查，交战、守村事件、试炼、动作未结束或生命体力已满时，直接在泉水旁显示具体原因；实际恢复仍经过同一门禁。
