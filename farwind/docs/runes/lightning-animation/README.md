# 动态闪电动画

## 本轮修正

此前雷电主形体是 `thunder.webp` 整图渐隐，用户反馈属实。本轮移除其正式加载与绘制，改为沿折线传播的动画；旧图片和上一轮截图仅保留为历史素材，不能作为本轮结果。

正式世界、符文详情和试验场共同调用 `runeLightning.ts`，覆盖雷触、感电、雷云冠、九霄雷诏，以及雷潮、雷雾、雷针和寒雷共鸣。普通雷为青白电流，雷诏与融合落雷使用金白通道；高度、主干宽度、分叉数量按事件形态区分。

1. 导电刻纹收束到实际落点；雷针配方保留针形预兆。
2. 预兆末尾最多 90 毫秒，先导雷头逐段向下传播，接地前不画贯穿地面的通道。
3. 伤害提交帧接地，回击沿主通道向上传播，48 毫秒到达顶部。
4. 侧枝按不同延迟展开；放电时细通道每 32 毫秒重排，112 毫秒后产生更细的第二次回击。
5. 接地电流在实际特效半径内爬行，火冠裂片抬升、下落；雷潮保留同一条电浪形体。
6. 216 毫秒后主通道断成独立残弧，每段收缩、上移，最迟在接地后 410 毫秒消散。

简化模式移除侧枝和次要辉光，保留先导、主干、回击及接地。低闪光将电光强度降低至 53%，不增加全屏闪白或震屏。没有新增定时器、Tween、监听器或逐帧 Phaser 渲染对象；复用原有 Graphics。每次放电的几何数量有自动化上限检查。

伤害、触发概率、学习进度和冷却未调整。普通雷击预兆仍由战斗配置解析（当前 160 毫秒），雷针仍为 300 毫秒。只把普通雷击的视觉存活时间延长为预兆加 430 毫秒，避免残弧被旧寿命截掉，攻击任务仍在原定时刻执行。详情画布增高并用镜头变换容纳完整雷柱，命中坐标和正式渲染不变。

## 实机证据

- `after/motion.json`：一次正式 J 攻击，记录同一事件下降、接地和残弧相位；仅有一次原生命中和一次雷击，未请求旧雷柱图片。截图接口有耗时，拍摄前后年龄原样保留，不能假定文件名就是截图瞬间的相位。
- `recordings/single-lightning.webm`、`single-lightning.mp4`：同次雷击的真实浏览器连续录像，正常速度。
- `recordings/legend-lightning.webm`、`legend-lightning.mp4`：五绝世实际装备，真实三连触发雷诏；短片截取原录像第 3 秒起的 5.5 秒，正常速度，没有补帧或合成特效。
- `recordings/mist-lightning.webm`：冰雷酿域真实连续攻击与融合落雷。
- `recordings/production-lightning.webm`、`after/production-lightning.json`：生产构建中新游戏，采集取得雷触，R 装备，走到木桩转向后 J 攻击。没有赠予、模拟命中或绕过剑风学习。
- `after`：六套配装、雷柱、凰心回归、简化模式、正式获取、存档、归风、场景切换和压力场截图及诊断。

录像由浏览器自动录制，尺寸 800×450、25 帧/秒，不包含音频；实际游戏和截图视口为 1280×720。内置浏览器也通过实际控件装备、实际 J 连击验证，详情页滚动后检查完整雷电预览，最终保留五绝世木桩配装。

## 执行结果

- `npm run typecheck`：通过。
- `npm run test:runes`：68 项通过（59 项正式符文判定回归、9 项演出检查）。
- `npm test`：56 个测试文件，1086 项通过。
- `npm run build`：类型检查与生产构建通过。
- `RUNE_EVIDENCE_DIRECTORY=docs/runes/lightning-animation/after npx playwright test --config tools/playwright-rune-elements.config.ts --grep-invert rune-painted-icons`：17 项通过，4.5 分钟。排除与本轮雷电无关、会覆盖旧图标验收截图的专门图标测试。
- `git diff --check`：通过。

首次单次雷击分镜检查未捕获残弧相位：连续截图调用耗时跨过短相位，且旧视觉寿命会提前截断余电。改为读取相位后拍摄并保留前后时间，延长纯视觉寿命后通过。首次几何单测选择的两个时刻属于同一个 32 毫秒步进，调整取样跨越步进后通过。未用重试掩盖失败。

全量测试会覆盖三份既有居民性能证据，本轮已还原运行前备份；未覆盖其他工作区改动。没有提交、推送或切换分支。

## 性能与边界

本机 macOS 27.0、arm64、Mac17,9，Chromium 153.0.8010.12、Metal WebGL，1280×720，像素比 1，开启录像；内置浏览器同时打开游戏。16 敌压力场 60 次 J 输入后，连续五次重置并交替雷雾与五绝世配装，每轮 24 次 J。

实测帧间隔中位数约 16.7 毫秒，95 分位为 33.3～49.9 毫秒，最慢 216.7 毫秒；场景对象 686～699，现有凰焰等位图材质池高水位 60。末轮尚有 18 个合法待执行攻击任务，后续生命周期测试通过。短测未观察到逐轮持续增长，不能据此声称稳定帧率、零泄漏或其他设备达标。原始数据见 `after/stress.json`，汇总见 `performance.json`。

本轮没有改音效或其他流派美术，也没有宣称达到《哈迪斯》的最终制作质量。用户的动画观感仍需本人确认；工程回归通过不等于美术验收通过。
