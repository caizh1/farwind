# 符文战斗演出升级

> 历史记录：用户指出整张雷柱渐隐缺少真正的落雷动画，后续已替换为动态传播、回击、分叉和残弧。当前雷电实现与实机证据见 [动态闪电动画](../lightning-animation/README.md)，下文雷柱图片与相关材质统计属于上一轮。

本轮针对实际游戏中雷电、凰焰和关联共鸣过于单薄的问题实现。参考方向是短预兆、清晰主形体、集中命中与快速消散；素材为 Farwind 原创手绘，未导入其他游戏资产。参考入口：[《哈迪斯》官方游戏页与演示](https://www.supergiantgames.com/games/hades/)。

## 已接入

- 雷触、感电、雷云冠、九霄雷诏：导电预兆、手绘分叉雷柱、落点裂片与残电。雷诏保留三轮落雷和独立终结雷柱。
- 不灭凰心、凰镜涅槃：化烬收拢、金赤双翼展开、真实范围火环、飞焰镜羽和羽片消散。镜羽格挡与重生分别采样，不重复播放重生蓄势。
- 海啸雷狱、雷酿风暴、雷矢贯星、寒雷长劫：电蛇沿浪脊流动；雷雾中央只显示电云，目标处才落雷；雷针保留延迟；寒晶包住残电。
- 潮浪与返浪改用有厚度、收尖和浪冠的手绘形体。共享羽片、猎星和剑域剑身增加明暗面，保留状态层数可读性。
- 世界、符文详情预览与隔离试验场共用绘制及飞行逻辑。三张正式透明 WebP 共 486346 字节；图片与哈希见 `assets.json`。

## 判定与生命周期

伤害数值、触发概率、冷却、技能学习门槛与装备规则没有调整。雷击继续使用正式战斗配置的预兆时间；凰焰反击仍在 180 毫秒后提交，重生火环仍在 360 毫秒后提交。命中反馈新增已提交标记，避免再播放一次蓄势。潮汐与随后落雷保留两个独立事件，浪冠方向取真实角色到目标的方向。

绘制只读战斗时钟，不新增伤害计时器、Tween 或监听器。材质 Image 按高水位复用，结束隐藏，清场立即隐藏，场景销毁时全部销毁；共享纹理由 Phaser 管理。特效层位于 Boss 预警与状态标记之下。简化模式减少次要裂片，降低闪光减少亮芯透明度，保留主雷柱、双翼、攻击范围与全部判定。

## 本轮验证

- `npm test`：56 个文件、1084 项通过，包含新增 7 项演出时序测试及原有战斗、任务、伙伴、输入、保存回归。
- `npm run build`：类型检查与生产构建通过。原有大于 500 kB 的分包警告仍存在。
- 真实浏览器：六套配装、装备与预设保存、Boss 重生、正式获取与读档、归风、十六敌压力场、切场景、生产隔离共 12 项通过；新增四项雷柱／凰心分镜／低闪光／生产雷触攻击检查通过，共 16 项。生产雷触攻击专项另见 `runtime/production-lightning.json`。
- 运行截图见 `runtime` 与 `after`，原版基线见 `before`。`sources` 是素材原画，不能当作运行证据。视频 `runtime/thunder-short.mp4`、`runtime/phoenix-short.mp4` 从真实浏览器录像截取，正常速度，无合成画面；自动录像不含音频。
- 首次低闪光测试失败：选项保存期间输入锁拒绝紧接的 Escape，页面仍停在设置中，J 没有进入战斗。改为点击正式返回与继续按钮并等待游戏模式。保留 `first-browser-attempt/settings-pause.webm`；原始追踪位于 `/tmp/farwind-rune-combat-settings-pause-trace.zip`。

## 性能与边界

实测环境为本机 macOS、Chromium 153、Metal WebGL、1280×720、像素比 1，开启录像；同时存在用户原有试玩页。十六敌压力场及五次重置采样的帧间隔中位数约 16.7 毫秒，95 分位约 33.3 至 49.9 毫秒，最慢帧 216.6 毫秒。材质池高水位为 50 个，场景对象 682 至 692；这次短测没有持续增长，不能据此宣称稳定帧率、长期零泄漏或其他设备达标。原始数据与统计见 `after/stress.json`、`performance.json`。

本轮重点是雷、凰焰、潮汐和共享命中形体，其余流派沿用现有程序化演出并受益于羽片、剑身与猎星改进；没有声称把所有流派重新绘制成逐帧动画。最终美术喜好、长期游玩和其他设备性能待用户验收。本轮未制作新的音频资产。
