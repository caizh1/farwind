| 品阶 | 材质与轮廓 | 额外辨识 |

| 中阶 | 切角银质双框 | 上方双纹、双叶底纹 |

中心采用新绘制的实色形体、材质渐变、高光和雕刻符线。四品阶框型在灰度下仍不同。图鉴图标增至六十八像素，详情八十八像素；HUD 保持三十像素及原六十四单位画布，原冷却扇面和蓄积刻度继续叠加。空槽改为单独的空槽图案。所有图标位于正常文档流。
