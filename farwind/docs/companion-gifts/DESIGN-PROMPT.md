# 设计图生成提示词

生成方式：内置图像生成工具。参考图为用户录屏截帧，仅参考游戏区域的绘画风格，不作为修改实机截图的目标。输出为概念分镜，不替代实机证据。

用途：游戏特效设计分镜（概念图，非实机）。以参考图的俯视2D手绘卡通游戏、草地石路、旅人、小宝和敌人为风格参考，只参考游戏区域，去掉浏览器和HUD。制作清晰的两行三列特效设计板，横向16:9，六格使用相同草地战场及角色比例，镜头略近但保持俯视角。所有特效均是局部的小型半透明锐刃光面、亮芯、少量碎光，不能遮住敌人，禁止任何贯穿旅人到敌人的长直连线，禁止屏幕大光圈。上行标题“递锋”：第一格“建立刃结”，旅人远程剑风已命中，敌人身侧出现小巧白金菱形刃结，两片细薄刀锋扣合；第二格“伙伴接力”，小宝真实攻击命中该敌人，暖金短流锋只在敌人附近展开，与白金刃结合成局部锐刃亮点，明确仅在实际伙伴命中时爆发；第三格“消费消散”，刃结断成三四枚小光屑淡散，敌人清楚可见，没有残留连接。下行标题“同心”：第一格“双锋汇入”，旅人命中时敌人局部两股短弧，一股珍珠银白一股温暖浅金，从两侧收束，小宝在附近旁观而非额外攻击；第二格“汇合亮结”，敌人命中点两个精致短新月光面扣合，白金核心微亮，轻微小光屑，半透明有切面，尺寸小于敌人身体；第三格“余光回收”，两股短弧向局部中心缩回并快速淡出，没有持续连线。画面顶部明确中文“伙伴风赐 · 局部特效设计”，底部小字“概念设计 · 不代表实机截图”。不要把伙伴风赐画成蓝色闪电；蓝色电弧属于闪链，应在此设计中排除。每个面板标注简洁中文，如上文逐字。精致、清楚、能用游戏几何渲染复现，保持原游戏2D美术质感，禁止写实3D景深。
