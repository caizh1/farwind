# 黑洞风赐追加强化与验收

日期：2026年10月6日。

## 生效规则

- 扩界原有每级增加20%伤害半径与裂缝大小，同时新增每级延长600毫秒停留；额外延时最多3000毫秒，与长夜相加。单独扩界三级持续3.24秒，扩界三级加长夜三级持续5.04秒，两项延时全部封顶时持续7.44秒。
- 裂界·黑洞斩沿用一级普攻40%／秒，每250毫秒跳伤一次；每次升级在单跳基础上加3点，单跳最多10点。普攻18时实际跳伤为1.8、4.8、7.8、10，飘字显示2、5、8、10；六级及更高等级仍封顶10点。
- 触发率仍为一级5%、每级增加一个百分点、最高10%。跳伤封顶后仍可升级触发率。发射时固定伤害、范围与时长，之后升级不修改已发射裂缝。
- 大步长逐跳结算，保留不足250毫秒的余量；离开范围与到期只结清已停留时间。墙体、外围只牵引、首领位移免疫、四裂缝上限和死亡清场沿用已有约束。
- 沿用既有风赐编号、升级与保存格式，已有存档无需迁移；正式战斗、教学说明、预览时长和隔离试玩同步生效。
