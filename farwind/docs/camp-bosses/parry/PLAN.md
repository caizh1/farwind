# 首领弹反踉跄强化

已确认四段分镜：接触定格、失衡后仰、踉跄撑地、收势站稳。覆盖孢心巢母、荆冠猎王、崩岩獠王、缚枝祭主。

## 修复前基线

当前首领播放失衡素材，但后仰反馈没有接入渲染；普通与精准弹反的六百和八百毫秒硬直被统一按八百毫秒取帧。先保留原构建和真实键鼠复现录像。

## 实现边界

复用已有独立姿态、脚底锚点、战斗时钟和图形对象。表现采样不得改写根坐标、碰撞、伤害、弹反窗口、硬直时长或保存结构。精准弹反加大姿态变化。远处只弹开弹丸时，首领不得凭空踉跄。已释放的其他弹丸及地面攻击保持正式生命周期。

## 验收

四种首领各覆盖普通与精准弹反；比较弹开、撑地、恢复的帧和精灵变换；检查暂停、保存后恢复、镜像与上下朝向、死亡清理、阶段转换优先级、恢复出招及非弹反攻击。固定姿态预览用于比对素材，实际战斗使用新游戏、领取补给、购买装备、步行、清驻守与真实键鼠。

通过逻辑、构建和浏览器检查不等于用户美术及设备听感验收。全量性能未测时单独注明，不宣称达到生产力节省指标。
