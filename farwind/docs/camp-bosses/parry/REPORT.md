# 首领弹反踉跄强化验收

已按确认分镜实现目前全部四种战斗首领：孢心巢母、荆冠猎王、崩岩獠王、缚枝祭主。正式弹反触发接触定格、失衡后仰、踉跄撑地、收势站稳四段动作；精准弹反的姿态幅度为普通的 1.4 倍。四种体态分别伴随孢子、爪下轻尘、苔屑碎石与枝叶。

## 修复与范围

原首领失衡按八百毫秒均匀取帧，普通弹反的六百毫秒硬直没有完整播放收势。现在依据真实弹反持续时间分段取帧，并在校准的脚底锚点上加入倾斜、压缩和失衡摆动。普通反斩的受击旋转与失衡姿态叠加，避免覆盖后仰。

表现只采样正式战斗时钟，保留原有普通六百、精准八百毫秒硬直、五十五和七十五毫秒停顿，以及原有伤害、击退和碰撞规则。远处仅弹开弹丸不会使首领凭空踉跄。死亡、登场、阶段转换优先；已释放的其他弹丸和地面攻击沿各自生命周期继续结算。碎屑复用原有两个图形对象，不增加粒子计时器或保存字段。
