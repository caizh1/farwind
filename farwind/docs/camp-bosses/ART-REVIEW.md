# 首领素材与运行画面审阅

四张独立设计板先于图集制作，分别包含正面、背面、侧面、四技能姿态、半血变化与人物比例。随后生成十二张透明动作表，机械打包为四张图集；向左由角色显示层镜像。显示尺寸、每帧脚底根和攻击几何分别配置。

图集含孢母一百七十四、狼王一百六十五、獠王一百七十四、祭主一百七十一，共六百八十四个独立姿态。摘要检查没有复制帧。没有把普通精英放大替代专属首领。

固定预览检查了三方向、七动作行与完整主体。首轮等宽切分曾切断跨格肢体，已改为按透明间隙切分主体；孢母首轮背面误画成正面，已保留首因并重新生成背面。详见素材修正记录。

实际运行检查覆盖四位首领的第一阶段、第二阶段、攻击、位移、弹反受制与场景比例。运行截图和录像抽帧显示独立菌冠与根肢、荆冠狼身、岩甲宽獠、镰枝与风核。地面根随正式碰撞后的实际位移更新，身体技能没有用瞬移替代。当前证据包含完整两阶段录像，并保留候选数值的旧样本。

已审阅固定预览与实际运行动作，不表示六百八十四帧都逐帧经过交互触发。主观美术喜好、最终手感与其他目标设备的纹理压力仍需用户验收。
