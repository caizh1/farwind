# 首领命中与远程可见度修正

## 根因及修正

原来的起手距离只有远程三百三十像素、近身一百三十像素等几档，实际伤害却读取另一套几何。孢母横扫只能达到一百一十五像素加十二像素移动；狼王扑击只能达到一百七十像素移动加三十六像素扇形；爪击半径一百一十五像素；侧跃反扑为一百八十像素移动加三十八像素扇形，还需承担侧移。孢母、獠王扩散环最多到达二百四十、二百五十像素。于是部分招式在实际打不到的位置启动，静止目标也能避开。首领现在从同一份技能规格推导起手距离，侧跃计入横向距离，留八像素余量，范围不足时先走近；没有扩大伤害判定或在锁向后追踪玩家。

祭主第一轮四颗针弹的偏角原为负零点七五、负零点三五、正零点三五、正零点七五，瞄准方向永远位于中央缺口。在二百八十像素处，最近弹道距离静止目标约九十六像素，远大于十四像素碰撞半径。现在一颗针沿瞄准方向发射，通行缺口位于侧面；第二阶段仍保留错位的第二轮。孢母第二轮错位弹幕、安全内圈、甩尾前方和护心结茧的防御用途保留，不能把这些预期安全条件误报为所有技能都必须伤害玩家。

原喷口在身体前方二十四像素，弹丸半径十四像素，距离身体八像素的玩家已在弹丸身后，弹丸向外飞后始终无法接触。首领喷口改为前方十四像素，使贴身位置也与首颗弹的接触范围相接；发射和预测共用相同喷口函数。普通孢卫、独立母孢精英仍使用原二十四像素喷口。

原首领弹丸复用了二十像素的绿色孢子图，在草地上难辨，而且可能被树冠和角色遮住。孢母改为三十六像素亮橙圆弹，祭主改为四十像素玫红针弹，两者都有亮色核心、深色边缘、淡光晕和拖尾；圆形与针形也提供形状区别。主要实体轮廓仍对应十四像素碰撞半径，外缘光晕不增加伤害范围。发射预警使用同类颜色与深边描线，只画真实弹道，缺口不填满。首领弹丸在必要战斗信号层显示。两张纹理只生成一次，拖尾复用一个图形对象，结束、撤离和重开沿用原实例生命周期。

## 验收证据与边界

固定无障碍的静止目标样本先运行原代码，十项中九项失败，保留原攻击数据。相同十项断言修复后通过，再增加从三百三十像素出发的真实首领导航、两阶段接触、喷口预测、锁向后躲避与预期安全用途，共四十一项通过。相邻战斗、架剑、远程弹反、小宝、追击、存档和遭遇逻辑回归共十二个文件、三百二十八项通过。类型检查、正式构建通过；实测包与当前全部源码重新构建后的十五个入口、脚本、样式和图集摘要一致，源码无漂移。

四位首领均从关闭测试授予的正式构建正常新游戏出发，通过键鼠领取补给、购买、装备、步行和清驻守；随后停止移动、攻击和架剑，只正常服药。四种技能均实际出现，记录了身体、弹丸和地面接触与生命变化。原祭主构建的实际站桩样本没有第一轮齐射伤害，修复后同类样本实际扣血，画面纹理和显示尺寸检查通过。截图与录像位于 evidence/accuracy 下对应首领目录。

第一次狼王、獠王脚本在完整首轮结束后仍要求观察二十四秒且不能死亡，药剂耗尽后玩家正常死亡，首领满血重置、驻守保持死亡。保留这些状态、截图、录像和原因记录。脚本改为完整首轮结束即完成观察；如果正常死亡，必须核对回村位置、满血重置、战斗编号和已清驻守，再核对四技能和伤害，不能将未观察到技能或未发生伤害的样本判为通过。重新实测狼王、獠王通过，原游戏伤害与重置规则未为脚本修改。

完整独战与难度的最新结果见 evidence/accuracy/balance。两条均完成第二阶段、真实弹反、地面躲避、暂停保存重开、击杀后的地图和委托联动、恶意一次结算与清除后重开。孢心巢母为158.6秒、消耗一瓶药剂、受到34点伤害、成功弹反17次；缚枝祭主为108.4秒、消耗一瓶药剂、受到60点伤害、成功弹反25次。孢母这一固定样本略超原参考150秒上限，难度判定未完全达标；祭主样本在参考范围内。没有为了满足时长或站桩脚本而改血量、扩大命中或修改死亡规则。此前八条完整击杀、同行和夜袭记录属于更早的构建，保留为历史证据；本次不能用它们宣称四位首领的全部双路径耗时已重新校准。主观美术、识招手感、其他设备和混战峰值性能另列未验证。

原独立裂岩林豕测试当前单文件为两项通过、一项失败，失败仍在 canChargeThroughStone 前置判定。它把石障编号当作射线豁免传给 clearMeleeLine，但射线只接受训练底座的豁免，石障继续阻挡。未修改该断言或拓宽全局穿透；本次据点獠王仍使用真实撞墙规则。
