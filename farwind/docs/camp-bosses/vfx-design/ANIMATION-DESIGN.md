# 四据点攻击动画与特效

先用 imagegen 生成四张独立分镜，再接入现有技能姿态与战斗时钟。参考角色原设计板、最新游戏截图，保持俯视手绘森林风格。设计板是视觉方向；开发以现有伤害几何为准。分镜中“命中”列也包含扑击落地、弹丸消散等出手结果，不代表每次必然打中主角。

## 分镜

- [荆冠猎王](thorn-crown.png)：三道爪痕、双扑尘尾、背后荆尾扫弧、侧跃落地。
- [崩岩獠王](crag-tusk.png)：冲锋拖尾和撞墙碎石、獠牙半月、震踏裂土、带石屑的扩散环。
- [孢心巢母](spore-heart.png)：喷口爆闪、根刺破土、菌冠厚扫弧、孢囊环与壳屑。
- [缚枝祭主](bound-branch.png)：青金镰弧、粉色针雨喷闪、三处根枝破土、枝壳和露核亮芒。

## 节奏与尺寸

| 段落 | 表现 | 规则 |
| --- | --- | --- |
| 蓄力 | 爪、獠牙、镰枝或孢口逐渐亮起，地面出现细裂痕 | 直接读取现有 650～1100 毫秒前摇，锁向后保持方向；每段独立蓄力 |
| 挥击 | 深色边、彩色厚弧、暖白芯；狼爪三条分开 | 主弧约 8～10 像素，柔边约 21～25 像素；实际半径仍为 36～150 像素，扇形方向与判定共用数据 |
| 冲锋 | 肩侧短刃、两条清楚拖尾、分离的贴地尘团 | 拖尾最长 110 像素；以真实移动进度限制长度，不能提前出现在前方 |
| 砸地 | 9 条折线裂纹、9 块带描边的石片、抛物线起落、淡尘圈 | 震踏圈半径保持 50 像素；碎屑额外扩散约 20～40 像素，只作装饰。短技能在本次有效期内完成起落和消散 |
| 根刺 | 地裂后根枝在 140 毫秒内撑出，结束前缩回 | 孢根半径 44、缠根半径 38；缠根三处位置来自正式危险区，不从玩家当前位置另算 |
| 扩散环 | 清楚的窄环、深外边、亮芯、断续孢壳或石片 | 半径直接读取正式扩散几何，最大 240／250，危险带宽 22；内部保持可见 |
| 结茧／破防 | 木质护壳线包住胸核；破开后短木屑和露核星芒 | 防御招不添加伤害或伤害爆炸；露核直接读取已有破防截止时间 |
| 收招 | 亮弧、尘团、碎光变淡 | 直接读取现有 220 毫秒收招；取消、死亡、撤战后不续播旧攻击 |

二阶段增加弧线力度并保留各段提示；连招顺序与伤害参数沿用当前游戏。荆尾只扫背后，镰斩每段只画其独立扇形；设计板中较夸张的整圈、交叉叠加和飞石面积不能直接当作伤害区。新增地碎是暂时的视觉效果，不产生实体障碍。

## 接入与验收条件

新增特效复用两个 Graphics 对象，每帧清理后从当前攻击、危险区和可靠受击时钟重画。没有独立粒子对象、定时器、动画事件队列、额外伤害入口或存档字段。暂停保持当前帧；恢复与读档采样剩余时间。危险边界继续在上层绘制，关闭辅助提示也可见。

需要通过正式无授予构建的真实键鼠流程逐招检查：四位首领四种技能、扩散环安全内侧、背后甩尾、破茧露核、暂停和读档、撤战清理、二阶段、对象与纹理数量稳定。逻辑通过、设计板生成与实机视觉验收分别记录；长时间性能和用户最终美术评价不能由分镜或类型检查代替。
