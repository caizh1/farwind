# 首领图像生成提示词

采用内置图像生成工具。设计板用于造型约束，尚不代表运行或美术验收。

## 孢心巢母

用途：游戏角色概念设计板。为中文俯视手绘冒险游戏《远风》设计独立小首领“孢心巢母”。孢根巢地的小首领。层叠的米白与灰青菌冠，深紫色孢心，根须四肢，腹部露出明亮琥珀色的生命核心。体型饱满，轮廓宽而低，清晰温和的手绘笔触，危险感来自菌冠与根须，不能是人类女孩。
画风：温暖而精细的手绘绘本游戏美术，柔和自然光、米白浅纸背景，青绿、琥珀与褐色，俯视三分之四视角，能够与草地、木桥、森林与可爱小旅人共存，不采用写实恐怖、像素或过度锐利的三维渲染。
构图：一张横向完整设计板，上方左侧一个主体大造型，上方右侧清晰的朝下、朝上、朝右三个独立角色视图；下方四个等宽技能小画面，以及最右小块第二阶段外观。技能：扇形孢雨：菌冠后仰后喷出三道孢子；追迹根刺：根须抬起，地面依次裂开三处；菌冠横扫：压低躯干，宽菌冠横扫；孢囊爆裂：孢心鼓起后释放环形波。第二阶段菌冠张开，孢心亮度提高，根须伸展。
画面文字全部中文，只允许主标题“孢心巢母”和短技能名，文字保持清楚。技能小画面用简单草地与轮廓线展示动作和危险范围，角色造型与主体一致。右下角加入很小的棕发红围巾旅人作为比例参考，首领实际身体约旅人一到一点五倍高，宽度各按物种轮廓。完整留白，不裁切任何肢体，不生成额外首领。
