# 四据点首领实施记录

状态：实施、本机逻辑与运行画面、八条双路径、自然夜袭联动、最终类型检查、构建与默认全量回归完成。采用内置图像生成工具与 ponytail 技能，所有记录使用中文、文件名使用英文。主观美术、手感及其他设备性能另列验收边界。

## 已确认规则

四处据点均为中等偏难。驻守杂兵全灭后进行二点五秒入场预警，击败专属首领才能正式清除。每位首领四种技能、两个阶段。死亡或离开据点活动半径外八十像素连续三秒会重置首领满血，已清杂兵不复活。世界和袭村照常运行。旧版已清据点保留结果，未清据点启用首领。

孢根巢地配置孢心巢母，技能为扇形孢雨、追迹根刺、菌冠横扫、孢囊爆裂。荆狼巢穴配置荆冠猎王，技能为双段扑猎、交叉爪击、甩尾荆刺、侧跃反扑。裂岩兽穴配置崩岩獠王，技能为裂地冲锋、半月甩角、三连震踏、环形震地。棘枝营地配置缚枝祭主，技能为十字镰斩、棘针齐射、缠根封路、护心结茧。

首轮血量分别为一千、一千、一千一百、一千零五十；基础伤害二十二、重型伤害三十。常态护体减伤百分之六十，大招结束后一点五秒解除护体。半血且当前招式结束后进入第二阶段。小宝控制最多四百毫秒，其后抗性三秒；普通攻击不能持续打断。单人目标九十至一百五十秒，带小宝目标三十至七十五秒，数值需真实键鼠检验。

## 实施与验证顺序

先制作四张独立设计板，再制作三方向动作图集、接入唯一生命入口与固定首领成员槽位。攻击几何、预警与伤害共享配置。存档升级至结构十四并保留当前战斗。同步委托、巡游、当地来袭来源、魔王恶意与场景状态。奖励结算一次，满包不复活敌人。最后进行逻辑检查、正式构建、实际键鼠、画面与性能检查以及对抗式审查。

## 初始基线

当前工作区包含其他任务尚未提交的战斗和装备改动，逐处保留，不提交、推送或部署。相关遭遇与精英检查十五项通过、一项失败。既有裂岩林豕的穿石前置判定失败：忽略指定石障时该石障仍是射线首个阻挡；新首领不沿用此异常豁免。基线失败与新增回归分别记录，不修改断言绕过。
