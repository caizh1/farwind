# 窄屏画布缩放首因

顶部血条和四种出场检查通过，但运行截图发现窗口从一千像素改为四百像素后，画布上下出现大片留空。原测试只检查血条和面板边界，漏检画布尺寸，因此此候选包的窄屏画面不能算通过。

根因在主入口：使用 FIT 缩放模式，却调用只适合 NONE 模式的 scale.resize。安装的 Phaser 源码表明，此方法使用保留旧宽高比的 displaySize.setSize；适用于 FIT 的 setGameSize 会调用 setAspectRatio 更新宽高比。

修正为 setGameSize，并增加实际画布宽、高、起点及窄屏画面检查；本目录保留修正前证据。不是首领粒子或相机性能问题，也没有降低图形质量或绕过原断言。
