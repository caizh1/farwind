# 自然夜袭样本首因

首次自然夜袭样本保留原有精确战斗编号断言，修正安全等待操作后重新执行，不修改游戏数据或放宽断言。

玩家在南路采药道史莱姆旁静止等候。完整轨迹确认附近活体为 `wild-herb-slime`，距玩家约二十六像素，生命四十八；它连续造成十点伤害并击退玩家，实际据点距离变为约四百三十像素，进入四百四十像素的入场范围，首领正常生成。玩家随后在世界分钟约二千五百零七死亡，回村满血并将战斗编号由一增加到二。夜袭时再次入场，之后真实撤战编号正确增加到三。首次样本因此在预期编号为二的检查处失败，并非重复重置。

首领交战时南门事件 `raid-1` 实际启动，撤回村后原序号一正常结算。死亡与撤离各自正确重置，未发生重复死亡结算。编号首次变化前后证据见 `attempt-transitions.json`，完整场景状态见 `world.json`。

修正为在归风旅馆附近安全等候至来袭前四十个游戏分钟，再通过正常奔跑与南路行军进入据点；进场前与进场后均保留精确编号检查。完整键鼠录像和首次失败追踪仍保留。

长时间样本原自动逐帧截图追踪产生大型文件；后续保留界面快照、只读状态轨迹、关键节点截图与完整录像，关闭追踪中的重复自动屏幕截图。
