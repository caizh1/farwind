# 东门首领：赤环灭光

2026年10月4日。按批准的[三段设计图](design/east-boss-laser-v1.png)实现。缚枝祭主增加第七招，其他首领保持六招。使用现有高清树身图集、连续关节网格、首领危险区与正式存档系统。

## 招式过程

| 阶段 | 持续时间 | 正式行为 |
| --- | --- | --- |
| 双臂上举蓄力 | 1200毫秒 | 正面展示抬肘屈臂，胸核赤光，八向虚线预警；锁向后留350毫秒反应时间 |
| 八向红色激光 | 600毫秒 | 八条线同时生效；距核心52至430，线宽16，地形处截断 |
| 换式 | 250毫秒 | 射线消失，圆周路径预告 |
| 圆周激光刻线 | 1450毫秒 | 半径230，光头顺时针走一圈，宽12，身后留暗红灼痕 |
| 灼痕蓄爆 | 500毫秒 | 圆周烧痕闪烁，没有伤害 |
| 第二段贴地追爆 | 1450毫秒 | 沿同一固定圆周再扫一圈，判定光头宽26；沿原灼痕顺序触发定点逐帧爆裂和独立飞石 |
| 收招 | 900毫秒 | 双臂连续放回，转入既有暴露窗口 |

三段基础伤害为22、22、30；每段对玩家和小宝分别最多命中一次。不可弹反。固定圆周不会随玩家移动，不会把整片圆盘变成伤害区。射线间隙、圆内及圆外提供避让空间。大招冷却12000毫秒，受既有大招互斥约束。

道数集中在 `src/game/systems/bossLaser.ts`，当前为8。光效与判定读取相同数据。一个完整技能只占一个危险区预算；复用两层绘图对象和两张透明特效图集，新增贴图对象池上限64，第三版连续播放峰值43；不建立额外计时器或持久化粒子状态。射线锁向后只缓存一次障碍截断，接触查询仍检查真实地形。

## 生命周期与保存

所有阶段读取正式模拟时钟。暂停不推进，失衡同步顺延；取消、死亡、撤战或挑战轮次变化清理整套连招。保存用相对时钟，保留道数、方向、截断长度与已命中集合；保存副本不共享运行缓存。旧六槽冷却数组在正常选招时扩为七槽。导入拒绝异常道数、重复命中集合及激光攻击缺失必需几何。

双臂与身体共用原图集纹理坐标，拆成三个网格。原始精灵隐藏以免叠影，普通招式隐藏额外手臂，销毁首领同时销毁全部网格；狼的原挥爪仍使用原蒙皮和爪尖定位。

## 第二版特效修正

用户否决第一版的粗线条表现；第一版仅有轨迹和时序，不能视为设计图美术落地通过。第二版使用实际透明素材替换加粗线条：白热芯、参差光丝、端部爆闪和流动亮点；圆周留下焦黑裂口与红色熔炽裂缝；第二段使用向上升起的火焰刃、飞石和错峰短爆裂沿同一圆周推进。收招期间灼痕连续淡出，不改变正式危险区的到期时间和伤害。

预览使用正式东门巢穴地面贴图和正式首领渲染器，支持真实键盘移动主角检查地面层遮挡。图片是实际渲染结果，录像是连续播放实录，均未使用概念图替换游戏截图。最终主观美术仍待用户验收；正式战斗与原存档路径的未验证边界仍保留。

素材、生成输入、分镜、录像与代码审查详见[第二版特效记录](LASER-VFX-V2.md)。

## 第三版爆裂动画修正

用户再次否决第二版第二段爆裂：静态贴图缩放、绕圈移动没有满足动画要求。第三版删除该绘制路径，沿原圆周设置36个固定落点；每处独立播放12种火焰形态，在330毫秒内完成起爆、升腾、断裂和消散，飞石用独立速度、重力、自转及440毫秒生命周期采样。落点不随光头移动；所有年龄仍读取正式相对模拟时钟。

已修复预览播放期间回写输入值干扰“精确时刻”编辑的问题。当前验证与美术状态以[第三版动画记录](LASER-VFX-V3.md)为准；第二版视为用户美术验收未通过。完整正式路线的未验证边界仍保留。
