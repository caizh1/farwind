# 远程弹反自动剑气

## 最终规则

灰冠孢卫的孢子弹通过正式弹反裁决成功后，打散本次弹丸，预约一次第一刀反击变体。成功接触先呈现暖白闪光、成功声与受力姿态；拨开后剑身红光继续关联同一成功事件。

| 自动反斩启动 | 成功后60毫秒模拟时间 |

| 主目标 | 本次弹丸的攻击者，不转移给沿途其他敌人 |

免疫和余势格挡不产生反击剑气。成本、退款、窗口、方向防御、取消权限、攻击优先级和敌人基础参数均保持。近战成功仍沿用原近战反斩；专用远程剑气关闭近战扇形伤害，避免同一次反击重复伤害。

## 瞄准与物理

成功时读取一次射手位置，只允许朝本次前方防御半面选向；之后不追踪。如果射手已在背后、已死亡或不存在，沿来弹反方向挥出。中心重叠时也使用来弹方向回退。四方向角色表现选择最接近的方向，剑气保留连续平面方向。

复用剑风的连续扫掠、起始段检查、实体障碍与世界边界规则。沿用已有空中剑气越水行为，不修改人物移动规则。目标离开路线、超出射程或死亡时挥空。沿途其他敌人不参与专用剑气的目标检测，不产生额外伤害或奖励。

出生表现使用反斩有效期第一帧的真实剑尖与图集附着点；不挪用第四击上挑动作的剑尖。身体根和人物比例不变。接触成功时不对远处射手施加伤害或失衡；保留原有100像素以内、无遮挡本体受力规则。剑气真正接触后才走既有敌人、守村敌人或练习投影的伤害路径。

## 状态与反馈

待执行反击和正式攻击增加投递方式、来源接触ID与锁定方向。反斩仍是正式第一刀实例，用既有释放标记确保只发射一次。发射快照保存第一刀身份、主目标、方向、伤害和连段编号。

成功闪光与红刃按来源接触ID关联正式反斩。远处射手不进入弹反瞬间受力动画。实际剑气命中产生独立反击命中事件，位置取真实剑气接触点；不在主角剑边伪造远方命中，不在挥空或取消时播放命中重音。

发射前的合法风步、防御或真实受伤取消会丢弃待执行反击。发射后按既有独立剑气规则继续飞行，不因受伤或风步追回。死亡、读档、新游戏和返回标题清空临时实例与反馈。停顿和暂停继续服从现有模拟时间轴，不加入定时器。

## 练习入口

靠近木桩，点击“迎风架剑练习”，选择“灰冠孢卫 · 孢子喷射”。面向孢子，K或画布右键架剑；成功自动发出剑气，J接第二刀。可在练习菜单关闭来招指示器。训练不扣真实生命、不掉落、不推进任务。
