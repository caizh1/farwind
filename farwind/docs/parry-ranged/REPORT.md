# 远程弹反实施报告

## 实际结果

远程弹反已替换为专用自动反击剑气：成功后保留闪光与红刃，第一刀有效期发射一发剑气；仅真实接触主目标后造成24或30基础伤害。无需解锁剑风，J继续接二三刀，已学第四击和五级技艺保持。

本轮没有扩大窗口、增加退款、额外无敌、延长敌人失衡或降低敌人强度。未修改音源，复用既有成功、破风与真实反击命中的独立反馈。未添加素材依赖。

## 文件改动

- `combat.ts`、`contact.ts`：正式反击投递方式、来源ID、成功时一次性瞄准、有效期单次释放、近战扫描排除、只读诊断。
- `swordWind.ts`、`data/swordWind.ts`：复用独立剑气扫掠，专用第一刀配置、主目标过滤、真实反斩剑尖出生、命中停顿保持原首刀。
- `World.ts`：射手位置传入裁决、装备伤害快照、第一刀身份与远程伤害入口、远方实际接触位置的独立命中反馈。
- `combatFeedback.ts`：红刃通过来源接触ID关联反斩，不依赖远处射手的受力目标。
- `parryTraining.ts`、`interface.ts`：孢卫训练与操作说明更新。
- `tests/parry-ranged.test.ts`：新增23个逻辑用例，已加入明确枚举的 `npm test`。
- `tests/parry-ranged.spec.ts`、运行配置和证据脚本：真实键鼠专项、实际游戏音轨、合法夹具与只读记录。

在共享工作区检测到主角受伤反馈与小宝立绘的并行改动，保留它们；报告中的范围仅为远程弹反。未提交、推送或部署。
