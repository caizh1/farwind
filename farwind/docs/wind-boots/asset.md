# 轻风靴图标

使用内置图像生成工具生成透明底素材，并保留透明通道缩放为256×256的网页图片。

正式素材：`public/assets/equipment/wind-boots.webp`。商店、行囊与鞋槽共用此图标。此素材不改变角色行走动画。

## 实际生成提示词

用途：Far Wind 手绘奇幻冒险游戏的物品图标，轻风靴。生成一张透明背景的成品素材。主体为一双结实轻巧的棕色短筒旅行皮靴，鞋口浅米色翻边，暗青绿色布带，简洁铜色扣，鞋侧有细小羽叶装饰，传达轻盈和赶路。三分之四视角，两只靴子自然前后错开，构图居中，四周留透明边距。清晰轮廓，温暖柔和的手绘水彩与不透明水粉质感，细节适量，缩小至64像素仍能辨认。光线柔和，棕色与森林绿调色。只画一双鞋，不画人物、脚、场景、光晕或速度线。不要任何文字、数字、边框、徽章或背景，不要像素画，不要3D渲染。
