# M3 东门防御切片

本轮承接M2，冻结当前共享目录的生活服务及弹反第二版；基线逻辑212项通过。独立实现后按源文件校验合并，不覆盖其他任务更新，不提交、推送或部署。

## 局部布局与修改清单

东门中间道路保留，两名近战分别沿2010，970与2010，1160值守和短巡逻。塔位根据射击口与门柱避让向东调整约40像素，在北侧2030，900设置小木塔；实体底座、平台弓手及弓上发射点独立定义。门柱、门洞、院门、练习场和北岸通路不移动。正常模式保留单位名称和受击反馈，不增加HUD栏。

补近战守卫、弓手和木塔候选手绘素材；与旧木匠、房屋、角色同屏确认，未批准前仍标临时。箭矢从可见弓的位置产生，射界偏向东方，登记射击口只越过指定低围挡，屋顶和高门柱仍阻挡。

拆出窄范围阵营与伤害入口、驻防行为和投射物。三名守卫有稳定ID、实际武器护甲参数、HP及死亡状态；不能伪装为敌人，不伤友军。近战巡逻、拦截、攻击、低血撤退、8秒脱战后每秒0.75%回血、回岗都使用同一有效模拟时钟。低血后撤不瞬移；HP为0真实死亡且只发一次死亡事件。自动伤害不调用主角hit stop。

受控来袭与固定主线野怪分开；开发模式显式defenseDebug=1在东门路牌提供一次3只普通怪演练，正常模式不出现该控制。M3不定时刷怪，不复制三门。每组只有一场，合法城外可走点与门连通，并避开玩家近身；不可达或近身就拒绝，不硬刷。动态怪不写固定killed、pendingDrops，不推进叶灵任务或发任务结晶，本阶段不发防守奖励。

## 保存与验证边界

存档结构3独立增加驻防、事件序号与最小活跃波次；地图5仅加塔基，不再次+600。旧结构2保留钱、包、装备与任务；结构3缺失驻防字段应拒绝，不用默认满血覆盖死者。伤害与死亡、结束关键状态接入完整IndexedDB事务并给出失败反馈。读档保留死者与HP，活动成员恢复但不补箭矢伤害；暂停、商店、失焦同时暂停双方，离线不模拟。

验证包括：实际键盘走三处通路；玩家不参与和离屏时自主击退；可见拉弓、箭飞行、墙体阻挡、弓手死亡停火、友伤关闭；受控致死与重载不复活；保存中止、活跃波次重载、暂停与菜单、原主线与弹反战斗回归。固定1280×720、同镜头与08时前后实机截图各含HUD和无HUD。功能、美术、性能分别报告，截图保存不视为人工美术验收，不预先宣称30波或60FPS。
