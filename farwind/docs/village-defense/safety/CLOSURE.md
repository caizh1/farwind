## 调用链与修复内容

`advanceNight → mayStartNight → nightWarningSnapshot → canScheduleAtGate → 已保存预警 → 正式更新二次准入 → 出生／同编号取消` 是生产入口。保护／冷却只在正式时间推进扣一次，居民轮休与返岗继续共同运行。保存事务失败不会发布预警；真实关键保存失败提示并暂停，条件不满足只延期。

威胁记录只保存目标标识、门、原因、观测时间、路线进度、接近确认与分配守卫。普通固定怪真正入侵也会响应，远怪与路过目标只观察。固定怪的防御／野怪更新所有权在时间片起点冻结，避免漏更新或双倍移动。交还野怪控制时取消仍指向卫兵的未释放攻击，不能把其伤害转嫁给玩家。

近战在内侧入侵时直接选合法局部站位，避免先寻域外拦截点而卡住。归岗清理旧目标、动作和路径，低血撤退不会被下一帧感知重新打断。守卫自治命中继续只产生局部反馈，不触发玩家全局停顿。

选敌、起手、实际释放共用资格；释放读取实时位置和生死。已经发出的箭不追踪、不重新索敌，按430像素／秒、1800毫秒寿命和774像素最大距离连续碰撞；墙体与目标按实际先后处理，一次伤害。目标退出威胁名单仍能被物理经过的箭命中；友军、玩家和训练靶不受伤。重新加载清除纯表现箭，不重放伤害。

固定怪死亡仍保存固定击杀状态；关键叶灵结晶保留在原家园待玩家领取，不自动推进叶灵任务。动态侵扰不给挂机收益。东门2170近郊不提前触发森林主线，2300明确森林入口仍触发。商店、装备、训练、玩家三连／第四击剑风／弹反／风步、镜头与输入没有改变。
