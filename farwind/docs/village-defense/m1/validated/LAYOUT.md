药师小院和练习场不迁位。北路调整至820轴线，仅移开原 `tree-7`，稳定编号保留；东北练习场主路仍走场外，教学桩和三场靶数量与能力保持。南门避开桥头与预留小院；西口移到果园西侧，避开旧木工房。

修改内容：

- 新增统一村界、门口、多边形区域、预留地及规划岗位数据。
- 从村界生成连续栏墙与独立柱脚，保留门洞；两种围栏复用旧横栏与新的透明竖栏候选。
- 区域显示与出村主线接收完整坐标；北南出门不误触森林任务。
- 复用正式局部寻路，增加每帧共享两次查询预算与门口路线节点；不可达继续等待。
- 保留移动与近战查询，增加限定己方低墙射击口的基础查询。实际弓箭、屋顶高度和射界结算在M3接入。
- 地图版本升至3，不增加世界平移。最老档仍仅加600一次，版本2仅升版本；新墙占用的保存站位按同一区域寻找可走位置。
- 装饰排除范围覆盖新村界、门洞、道路、桥面、NPC、练习净空、规划岗位与预留院。三簇侵入新院的旧生成灌木被排除；森林与遗迹内部布置保留。
- 地图面板展示真实门名和预留地；正常画面无工程分区编号。

村内保护暂按多边形保留，避免驻防尚未接入时改变原村庄体验。M3真实守卫可用后，再由围墙和驻防接替保护；本阶段没有宣布完成计划中的最终安全机制。

[坐标布局与可分离防御叠层](layout.html)由正式数据生成；[固定视口对照](review.html)独立提供真实画面。现有屋顶与北墙的视觉衔接、商业街和新房屋占地仍需下一阶段细化。新增六至八栋、四类服务、守卫死亡、箭塔与骚扰均不在本阶段伪装成已完成内容。

预留地共327900平方世界像素，约为村界矩形毛面积的10.1%。15%～20%的目标针对可建设面积，需扣除道路、水体、现有建筑再量化，目前不能宣称达到目标；村内有效面积增加30%～50%也尚未量化。
