# M5 集成验收与持续运行

用户已通过M4候选并授权继续；保持当前已认可的布局，不重新扩大地图或更改战斗数值。应用ponytail技能复用正式存档、运行时、碰撞与已有浏览器用例。

## 本轮清单

- 核对当前分支和全部运行源码摘要；共享目录相对M4无运行代码变化。
- 增加跨结构／地图版本的重复保存迁移、死者保留、非法位置恢复、各门各事件阶段恢复样本。
- 用正式敌人实际致死，保存后真正关闭并重新打开浏览器，检查死亡、冷却与结算号，不仅刷新标签页。
- 用生产构建和真实Apple M5 Pro Metal后端做三门活跃事件采样及20分钟自然调度持续运行，保留帧间隔、实体／箭数、堆／DOM趋势、保存与页面错误。
- 复核正常模式、三门通路、交易／暂停／失焦与原战斗；已有相同源码验证只在发现新增变化或失败时扩大复测。

## 条件与边界

人工基线是每阶段逐门重复导入、死亡、保存、关闭、重开和观察长期运行。固定样本使用新档、合法历史档与实际键鼠；只读诊断仅用于断言，不改运行状态。测试故障注入限定IndexedDB事务。

通过门槛：迁移不重复+600、不丢任务／装备／背包；已提交死亡不复活；一次结算不重复；无主线污染；单场2～4、九守卫、箭不超过12；无页面错误／无限增长。20分钟自然调度仍按5分钟保护与初始6分钟冷却，不加速时间。

性能记录限定本机、1280×720、Chromium153、ANGLE Metal Apple M5 Pro。与此前SwiftShader粗采样区分；长帧、活跃事件和内存趋势如实记录，不能以浏览器加载或少量均值宣称全部设备60FPS。先前已通过的M4图为本轮人工认可基线；专属纵向阵亡动作仍未补齐，资源支持范围保持明确。没有实测不宣称减少80%人工。
