# 风赐连续演出实现与验证

2026年10月3日，六十种非黑洞风赐与十八组共鸣已替换为连续编排。旧版通过整张六帧图集轮播形体，本轮采用二十四个内置 imagegen 透明组件，配合逐时刻变形的曲面、尾流与传递轨迹。每项具有独立结构和参数，覆盖刃锋、枪锋、破帘、聚焦、回声、护幕、弹反碎镜、液态治疗、步迹、牵引、伙伴传递和共鸣。

## 连贯性

起手蓄势绑定真实攻击准备期，J刃锋在攻击释放时扫出，I材质跟随真实剑风及回声位置。命中反馈、治疗回流和伙伴连线消费现有战斗事件；护盾、减速及标记由真实剩余状态驱动。位置、转角、尺寸、曲面和透明度使用连续模拟时间，暂停不继续推进，结束、死亡与场景切换按原生命周期清场。飞行组件使用与剑风出生一致的世界时间，避免读档后两套时钟造成跳变。

锋面新增三层透光厚度、亮脊与薄尾。吸露从真实受击点连续回到玩家。范围余震在真实中心统一展开，多个受击者仍分别结算伤害。同刻最多四次新演出，主攻击与共鸣优先；最多十八个活跃事件、九十六个材质对象。常驻护幕保持小规模透明侧面，保留脸部与攻击轮廓。
