# 游戏画面材质改造与验收

本轮按设计图的手绘材质、细节层次与落地感改造实际游戏，保留现有地图布局、建筑位置、交互入口、道路、水域、桥梁通道、碰撞与正式存档结构。设计图保存在 `style-reference.png`，用于风格比较。

## 已实施

| 项目 | 改造内容 | 范围 |
|---|---|---|
| 草地 | 新绘草丛、花点、明暗色块；只对纹理边缘羽化，避免整块镜像造成对称纹样 | 全地图 |
| 石路 | 新绘大小不一的灰暖色石块、细裂缝和灰褐石缝，缩小平铺尺度 | 村庄、道路与遗迹 |
| 森林底纹 | 新绘苔藓、蕨类、落叶，继续沿用各区域冷暖色调 | 森林、山道及区域交界 |
| 建筑 | 按原素材比例调整显示高度，底部锚点保持不变；投影独立烘焙 | 房屋、商店、塔楼 |
| 落地阴影 | 静态轮廓投影和接触影写入地面缓存；角色与居民使用统一斜向接触影 | 场景与角色 |
| 花簇与树篱 | 三种低矮花簇、三种不规则树篱；墙脚、喷泉和岸边共179处独立低矮景观 | 村庄和水域周围 |
| 喷泉 | 新绘高柱、灰石双盆和水面；按新原图重建流水、池水遮罩 | 原广场喷泉 |
| 湖岸 | 保留岸线和浅水参数，增加大小不一的石块、水草和低矮花簇；避开桥面 | 村湖及野外水域 |
| 野外水面 | 复用村湖的手绘水纹，消除旧水纹过强的亮白大形状，边缘羽化后缓存 | 野外池塘与溪流 |
| 木桥 | 新绘木纹、磨损、钉头、边梁；村湖和野外共用材质 | 原桥位和通行尺寸 |
| 店招 | 使用手绘空白木牌，中文店名仍动态绘制，维持清晰度 | 原商店招牌 |
| 训练教本 | 手绘羊皮书页、绿色皮封和雕刻木架，替换几何纸板式绘制 | 原练习场交互点 |

表现参数位于 `src/data/worldAppearance.ts`，静态表现烘焙位于 `src/game/rendering/worldAppearance.ts`。没有为新增花簇创建逻辑物件，也没有增加碰撞、任务或背包数据。

可收集物、可破坏石块、可开启阻挡物的阴影没有烘焙进静态地面，避免移除物件后留下固定影子。边缘处理、投影、宏观色块只在生成地面块时执行，不逐帧上传材质。原有地面块释放机制保持不变。

## 素材与清理

十四项主要材质和景观素材的源文件、运行文件与尺寸见 `material-manifest.json`，可通过 `node tools/pack-art-quality.mjs` 重建。源图由内置图像生成完成，切图、透明通道检查和缩放通过 Sharp 完成。完整生成输入保留在本次会话工具记录中。

主要生成要求：草地与森林应有手绘笔触和自然的色块变化；石路使用不规则灰暖色石块；喷泉强调高柱、厚灰石盆和清澈水体；植被使用三色花簇与三种树篱；木桥保留原几何方向，补充细木纹和磨损；店招为空白深色木牌，训练书架使用羊皮纸和雕刻木架。所有物件源图保留真实透明通道。

- 已删除：`public/assets/village-polish/plaza-fountain-source.png`、`public/assets/ground-source.png`。旧喷泉与旧四象限地面源图已被本轮源图和复用的村湖水纹替代。
- 同名覆盖替换：`grass.png`、`road.png`、`forest.png`、`water.png`、`village-polish/plaza-fountain.png`、`level-rework/bridge-candidate.png`，以及两张喷泉水效遮罩；正式目录没有保留这些旧运行素材的副本。
- 已移除：旧店招和训练书架的几何主体生成代码。
- 已更新：正式素材登记、村庄素材生成脚本和水效遮罩生成脚本；旧喷泉源图在源码、工具、测试和当前素材登记中均无引用。
- 保留仍使用的 `bush.png`：风课藤蔓、据点根部状态切换仍调用该素材。未删除其他专项仍依赖的素材或用户原有改动。
- 本轮修改前冻结构建和源码副本在对照完成后清理，不保留已淘汰素材的临时副本；只保留证据截图、采样数据和 `source-diff.txt`。当前候选构建继续保留供复核。

本轮涉及的主要运行素材压缩体积约7.05 MiB，替换前对应文件约5.11 MiB。新增的是八张小型植被、店招与教本纹理，其余六项替换原纹理。

## 验证结果

- `npm test`：69个测试文件、1360项全部通过。该回归在本轮接入期间完成。
- 最终材质专项：8个测试文件、94项全部通过，覆盖地图表现隔离、几何、障碍、首图、地面过渡、泉水恢复、水效与昼夜。
- 最终 `npm run build -- --outDir .art-quality-local/current` 通过；保留原有大包体积提示。
- `git diff --check` 通过。
- 真实Chrome检查18个站位：广场、练习场、药师院、湖岸、森林、田野、旧农庄、山道、北部遗迹、遗迹边界、西塘、芦塘、深塘、峡谷、河道、喷泉背面、桥北和桥南。截图见 `evidence/`。
- 检查白天、黄昏和夜晚；检查默认视口、1280×720及1920×1080，随后恢复浏览器原尺寸。
- 正式键盘输入路径下，角色从广场向南移动，位置及脚点深度同步；新增材质没有阻断原通行。
- 打开居民笔记期间，水效计时固定在61549.33毫秒，运行状态为暂停；关闭后恢复计时。数量保持1个水面、4处池塘反光、4处池塘涟漪、3处喷泉涟漪、9滴水、18片荷叶和5座村湖桥。
- 未导入或覆盖用户5173端口的正式存档。原页面通过“继续旅途”成功加载，生命84、金币171等数据保留，新材质实际显示，截图见 `evidence/live-game-after.png`。验收工具使用5308、5309独立来源的合法测试存档，通过正式导入流程启动，不伪造完成状态。

VERDICT: PASS

P0/P1 BLOCKERS: 无。

审查了贴图加载与切帧、重建和关闭时的资源释放、静态与可变物件的隔离、显示锚点与碰撞数据、跨地面块的坐标连续性、负坐标、桥面排序、喷泉遮罩、正式导入流程、昼夜及暂停时钟。没有发现符合阻塞条件的P0/P1问题。

UNVERIFIED RISKS:

- 最终美术相似度仍需用户主观验收；本轮真实运行截图已检查，不宣称与概念设计图完全一致。
- 20分钟连续游玩、显存实测及其他设备性能尚未完成，45秒采样与有界缓存审查不能替代这些结果。
- 未执行全库浏览器端到端回归；本轮没有改变战斗数值、任务、入口、存档或玩法。

NON-BLOCKING FINDINGS:

- 草地与道路仍采用有界平铺，较大空旷区域仍可能感知重复；新增色块与景观减少了规律感。
- 大量现有树木和优质房屋素材被复用，没有把所有资产重新生成一遍；本轮通过材质、比例、阴影和周边景观改善整体品质。
- 源图与设计参考留在文档目录，正式发布需要继续沿用项目原有的美术和素材权利验收边界。
