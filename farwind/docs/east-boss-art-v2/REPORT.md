# 缚枝祭主第二版加强与验证记录

当前状态：静态精修候选。已完成实体结构、材质和可编辑工程交付，尚未接入正式游戏，也未完成最终美术验收。

## 本轮改动

- 叶片使用六种轮廓与多种色调，增加折面、弯曲和厚度；左右分组独立，减少连续披风感。
- 树身主根改变走向与粗细，增加腹腔内层暗根；腿部弯曲并补充脚底根趾和侧分叉。
- 面具重建为有厚度的壳体，眼孔具有内壁和后置凹腔；补充额头、下颌和两侧连接根。
- 枝冠增加多级分叉和末梢收细；双镰分开刃缘、骨质主体、木质背脊及不规则暗色钩齿。
- 风核使用独立弧面、新生成的绘画风格纹理与实体金色根框；纹理生成说明见 [记录](TEXTURE-PROMPTS.md)。其余纹理复用已有资源并调整混合。
- 保留可编辑的独立部件，另存烘焙交付工程。交付工程合并主要部件并使用四张四千像素图集，贴图均已打包。

## 后续编辑与复现

继续精修应直接打开 `source/east-boss-art-editable.blend`；不要重新生成后覆盖人工调整。`--rebuild` 会明确覆盖本版源工程，仅适合有意从脚本重建。

在游戏仓库目录执行：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-exit-code 1 --python tools/build-east-boss-art-v2.py -- --load --render all --percent 100
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-exit-code 1 --python tools/bake-east-boss-art-v2.py
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-exit-code 1 --python tools/check-east-boss-art-v2.py
python3 tools/compose-east-boss-art-v2.py
```

烘焙后若要刷新交付预览，在渲染命令添加 `--input docs/east-boss-art-v2/source/east-boss-art-delivery.blend`。变形短片是检查样片，并非完成的战斗动画。本轮未修改正式游戏逻辑、未提交或推送。
