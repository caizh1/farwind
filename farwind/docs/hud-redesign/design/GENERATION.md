## 生成提示词要点

以下是生成指令的中文归纳记录，不冒充逐字工具输入。

共同要求：在提供的真实村庄场景上设计温暖、克制的手绘 RPG HUD；深墨绿半透明底板、细旧金边、米白文字；保持树木、道路、桥、水面、喷泉、木工台、角色位置和镜头；减轻厚外框和米黄格子；左上生命体力保持原风格；主稿按 1440 × 900 视口考虑。正式界面文字和数字最终以真实字体校正。

- 默认态：底部居中仅完整八格快捷栏，宽约 440、高约 58、底距 10；编号 1–8；复用道具图标；右上两个独立紧凑行，分别显示地点/时间/地图按钮和当前任务摘要；移除永久帮助和底部工具按钮。
- 展开态：同一背景和同一位置；右上显示小地图、完整日期、完整地图入口，再以纵向间距显示当前任务名、目标和手记入口；都有明确收起按钮；快捷栏一个格子处于局部悬停态，整栏不放大。
- 暂停态：同一背景；居中深墨绿菜单；清楚的继续旅途、行囊 Tab、完整地图 M、旅途手记 Q、操作说明；另组保存、导出、导入、设置、返回标题；两列入口与快捷键胶囊，避免过长单列。

生成来源分别为本任务 generated_images 目录中的 exec-8a5cc868-fe07-49b3-983b-f2f60f337f17、exec-091b7702-cd0b-4245-a526-24469ebfab24、exec-b95de417-96d2-4495-893b-defbd21556af。原图完整保留。

## 开发依据

原稿表达视觉方向，但生成的中文和几何尺寸不能直接用作开发依据。因此在正式开发前，使用原始游戏背景、真实 HTML/CSS 字体和复用图标制作精确校正稿，并保存、查看三种独立状态。校正稿明确属于“图像生成后的 HTML/CSS 渲染设计预览”。

- [hud-design-default.png](hud-design-default.png)
- [hud-design-expanded.png](hud-design-expanded.png)
- [hud-design-pause.png](hud-design-pause.png)

主稿为 1440 × 900 像素，对应 DPR 1 的 1440 × 900 CSS 像素；每种状态另有 1280 × 720 紧凑稿。生成原稿的 1586 × 992 图像像素不用于推算 CSS 尺寸。

开发中把示意地图更换为真实地图绘制逻辑的 Canvas 预览；暂停菜单按实际内容自然撑高至 573.688 CSS 像素；焦点边框采用已有通用 3px 轮廓。同步更新校正稿和 [规格](../design-spec.md)，以并排、叠加图核对。场景动态水纹、时钟分钟变化不作为 HUD 几何差异。

preview.html、preview.css 仅用于设计预览；正式产品使用 Interface 的动态 HTML/CSS/Canvas，没有使用整张设计图铺在游戏上。

[模拟暗背景预览](hud-night-legibility-preview.png) 是截图期间临时叠加暗色层的可读性预览，明确不是实际夜间渲染结果。原因见 [验收报告](../REPORT.md)。
