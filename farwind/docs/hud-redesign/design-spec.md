# HUD 设计与交互规格

主稿游戏视口 1440 × 900 CSS 像素，截图 DPR 1 为 1440 × 900 像素；紧凑稿 1280 × 720。DPR 2 截图为 2880 × 1800 像素，组件尺寸仍按 CSS 像素。相机沿用原代码。

## 设计选择

温暖、克制的手绘 RPG。深墨绿 RGB(20,43,36)、米白 #f6edce、旧金 #c8b078。文字与图标保持不透明，仅分别控制背景和细描边透明度，无 HUD 背景模糊。左上生命体力样式保留；动态风步状态在其下方。

快捷栏 hover/focus/使用时仅强化对应格子背景至0.72与旧金边，120–160毫秒，不缩放不跳位。物品名称提示在快捷栏上方以网格叠层排版，不增加默认占用。键盘焦点轮廓3px米金，外距3px（沿用原通用按钮焦点，以保持易识别）；尊重减少动画偏好。

## 状态与输入

默认任务、小地图都折叠，分别通过按钮切换 aria-expanded/aria-controls；hidden正文退出布局、命中与焦点。保存到独立 farwind-hud-v1 本地配置，字段版本1、小地图展开、任务展开、已见菜单提示，解析/存储失败回退。不会改旧游戏存档。展开不暂停、不改变 Interface.mode。任务更新只短暂提示，不改变手动选择。小地图隐藏不绘制，展开立即重绘；显式区分 minimap/world-map，Canvas按CSS尺寸与DPR适配。

游戏 Esc → 暂停主菜单 → 行囊/地图/手记/帮助/设置 → Esc/返回 → 暂停主菜单 → Esc → 游戏。从游戏 Tab/M/Q 直接打开面板，Esc或关闭按钮直接回游戏；菜单内Tab用于焦点循环，箭头/空格保留控件原生行为。主菜单、子页、对话框每个按键仅处理一次。关闭时清空游戏输入并恢复来源焦点，游戏画布点击后清除HUD焦点。暂停页面HUD inert。

菜单集中继续、行囊Tab、完整地图M、旅途手记Q、操作说明、保存、导出、导入、设置、保存并返回标题。操作说明列真实WASD/方向键移动、空格奔跑、E交互、J/左键攻击、K/右键弹反、L风步、1–8道具与Tab/M/Q/Esc。首次进入提示“Esc 打开菜单 / 查看操作”，4秒后消失。

## 响应式

1280×720、1440×900、1920×1080沿用同一CSS组件尺寸。宽900以下边距10；宽700以下右上组220、保留原小号生命体力；宽480以下右上组为min(200px,48vw)，热点字体11，道具栏min(440px,视口减16)，间距3，图标最大28且可缩小，仍8格。暂停菜单宽min(620px,100%)，短屏内部滚动；宽480以下入口仍两列，备份小字折行。底距max(10px,safe-area-inset-bottom)。

## 验收基线

原快捷栏590 × 78，原整个底部组件高度147，底距18。目标58高，预计减少60.54%。以实际可见矩形并集计算面板面积，不计满宽透明父容器，不重复计父子，不将半透明视为零遮挡。

## 图像来源与校正

使用内置 imagegen；真实无HUD场景、原HUD截图、根目录design.png、恢复药剂与浆果图标为参考。生成原稿保留；最终设计另以HTML/CSS真实字体校正中文、精确坐标与尺寸，并使用真实背景进行组合。正式界面不使用整张效果图。

## 实施时的校正

小地图展开组件实测高度208；任务当前短目标展开高度133.094；两项展开总高349.094，后续目标换行由自然文档流增加高度。暂停主稿由内容自然撑高，最终以对照测量为准，不采用固定高度裁字。小地图地形统一合成后alpha0.60，道路、水域、桥与玩家标记不套整体透明度；修正叠加地形累计alpha的问题。原稿的地图缩略图更换为同一地形逻辑绘制的真实Canvas预览，中文、格子与暂停页均以真实字体校正稿为实施依据。
