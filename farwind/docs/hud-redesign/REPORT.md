## 实现与交互

- 快捷栏保留 8 格及 1–8 绑定。尺寸、alpha、间距采用组件变量与 Grid；道具图标复用 `/assets/icon-*.png`。底托 alpha 0.32、物品格 0.48、空格 0.18，文字/数字/图标保持不透明。hover、focus、刚使用仅强化局部格子；稳定节点更新数量，不夺焦点，不放大整栏。清除旧帮助、工具按钮及被覆盖的重复 CSS 规则。
- 小地图/任务各有明确按钮、完整可访问名称、aria-expanded/aria-controls。隐藏正文退出布局、焦点和命中；装饰外壳及组件间空白透过到游戏画布，实际控件和展开正文截获操作。任务更新短暂提示，不改变玩家折叠选择。
- 独立版本配置 `farwind-hud-v1` 保存两种折叠偏好及首次提示记录，解析异常/存储拒绝回退内存。没有给旧存档增加 HUD 字段。正常展开不改变 Interface.mode，也不暂停移动、时间或战斗。
- 隐藏小地图不重绘，展开立即更新。绘制显式区分 minimap/world-map，按逻辑 CSS 尺寸与 DPR 设置 Canvas；小地图地形先完整合成再统一 alpha 0.60，道路、水域、桥和玩家标记保持清楚，完整地图仍不透明。
- Esc 主菜单集中继续、行囊、完整地图、手记、操作说明、保存、导出、导入、设置和返回标题。两列布局；短屏内部滚动。子页面来自暂停菜单时关闭先回暂停菜单；直接 Tab/M/Q 打开则关闭回游戏。输入只处理一次，清理游戏按键/动作队列/轴并恢复来源焦点。
- 菜单 Tab/Shift+Tab 导航、原生空格/箭头操作保留；HUD 控件可见焦点。首次 Esc 提示 4 秒消失，不新增永久底部说明。动态风步、训练反馈、交互和重要消息继续显示；对话能力保留。

详细颜色、字号、尺寸、响应式和状态规格见 [design-spec.md](design-spec.md)。正式 UI 不使用整张图片，不使用父级统一透明度或游戏区域模糊；图标均在正常布局中，没有 absolute 图标对齐。

8 个 HUD 用例覆盖：

1. 独立折叠、刷新/重进持久化、快速重复切换、时间和移动继续、首次提示。
2. 暂停及子页返回来源、直接 Tab/M/Q、Tab 焦点/空格/箭头、关闭后清除移动输入。
3. 八槽绑定、数量更新、每槽键盘与鼠标使用、焦点稳定、不误触攻击；通过正式存档导入建立物品样本，不作为物品获取或通关证明。
4. UI 点击/拖动不穿透，装饰空白与隐藏地图的命中目标确为 Canvas。
5. 配置损坏与本地存储拒绝时仍能操作。
6. 真实走到 NPC 对话并更新目标，任务不强制展开；训练入口和动态风步信息保留。
7. 三个桌面视口、DPR 2、小地图/完整地图 alpha 和逻辑尺寸，以及 480×420 短屏菜单内部滚动。
8. 保存、实际导出下载、旧存档结构、非法导入保留原状态、标题设置返回。

6 个既有回归分别为 village-chest、hidden-chest、session-title-continue-new-refresh、session-sprint-recovery、village-polish-render-lifecycle、village-polish-movement。村庄回归检查木工台/喷泉/水面纹理、生命周期和真实移动/桥岸/遮挡/交互；本轮证据位于 `regression/village-polish/`，没有用本轮运行覆盖原修复证据。

复现命令：在应用目录先运行 `node tools/serve-hud-runtime.mjs`，另一个终端运行 `npx playwright test tests/hud.spec.ts --config tools/playwright-hud.config.ts`。相关回归可用同配置运行 `tests/chest.spec.ts tests/session.spec.ts tests/visual-polish.spec.ts`，村庄证据目录通过 `FARWIND_EVIDENCE_DIR=docs/hud-redesign/regression/village-polish` 指定。截图工具为 `tools/capture-hud.mjs`，可读性工具为 `tools/capture-hud-legibility.mjs`。

首轮确实发现小地图底层 alpha 叠加至 0.84，已修正为统一合成后 0.60。另有定位器歧义、读取事件帧过早、软件 GPU 并发时固定墙钟等待不足和热重载中断；保留首次截图/trace，改为观察实际模拟状态，不以盲目重试掩盖原因。详见 [首因记录](first-failures/ROOT-CAUSE.md)。

## 可读性与未验证项

石路、草地、明亮水面已采集真实运行图，包含七种图标和八格双位数数量；均使用不透明米白数字与独立半透明衬底，局部加强只出现在操作格子。见 [道具栏局部比对](comparison/legibility-hotbar.png) 和 `after/legibility-*.png`。展开地图的道路、桥、水域和玩家标记已在运行图及 Canvas alpha 检查中核对。

真实时间 20:00 的夜间样本已导入并截图，但当前基线场景没有实际变暗：World 创建夜间 Rectangle 时填充 alpha 为 0，后续 setAlpha(0.22) 与填充 alpha 相乘仍为 0；对应日/夜样本同坐标背景像素一致。本轮不改场景光照。`after/legibility-night.png` 是真实 20:00 运行截图，但不能据此宣称通过暗夜可读性。[模拟暗背景预览](design/hud-night-legibility-preview.png) 只检查预期暗色背景，明确不是正式运行效果。

尚未验证：真正变暗的夜间背景、目标设备 FPS/低端设备性能、全部其他 E2E 用例及用户最终美术验收。软件 GPU 测试中的帧率不作为目标设备性能结论。
