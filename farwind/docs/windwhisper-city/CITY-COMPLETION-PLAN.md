# 风语城完整实现计划

日期：2026年10月4日。状态：原始完整计划保留；本轮已先生成素材再接入正式实现，进度见[实施记录](COMPLETION-PROGRESS.md)。以下“当前基础”描述实施前基线，不能作为最新开发状态。

目标是把现有城市骨架建设成白石红瓦、商贸繁盛、居民有日常生活、守备严密的完整风语城，并让世界地图、区域地图、小地图、室外和室内入口对应同一套地理数据。遵循用户指定顺序：先完成布局与素材规格，使用 imagegen 生成高清素材并验收，再开始正式实现。此次是较大的内容扩建，按可试玩、可保存、可回归的阶段交付。

## 一 当前基础与完整交付范围

当前源码已经有连续商路、六处遭遇、西门、中央广场与风塔、议事厅、档案馆、驿站、补给铺及12处住宅。16处建筑用地中没有开放城市室内；风塔内部、地下设施和章节首领仍是未开放入口。已有4个服务角色、4名近卫和6名弓卫，主要服务于西门防线。公开街道能走通，不等于繁华城市已经实现。

保留商路与西门的连续步行、城市库存的原子购买、商路参与奖励规则和独立城市守备。当前主存档结构22、地图9，仅作为本次核对基线；正式开发时必须重新读取最新版本，不能提前占用下一版本号。

完整交付包含以下可实际游玩的内容：

- 完整外城建筑与街巷、中央风塔、商业和生活细节、白昼与夜间表现。
- 11处公共或剧情场所及12处住宅。公共场所为驿站、市场商馆、行会、锻造坊、药坊、茶馆、议事厅、档案馆、兵营、风塔和地下设施。风塔或地下可以分层；场所数量不等于最终室内场景数量。
- 24名有身份市民和12～20名来访者的首版设计目标；保留现有4名服务角色的身份、位置和业务。居民有工作、购物、休息、夜间归家和警报避难行为，来访者有真实进城、目的地和离城路线。
- 24名城市守备的首版设计目标：现有西门10名岗位保留，增加4支双人巡逻队和6名行政区、兵营及其他门岗守卫。正式人数须在性能与路口拥堵样板验收后冻结，不能以满屏重复站立角色充数。
- 一条完整城市主线、一位章节首领及12项支线或委托；有开始、前置、失败处理、完成状态、唯一奖励与回访反馈。
- 购买、休息、制作、交谈、调查、护送和城防闭环，全部纳入正式保存、旧档迁移与刷新回读。

范围止于风语城本身。北风山脉、月影湖、金沙荒漠等完整区域不随城市完工自动开放；城市新增的北、东、南门保留未来连接位置及整备说明，不生成通往未实现九境的假道路。住宅可以有合理的访问权限，但每处必须有实际室内与居民用途，不用十二块“暂未开放”招牌代替住宅完成。

## 三 imagegen 素材前置流程

### 参考与规格先固定

以根目录 `design.png` 的白石红瓦城市、当前村庄实际游戏视角、现有城市地标和统一手绘世界地图作为参考。风格为清晰的2D斜俯视手绘动漫；白石、红陶瓦、蓝金旗、木制商棚及绿植形成统一色彩。建筑与角色的视角、光向、脚底锚点、角色身高、门宽比例和阴影强度先写入素材规范。

先绘制标注真实坐标的几何底稿，并登记每座建筑的编号、占地、门点、用途、外观与室内对应关系。几何底稿是生产约束，不是最终美术素材。imagegen 不能自行决定新道路、水域或建筑位置。

第一组 imagegen 视觉基准包括城市日景总览、夜景总览、西门、繁华市集、风塔广场和行政区六张参考图。总览承担氛围和建筑样式对齐，不被当作整张不可交互地面；关键地标与街区位置必须对应底稿。夜图不改变建筑和道路形状。

### 首版生产素材清单

| 街区建筑 | 住宅变体、商铺立面、驿站、茶馆、锻造坊、药坊 | 同视角与比例，屋顶／立面可独立组织，屋檐不能变成不可见碰撞 |

生成使用内置 imagegen，源图和正式素材都保存在项目中，文件名英文、生成与校核记录中文。透明素材要求真实透明背景；不烘焙中文招牌、按钮、进度或角色名字。阴影单独处理或烘焙进静态地块，避免每件物体附加一张透明地面阴影而破坏合批。

高清按有效图像像素验收：大型建筑建议独立源图长边1536～2048或更高，常规物件和单帧人物有效区域尽量达到实际显示尺寸的2倍。数字是生产目标，最终记录工具真实输出尺寸及主体有效区域；不能把插值放大叫作原生高清。动画按方向和动作拆成受控小图集，保证每格像素、脚底、服装、朝向与肢体一致，不将几十个人物挤在一张图里。

所有首版必需素材在正式实现前完成。只有生成图通过透视、裁切、透明边缘、分层和小样板验收，才开始城市正式接入。只允许素材预览／导入检测所需的最小工具，不先做占位城市再补美术。实现中发现缺陷时按冻结风格返修，不能临时换另一种画风。

### 素材验收样板

用已生成素材做三个最小预览：一段西门含两类守军，一条市集街含人物、摊位与道路，一个广场含完整风塔、前后遮挡与入口。检查角色走到建筑前后时深度正确，门点能辨认，屋顶符号与立面同一建筑，实际显示倍率下清晰。

素材清单记录编号、源图、实际像素、有效主体像素、脚底、碰撞参考、切帧、透明方式、日夜共用规则及状态。概念图好看不替代这些检查；素材未通过则仍标未验证。验收前不宣布美术完成。

## 四 城市生活与商业规则

24名市民的建议分工为现有4服务角色、8名商人／工匠、8名住户与学徒、4名行政和文化人员。每人有身份、工作点、住所或合理休息点、日程及少量与城市事务相关的对白。12～20名来访者补充行旅感，按固定规则进入、购物、停留、离开，不跨屏凭空刷新。

白昼：开铺、搬货、排队、巡逻、广场表演。傍晚：收摊、回家、交接班、灯火亮起。夜间：驿站和部分饮食服务继续营业，街上行人减少，岗哨和巡逻更明显。警报：商贩收摊、民众走向避难点、巡逻赴援；解除后逐步恢复。时间使用现有游戏时钟，暂停后全部暂停。

行人不抢占玩家主要路径。常规人群采用软避让，不能构成人墙或把玩家推入碰撞；排队区在街道旁划定，服务交互距离从可到达侧计算。市民和访客不得作为玩家友军伤害或刷奖励对象。受敌袭时采用可测试的避难规则，重要服务不会因背景行人永久丢失。

商业延续现有城市独立库存与保存成功后发布状态。新增店铺、制作和旅店也使用统一事务入口，避免界面双击重复扣款，失败时金币、材料、物品和库存一起回滚。日常住宿与“重排商路遭遇”分开表达：普通睡觉不隐式重排商路或补回库存；原有明确休整入口保留，永久风赐和待领候选不丢失。

对白、制作、药坊、行会和茶馆各有用途；公用建筑不只是名字不同但都打开同一段说明。12处住宅采用少量布局模板和差异家具，配合身份及权限，不追求十二套重复的新系统。

## 五 城防和章节玩法

### 三层防线

- 门外拦截与城墙弓卫：保留西门4近卫、6弓卫及自身短射击口豁免；城墙、树木及其他建筑仍真实阻箭。
- 城内双人巡逻：沿实际环道和街区行走，遇到合理可达威胁才赴援；不能隔墙锁定敌人、跨地图瞬移或把护送判成刷怪场。
- 行政区与兵营岗哨：防守限制入口、协调警报与补员，提供战后恢复秩序的可见反馈。

首次入城有一次简短登记，可以略过演出继续游玩；日常往返不重复阻塞。公共街区保持自由通行，剧情限制只作用于对应房间或任务阶段。西门不得在没有可达退路时自动关闭，把玩家和任务同行者困住。

警戒采用日常、关注、交战、恢复四个确定状态。触发依据为敌人进入有效警戒范围及真实可见／可听事件；要有退回正常状态的规则。守军伤势、倒地身份、换岗与任务结果按设计保存，临时索敌和路径不写存档。离开城市后不补放积压箭矢或战斗，补员与恢复是否推进用同一游戏时间规则明确处理。

拟新增24名守备不等于24个常驻战斗扫描器。仍遵守当前全局12名敌对活动名额和有界寻路预算，近处高频、远处低频或挂起；友军数量和背景人口不偷改敌对预算。

### 城市章节与支线

首领首版建议三类核心招式：可绕行的风刃扫掠、可读的地面风压落点、装置蓄能后出现可攻击的弱点窗口；第二阶段组合已有招式，而不是用大量单位堆难度。阶段0确定判定形状、动作列表和所需素材，具体数值再以正常装备及已有风赐样本校准。

建议城市主线为“风塔异响”：入城与委托引导→市集异常→档案调查→地下维护线→风塔失衡→章节首领→恢复与城市庆典。该主题是本计划提出的剧情方向，不冒充已存在剧情。

城市调查与原野主线分别记录，不强制玩家先清空全部原野据点。关键战斗按明确城内调查前置解锁，公共服务和探索保持开放。首领暂定为失控的风塔守护装置，正式造型与招式在素材阶段冻结；身份、掉落和奖励不能借用原野据点首领记录。

支线建议覆盖商业补给、制作与药坊、邻里生活、城防巡检、地下探索和档案调查，合计12项。每类至少包含有实际操作的一项，不用十二条跑到标记点读文字代替任务。护送有连续同行与丢失恢复；调查有证据记录；制作核对材料；城防有真实可达战斗或维修操作。

| 邻里的旧信 | 访问两处允许进入的住宅，调查实物并交回信件，保留证据状态 |
| 城墙巡检 | 沿实际楼梯和内侧步道检查墙段与射击口，完成后军官反馈 |
| 换岗补给 | 将军需送到兵营及指定岗点，实际换岗行为可见 |
| 地下泄风 | 进入地下维护区，按线索修复三处装置，出口与失败恢复可用 |
| 档案缺页 | 从资料与城市实物交叉查证，回档案馆补录，解锁主线可用线索 |

首版奖励优先采用已有金币、材料及城市实际服务内容；阶段0逐项登记奖励及凭据。不为了12项委托另建12套货币或成长系统。必要的新配方、任务物件和服务解锁纳入同一城市状态及素材清单。

首领具备清晰预警、阶段变化、失败重试和一次性完成奖励。中途保存与刷新必须保留合理阶段；重复交付、刷新和守军收尾不能重复奖励。剧情后改变对白、灯火、广场活动与开放入口，城市完成后仍保留日常商业与探索。

## 六 接入策略与当前实现缺口

复用已有室外世界、室内绘制、碰撞扫掠、居民寻路、游戏时钟、对话、经济事务和保存队列；只对明确城市用途扩展。室外保持同一世界，不新建一个与商路坐标断开的城市场景。

| 当前缺口 | 正式实现必须做的适配 |
| --- | --- |
| `CityDefense.update` 以距西门1400为活动门槛，索敌范围围绕西门 | 改为守备岗位／巡逻区与玩家活动范围的调度，验证广场、行政区也能响应；不能只加岗位配置 |
| `validateCity` 固定10个守军、岗位坐标仅覆盖西门，库存固定3种 | 用城市岗位和商店登记进行明确校验；旧10岗状态完整保留，新岗和新库存确定初始化，不吞掉损坏记录 |
| `CityGuardState` 只含现有守备模式 | 扩展实际需要的巡逻、换岗和警报状态；攻击身份、倒地恢复与串行号沿现有规则去重 |
| 城市NPC当前来自4个静态服务地物 | 引入城市身份、日程和运行实体，停用原静态人物展示及其已转移的交互／碰撞注册，避免同一角色同时站两处或留下不可见实体 |
| `SpaceId`、住所、房间碰撞和入口主要覆盖村庄 | 扩展城市空间登记及其消费者，接通实际房门、家具碰撞、室内服务、入口保存和地图室外定位；不能只在类型中加字符串 |
| 城市只有建筑招牌和未开放说明 | 改成真实业务、访问权限、任务或房门交互，并保留旧编号或明确别名映射 |
| 旧站位可能被新增建筑与家具覆盖 | 迁移前检查玩家、居民、守军、伙伴、掉落和门点；必要时移动到同一地区最近合法点，记录原因并保留可恢复备份 |
| 地图目前使用通用屋顶 | 将建筑登记与专属地图素材关联，以同一位置、门点和地标数据生成各尺度地图；不独立手摆第二份城市 |

城市居民使用独立名册与状态，复用必要的生活辅助函数，不把村庄12名守卫和原居民的日程扩展成全城共用名单。小黑及小宝跨城市、室内和剧情空间的支持边界必须明确；小宝现有自主生活不自动被改成全城漫游。

静态地表烘焙，街区按可见范围加载；动态行人、灯火和效果分预算更新。所有角色按地面脚底计算深度，高位屋顶、旗帜、桥栏和城墙分别遮挡。靠近门洞或高大建筑时适度淡化遮挡层，不能通过改碰撞范围来解决看不见玩家。

城市状态扩展须采用正式迁移和先保存后发布策略。正式读取与外部导入目前对结构版本有独立白名单，必须一起更新、覆盖旧22档和允许的历史格式；不能仅改变类型声明或迁移函数。队列、库存、任务领取、室内位置和章节结果均进行事务／刷新专项验收。

## 八 正式验收样本

1. 世界一致性：世界、区域、局部和HUD地图分别核对西门、广场、风塔、议事厅、档案馆、室内入口与首领所在地；标记和真实入口偏差为零。北、东、南方向未开发连接仍正确禁用。
2. 实走与场所：正常从原野经商路进入城市；逐一走到23处场所，进出允许访问的室内，验证权限反馈、通路、遮挡、穿隙及逃离路线。不注入坐标冒充通路通过。
3. 城市生活：白昼市集与广场两个繁忙视野，目标每屏12～20名活动者并含多种行为；夜间少量市民与清晰巡逻；警报后真实避难和恢复。目标以截图与实际观察验收，不能把城市总人数当成同屏繁华度。
4. 交易与日程：用正式来源获得货币、材料并购买、制作、住宿；快速点击、行囊满、保存失败和刷新回读均不丢失或重复。旧商路待领奖励和独立库存保持正确。
5. 城防：同一合法样本的12名混合敌人分别测试西门、可达内街威胁与行政区警戒；实际伤害、墙体阻挡、近卫／弓卫／巡逻配合、倒地换岗、警报收尾均可核对。专项导入夹具与正常新旅途明确分开。
6. 剧情：一条主线和12支线逐项完成与回访，首领首胜、失败重试、中途刷新、奖励领取前后刷新均验收。城市章节结果不污染原野据点及原主线状态。
7. 兼容：覆盖正式旧22档、待领风赐、已伤守军、城市／原野／室内站位、旧掉落、存档事务失败和非法记录；新版本读取及导入都验收。迁移不清空原进度，也不静默抛弃损坏的关键记录。
8. 性能：在用户实际Mac与Chrome，固定源码、存档、视口和同一路线比较。普通城内目标参考既有本机约120帧记录；市集最繁忙与12敌人警报样本以帧耗时P95不超过16.7毫秒为最低目标，连续运行10分钟检查缓存／对象数不持续增长。游戏帧、寻路、绘制与地图开关耗时分开，不能用地图专项替代实战性能。
9. 美术与界面：imagegen参考与真实西门、市集、广场、行政区、日夜画面同屏比较；先查比例、构图和建筑识别，再查近景清晰度和动画。桌面、390宽及短屏的业务操作、关闭入口与图标正常文档流分别验收。

只有场所、人口、城防、剧情、保存、地图与美术均达到约定范围，才称完整城市交付。性能或美术样板未达标时修复该首因，保留明确未验证项，不通过降低完成标准宣布城市完工。

## 九 方案审查

VERDICT: PASS

P0/P1 BLOCKERS:

无成立的阻塞方案缺陷。审查范围是本计划，尚无对应新实现，不能据此声明未来代码已经通过审查。

反证检查覆盖地理漂移、素材错误充当导航、硬编码守军状态、存档导入白名单、室内站位、交易一致性、守军奖励、活动预算、人群堵门、城门困人、警报跨空间、离城追补和主线相互污染。本计划已明确对应适配或验收门槛，未保留一条确定会造成严重失败的已选执行路径。

UNVERIFIED RISKS:

- 首版24守备和市集人流的性能、imagegen人物逐帧一致性、大型建筑有效像素，均需样板验证。
- 城市新增空间与小宝现有生活／战斗的跨模块影响，须正式接入时沿消费者检查。
- 现有共享目录持续存在并行改动，素材与代码开始前必须冻结最新基线。

NON-BLOCKING FINDINGS:

- 总览图不能同时担任导航和实景；保留统一坐标与独立生产素材。
- 优先通过街区差异、店铺服务和真实日程形成繁华度，不引入未经需求支持的城市经济模拟器或玩家通缉系统。
- 城墙与市集为第一批美术样板，但第1阶段要完成整套首版必需素材后才开始正式城市实现，符合用户指定顺序。
