# 城市同类接地问题排查与修复

日期：2026年10月4日。范围为已接入的风语城建筑、街市、室内陈设及其任务显示状态；没有扩建其他未开放区域。

## 排查发现

逐项查看64项静态候选素材，结合正式建筑与家具登记、阴影代码及实机截图分类。人物步态、悬浮守护装置、能量特效和地板不作为落地物处理。

| 对象 | 原问题 | 修正 |
| --- | --- | --- |
| 城市建筑、城墙、门塔、花台、告示板 | 通用椭圆影不能贴合实体底缘 | 依据素材不透明底缘描出窄接触影，固定物继续烘焙进地面区块 |
| 货车、长椅、梯道 | 斜视图的后轮／后脚高于前脚，单一底缘阈值会漏掉 | 补充已查看素材的后支点，保留实际脚根与占地 |
| 床、书柜、桌台、箱柜、炉台、铁砧、阀门与晶座 | 接触影集中在底部前点，支脚之间还有浮离感 | 共用实体底缘检测；断开的脚和门柱不连成黑带 |
| 墙灯、城徽 | 挂件放在地面上，还生成地面影与脚下碰撞 | 挂到后墙490高度，改用后墙层级；撤掉落地影和多余碰撞，查看点仍可达 |
| 室内后墙与出口门柱 | 缺少贴地石基暗边 | 分别在后墙下面、室内地面层绘制接触影，出口空隙保留 |
| 未开摊位柜台／完整水果摊 | 当前贴图不同，但烘焙影仍按完整摊位绘制 | 转为按实际贴图、帧与显示尺寸缓存接触影；投影跟随当前素材 |
| 可搬走货箱、已交接补给 | 静态缓存可能留下任务残影，交接补给原先没有影 | 保留可变物件的动态显隐，接触影随隐藏一起消失；交接补给复用缓存轮廓 |

底缘检测只在首次需要该素材时采样128像素宽的透明通道，取最下18%内的不透明轮廓，忽略淡烘焙投影。前次三类石基标定继续保留。静态地面只在区块生成时绘制；室内及任务变体按素材／帧／显示尺寸缓存小纹理，不逐帧读像素或上传画布。缓存随场景关闭释放；原透明占位椭圆仍禁用填充，未恢复曾打断合批的透明三角形。

源图及透明通道未改；建筑楼址、门点、城市任务与资源规则未改。墙面挂件移位并去掉碰撞，属于本次明确的室内修正，不宣称所有内部几何完全不变。

## P0/P1 BLOCKERS

无成立阻塞。审查核对了共享阴影默认路径、图像帧与尺寸切换、显隐、跨区块边界、场景释放、室内图层与实际交互距离。人物与旧村庄阴影继续走原默认分支；物件检测不写游戏状态。挂件无使用型事务，移位后的查看点由实际导航专项确认可达；城市任务设施与门点未移位。没有可达且达到严重正确性或数据完整性影响的执行链。

## UNVERIFIED RISKS

全部缩放倍率、全部昼夜与每个实例的最终主观美术未逐帧验收；其他设备与长期GPU资源未测。这些边界不影响上述PASS。

## NON-BLOCKING FINDINGS

三类石基与三类后支点为当前素材标定，替换素材时应一并复核。接触轮廓采样采用保守底缘范围，避免把悬空部件当作地面；未因物件是透明贴图而一律增加大椭圆。构建仍有既有大分块提示。
