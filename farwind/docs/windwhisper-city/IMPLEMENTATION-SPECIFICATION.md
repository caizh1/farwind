# 风语城闭环实现规格

本文件冻结首版内容与状态边界。2026年10月4日已接入正式代码，实际完成项与验收边界见[实施进度](COMPLETION-PROGRESS.md)和[本轮验收](completion/VALIDATION.md)；以下规格不代替运行证据。

## 场所与业务

十一处公共或剧情场所：候风驿站、市场商馆、商旅行会、锻造坊、药坊、茶馆、议事厅、档案馆、兵营、风塔、地下维护区。十二处住宅保留既有编号。外观脚底与入口分开登记，入口位于建筑脚底正南侧可达点；室内沿用已存在的房间边界与门口返回机制，家具逐件碰撞，退出后恢复对应室外门点。

驿站住宿恢复生命体力并推进到次日早晨，安全检查通过且保存成功后发布；不重排商路或隐式补库存。原“休整商路”服务仍保留明确说明与入口。市场卖药剂、面包、茶及已有材料；锻造坊以木材、石材、风之结晶制作已有铁剑；药坊用药草与浆果制作恢复药剂；茶馆提供饮食和市民线索；行会负责登记委托；议事厅与档案馆负责城案；兵营负责换岗和补给；风塔与地下承接调查及首领。住宅有住户身份、床、储物及可调查个性物件。

新增商品库存登记后独立校验，沿用交易序号、互斥提交、保存成功后发布。装备只能在原有规则允许处穿戴，不绕过成长前置。任务证据存于城市状态，不挤占普通行囊；交付普通物料须真实扣除。奖励金币不超过既有金币上限；满包奖励待领取，不丢弃。

## 人口与日程

现有四身份保留：西门指挥官岚铎、补给商芦锦、驿站林姨、守塔人望岚。新增二十身份：行会长常青、铁匠石衡、药师叶蘅、茶馆阿荞、货商秦舟、布商绫月、果商桑实、厨师麦叔；住户周婶、陆伯、沐禾、青萝、砚生、南音、学徒阿铎、学徒小栎；议事员顾川、档案员书宁、巡城文书卓然、说书人闻溪。

固定名册之外十六名来访者按确定种子错峰到达西门，经过门口、市场、广场等登记路径，购物停留后从原门离开；存档记录身份和旅途阶段，不靠摄像机切换凭空刷新。白昼工作与购物，傍晚回住所，夜间仅驿站和茶饮维持少量服务。警报走向避难点，解除后继续日程。街道人群软避让，不作为攻击目标或实体堵路。远处低频决策，当前空间和近视野角色优先更新。

二十四守备目标：保留原四近卫、六弓卫，新增八名巡逻卫（四条双人路线）、六岗卫（兵营两名、行政一名、北东南门各一名）。每岗有真实可达脚底与恢复点；巡逻沿环路、北街、市场与广场，轮值不瞬移。新增城门不开放其他区域。城墙巡检梯道、平台与高位弓卫分别登记，不将立面高度当碰撞深度。

## 城市章节与首领

主线“风塔异响”：入城登记、商馆异常、档案证据、地下维护、风塔蓄能、失控守护装置、恢复庆典。与原野主线分别保存；公共城市不要求原野全清。最后挑战只由城案前置解锁，不借用据点首领身份或结算。首胜奖励一百二十金币、三份风之结晶；奖励待领状态保存，满包不强行清掉候选。

首领三类招式：风刃扫掠（先预警扇面再沿扇面判定）；地面风压（三个固定或跟踪至锁定时刻的圆形落点）；蓄能冲击（可读核心提示，结束后弱点窗口）。第二阶段组合已有招式，最多一名首领、不添加大量杂兵，不改变全局敌对预算。动作、锁定落点、命中序号与战斗时间均确定，暂停不推进；同一攻击对玩家一次结算。失败回到可恢复点并可重试，已经取得证据不回滚，刷新不得复制首胜奖励。

## 保存与迁移边界

新字段必须同时接入正式读取、外部导入、校验、迁移和发布。结构版本根据实际接入时最新源码增加，旧十岗的身份、生命、串行号及伤势原样保留，新增岗位按登记初始化。损坏记录明确拒绝，不静默清空原进度。新家具覆盖旧室内站位或建筑覆盖旧室外站位时，在同一空间搜最近合法落脚点；玩家、伙伴和掉落分别核对，迁移留可恢复备份。

城市居民独立名册，不扩展村庄居民生活状态。室内城防不隔空间攻击；小黑采用已有空间迁移机制，小宝跨边界按实际支持与跟随模式处理，不能因新室内让已有伙伴永久丢失。离城不追补累积弹丸。

当前仅规格确定；完整自然旅途、十二委托、首领、旧档、失败事务、美术和性能均未验证。实际实现必须逐项提供证据，未验证项不能用方案审查通过替代。
