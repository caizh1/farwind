# 风语城与连续商路实现

实现日期：2026年10月3日。目标是桌面键鼠单人游戏中的连续探索、可绕行遭遇、城门真实防御与可恢复旅途。输入为现有大陆图、原野正式存档及项目已有战斗、导航、永久风赐和保存系统；没有增加依赖、提交、推送或部署。

## 地图与开放边界

同一个世界场景向东延伸，旧原野6400×4800范围保持，追加5400商路与4200城市，统一16000×4800。东口约（4230，1600）、西门（9690，1600）；六段主路、两条绕行支路、270单位有效桥面、超过360单位净空门洞连接到中央广场。树干、河水、岩石、墙体与建筑底部使用正式碰撞。门顶独立高位显示，玩家穿过时降低遮挡透明度。

西门集市与驿站、中央广场与风塔、东南住宅、东北议事与档案区已能探索。四名角色可交谈；药剂、面包、清茶各12份独立库存，价格18、7、10金币。两端驿站与城内接待员能明确休整。未开放室内、地下设施、章节首领均有中文提示。大陆图原“翡翠森林”改名“风铃原野”，显示混合地貌与风语城部分开放；海上位置继续只写黑紫色“？？？”。区域图按真实坐标显示道路、占地、服务点与玩家，提供全域／原野／商路／城市缩放。

## 旅途与战斗

六节点独立激活，每节点三波5、6、7只，合计108。随机种子固定成员、精英与候选出生点，碰撞查询将不合法点确定性调整到路肩。预告至少800毫秒、离玩家至少220；主路中央留撤退空间。绕行不要求清怪，不设剧情门槛。

峡牙猎兽生命72、主要伤害18，以绕侧扑击为主；崖羽投矛者生命84、主要伤害26，远程牵制；裂岩斧卫生命160、普通40、蓄力重击72，并使用重甲保护。六段伤害倍率为1、1.1、1.2、1.35、1.5、1.65；第四、第六节点末波各有一名斧卫精英，生命×1.8、伤害×1.25。

首次进商路生成旅途；撤退、往返、进城、刷新保留种子、波次与伤势。死亡或明确休整才增旅途身份并重排。清完18名成员后，至少9名受到玩家或同行伙伴有效伤害才给一次永久风赐候选。守军收尾允许保留有效共同战斗收益；纯守军击杀无金币、掉落和风赐。凭据由旅途身份和节点决定，重复击杀与领取不能重复奖励。重排保留已持有风赐与待领候选，清理小宝对上一趟敌人的瞬时引用。

所有活动敌人、夜袭和出生预告共用12名额。远处商路身体保存后释放，返回按保存位置恢复；追进原野的怪物也能恢复。恢复冷却至少800毫秒、保留攻击实例序号，不回放旧攻击。原野战斗远离后保存挂起；夜袭仅在原野运行，返回时按剩余名额逐个恢复，不一次解冻越过上限。

## 城门防御

四近卫：生命600、固定护甲12、近战42、间隔900毫秒；门外约450单位拦截，命中短距离击退，同目标800毫秒内最多一次。六弓卫：生命300、护甲6、箭伤34、850射程、约1400毫秒错峰射击，两侧各三名。每个岗位有独立合法射击口，只豁免自身墙体上的短出射段；出射后每段真实箭矢查普通墙、树与岩石，不将友军作为命中目标。

城内不生成怪物。追击者由真实攻击杀死，未用越界消失模拟清理。近卫不追进森林，脱战归岗；生命低于35%撤回恢复，倒地20秒由新实例从城内步行接岗，弓卫沿城内通路到楼梯位置登墙。守军状态与轮换身份保存，远离城门时暂停防御计时与清空飞箭。

## 保存与伙伴

主存档22、地图9。21／地图8旧档仅补城市与商路状态；原坐标、任务、伤亡、装备、伙伴、行囊与商店库存保留。原始21档在数据库写入升级时另存迁移前备份。商路不覆盖原野风忆，十名城市守军不加入原村庄名单。

独立库存交易与休整沿用串行原子状态提交，事务成功才发布副本；失败保留原金币、行囊和库存。节点奖励失败时保留待领候选并提示继续保存。同步扩展玩家、掉落、敌人、伙伴坐标校验；出生范围与当前追击位置分别校验，防止正常撤退造成存档拒绝。

小黑继续跟随，小宝自由生活仍在村庄与安全近郊；明确同行可参与旅途。阵亡沿用归风珠返回风铃村，旅途重排而永久风赐和待领候选保留。地形按相机附近分块生成，建筑与碰撞布局独立于整张设计图。
